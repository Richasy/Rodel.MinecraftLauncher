# 种子探索器 · 契约与性能

## 地表材质与起伏

地表与群系图分开：群系图保留可辨识的图例色，地表使用实际表层方块的顶面模型、纹理透明度和对应染色。保存列保留完整方块状态，不能选用blockstates文件的第一项冒充当前朝向；新版sprite对象与继承模型复用3D预览的资源解析。已安装原版的biome effects及grass／foliage色图提供保存地表的草木颜色，斑驳森林的原版橙色覆盖不能再替换为绿色示意色。缺少资源仍可读取保存地图，颜色降级不构成存档准入条件。

起伏由相邻有效列的高度差与西北方向照明表达，同一平地升高不改变材质颜色。树冠顶面与流体表面高度独立于原有实体／河床高度；水面保留原有群系水色，已知水深控制明暗。未知区块保持透明，不参与坡度计算；群系层和明确Y切层不附加地表阴影。原生地图与PNG共用同一像素实现。

当前26.3适配器通过目录`decoratedMaps`声明真实植被表层采样能力。`world seed map --request-file`的typed请求可设置`decorated: true`，要求terrain、无Y切层、`side * step <= 128`；返回`decorated`、`surfaceColors`、`surfaceHeights`和`waterDepths`。它在独立临时世界按固定请求范围执行原版TERRAIN／FEATURES／FULL，读取实际树冠、建筑和草木，不打开玩家存档、不自动求值容器。冻结范围／生成次序仍是预测策略，不承诺与任意探索次序的世界完全相同。缺少模型的ID进入warnings，不涂成另一种群系。

细瓦片额外读取一圈真实相邻高度，绘制与裁切不会在瓦片边界改用缺失值。保存／预测合成各自保留来源内的阴影，不能用预测高度给玩家修改过的地形制造假断崖。紧凑保存状态缺少原版默认属性或早期客户端没有JSON模型时，只使用可读取纹理与生效群系颜色降级，不猜选第一个变体，也不对已着色的红叶再次套绿色染色。

App远景继续先返回轻量基础地形，近景提高到按方块采样；只有能力已声明且范围满足预算的细瓦片才生成真实植被，结构查询、群系切层与粗预览不继承该请求。已有历史适配器保留基础地图，未声明植被表层能力时不冒称同等细节。存档模式直接使用实际保存表层；未探索外围仍是独立原版预测，不能将预测提升为已保存数据。

参考源码：

- [squaremap](https://github.com/jpenilla/squaremap/tree/2e158c2f11b22923c29bdd91ed0dbab74d055d15)，MIT。`common/.../render/scanning/ChunkScanner.java`核实跨区块前一列高度、相邻高度差着色与流体深度；`BiomeColorSampler.java`核实独立群系着色。这里参考数据职责，没有引入服务器插件或复制其渲染代码。
- [VoxelMap](https://github.com/Updated-VoxelMap/VoxelMap/tree/dab1a50a7ae789f2671313b30db9c2662fd8c9b5)公开源码中的`ColorManager.java`与`Map.java`核实顶面模型／纹理取色、native tint和地表／植被／透明／水底分层。[项目页](https://modrinth.com/mod/voxelmap-updated)标为ARR，不作为宽松许可依赖或复制来源。
- [Xaero’s World Map项目页](https://modrinth.com/mod/xaeros-world-map)标为ARR，公开说明包含资源包支持与地形阴影；当前没有从其官方入口找到地图渲染源码，不能把第三方扩展／缓存格式说明当作官方算法。

## 存档模式功能边界

同一工作区按来源读取数据；存档不要求可读种子。保存内容始终优先，未探索区域可补原版预览；损坏或无法读取的保存区块不被预测掩盖。

| 功能 | 存档模式 |
| --- | --- |
| 地表、群系、Y切层与图例 | 读取保存区块；原版完整目录与观测ID合并，未知采样透明。 |
| 结构图钉、附近搜索、地点详情 | 使用保存的结构起点及子件合并边界；没有记录不代表未保存区域不存在结构。 |
| 3D／俯视、Y范围与容器定位 | 读取保存方块及属性，复用安装资源和现有网格；缺失模型明确列出，未知体素不画成空气或替代方块。 |
| XYZ区域材料与矿石筛选 | 统计实际保存体素，未知格单列，不计为已确认空气；矿石数量不是掉落量。 |
| 容器、物品图像与组件 | 只读Items及components／旧tag；LootTable不自动求值，缺少物品清单使用InfoBar说明并提供独立的手动预测。保存槽位仅表示已记录范围，不猜总容量。 |
| 收藏、语言与PNG | 收藏保留实例／存档／维度／视野，刷新修订不混为另一种子；语言刷新重读名称；PNG元数据保留saved来源及存档名称。 |
| 玩家与坐标定位 | 保存位置和精确匹配的实时观察分开呈现；复制坐标／传送命令不在游戏执行。 |
| 筛选种子与历史 | 属于生成任务；进入筛选时切回种子来源，返回可恢复存档视野，不用保存数据冒充生成候选。 |

Core的`WorldRegionQuery`、`WorldStructureQuery`与保留会话提供相同读取；CLI入口为`world map region`、`structures`、`scene`，均接受typed JSON的`--request-file`，scene沿App路径构建模型／网格后返回摘要。原版紧凑状态省略的默认属性由原版注册表补足，再应用保存覆盖值；不会把用户存档交给JVM或生成区块。当前生成运行时和部分历史资源仍有兼容限制，不能从存档读取覆盖推定所有Java版本已验收。

生成预览只调用对应版本的Minecraft Java原版逻辑，不引入Cubiomes或C#重写的生成器；独立Sprout窗口支持输入种子、按群系／建筑条件筛种及地图查看。所有Java版本均须纳入支持目标，不能长期限制26.3；版本列表仅启用已有实例对应的已安装版本，其余禁用。跨版本接口、历史命名和存档格式仍须实际核验，不把调用原版等同于无需兼容处理。

实例世界地图不设第三排工具栏：输入／地图内容在上一行，玩家入口在地图覆盖层并紧邻坐标定位左侧，版本／种子及复制在footer。完整状态与边界见[当前设计](../design/seed-explorer/DESIGN.md)。整合包支持留待后续。Core／CLI已接存档读取与位置来源，Sprout已按最新布局完成原生宽／窄窗口核验，视图／Y直接浮在地图上，不套额外外框。原版生成已扩展实际API族，不能把版本目录或存档格式覆盖当作全部历史API、运行时及生成能力已验收。

## 原版运行时兼容契约

Core从选定实例解析原版基础JAR、依赖和Java，在独立工作目录执行，不带入加载器参数、模组、数据包或玩家世界。手动种子、实例世界生成预览及外围补图共用当前生效的全局／实例Java配置与托管运行时引用，沿用实例覆盖优先级，相对Java路径以实例游戏目录解析；未选择时保留自动发现，不能只读取实例顶层的Java字段而忽略正常设置入口。Java配置读取失败保留可读存档及配置警告，不阻止只读已保存地图。缺少可运行的Java或依赖时，App保留Core错误码与实际原因，需要处理的功能失败由玩家手动关闭。后端按实际API形态选择：已编译快路径、WorldLoader／WorldGenSettings注册表接口、WorldSettings／服务器接口，以及早期直连World接口。缺少官方映射时以类文件、原生NBT写入及构造／调用关系证明绑定，不维护按游戏版本号列出的混淆字母表。生成和结构放置／部件组装始终由安装的原版代码执行。

官方映射依据基础元数据的SHA1和大小验证，进入精确运行指纹；下载器独占目标lease并原子发布，验证过的缓存可离线复用。地图、区域、搜索和收藏不混用其他游戏依赖或适配器的结果。目录保留实际数字群系身份和原生名称；界面未知ID的稳定配色只是显示规则。维度高度和候选来自当前运行目录，合法但不存在于该原版的功能由原版明确拒绝。

完整区域以固定邻区和阶段顺序生成，读取状态后关闭原生世界／存储锁，再冻结导出供Core读取；原生容器容量和槽位来自该次世界。进度只报告实际loading／terrain／features／full／scan阶段，不造总体百分比。相同规则的可重复预览不等于不同生成顺序、不同范围或玩家已活动存档的每个方块都一致。

某些早期原版的出生点选择使用种子以外的随机状态。目录以`SeedBoundSpawn=false`说明此能力，生成地图不画伪精确出生点，也不将它用于确定性spawn条件；存档模式仍可读取已保存的实际出生点。早期实验天空维度保留真实legacy标识，不冒充末地。不存在的结构、群系或维度不能通过补一张版本表伪造出来。

存档读取按文件实际形态选择Anvil、McRegion、早期独立区块、Indev NBT及Classic有限地图解析，不按版本号逐项分支。纯保存读取保留未知区域，缺少种子／玩家记录时不造默认值；文件变化使已有读取会话失效，调用方重开取得新修订。App在后台检测落盘文件变化，保留视野及最后有效画面自动刷新；拖动、选区、高级详情和导出期间延后替换。Classic Java对象流只解析有界的原始数据，不加载Java类或执行反序列化回调。格式参考[ClassiCube固定源码](https://github.com/ClassiCube/ClassiCube/blob/44ba25aa5cceb0030d3b28c52d26d416599a8606/src/Formats.c)。

存档实况的未探索区域直接使用原版生成预览。`WorldMapSession.MapWithPreviewAsync`以已保存样本为优先，只补确实缺失或处于原生地表生成之前的区块，损坏／权限／解析错误不被预测掩盖。`Saved`与`Known`分别记录保存归属和最终可用覆盖；`PreviewFingerprint`独立绑定原版运行时，预测结构另存`PreviewStructures`。App按当前可见范围逐步补图，地点／预测结构详情与footer显示来源；材料统计、已保存结构搜索和容器读取仍只承诺实际保存内容。无法准确复现的自定义生成配置保留实况并说明外围预览不可用，整合包生成继续后置。PNG保留两种来源及其身份，原版工作进程只使用独立临时世界，不写玩家存档。

元数据兼容内联WorldGenSettings／Player与分离的data/minecraft/world_gen_settings.dat、players/data玩家记录；维度优先实际namespaced目录并保留旧region／DIM布局。singleplayer_uuid用于识别本机角色，不能按另一玩家文件较新就替换。方块状态按实际NBT形态读取旧Name复合字段、字符串、id／properties及异构列表的空键包装，不按游戏版当前实现；无法解释的状态报告读取警告，不能当成实体方块铺满地图。原版材质从客户端JAR读取，压缩条目先进入有界可回读缓冲，再由图片解码器采样。

CLI入口为`world map show INSTANCE WORLD`、`world map player INSTANCE WORLD [--player-id ID]`、`world map read --request-file QUERY.json`及`world map export --request-file QUERY.json --output MAP.png`。请求是typed `WorldMapQuery`，例如`{"selection":{"instanceId":"INSTANCE","world":"WORLD"},"minX":0,"minZ":0,"side":64,"step":16}`；省略维度使用overworld。读取与导出不写真实存档。实时定位要求数据桥提供相同实例、精确世界目录和世界代际证据；未完成真实游戏验收的历史运行时不能记为已支持实时定位。

## 当前产品状态

普通地块查询使用独立准星，不加入建筑/群系图片图钉层，关闭后清除；地图菜单为左上角半透明覆盖工具组，窄地图收为图标。顶部不重复种子/版本/维度/视图，确认数量和局部覆盖进度移至固定测量高度的footer，加载/复制状态不能改变地图大小。完整视野归一化覆盖打开、恢复、调整窗口与平移，收藏接受与地图相同的0.25..65536格/DIP范围；原版工作线程的CompletionException/ExecutionException包装取消映射为cancelled终态，正常取消不显示错误，真正错误使用本地化Toast并保留日志诊断。

当前实现已实现独立`Rodel.Minecraft.Seeds`、按原版API族选择的生成适配器、Core/CLI及Sprout独立窗口。基础地图、条件筛种、持久搜索/两类收藏、地点Popup和冻结视野PNG已有实际验收，高级路径已接结构筛选、原版模型/纹理预览、普通容器位置及物品查询、有界XYZ区域材料统计；X-Ray继续暂停。不同运行时、NativeAOT与原生交互分别验证。

26.3原客户端JAR与实际目录逐项核对为67群系、52个`worldgen/structure`条目（含五村庄、七废弃传送门、18营地变体）。四张生成图集裁为119张透明小图标，地图/筛选/图例共用精确ID映射，普通主题各缩放统一采用单元素图片，世界原点和高对比保留功能符号。来源、裁切、摘要见[图像资产](../design/seed-explorer/ASSETS.md)与[清单](../design/seed-explorer/icons.json)。52条不包含地牢/晶洞等非结构注册表feature，不能将其误称为全部世界生成对象。

地图不再聚合地点或显示聚合数字，一个图标只代表一个真实位置，点击直接打开该位置的详情。普通地点标记随格/DIP按对数连续缩放，范围24～56 DIP，近看变大并在上限停止；图像绘制、点击区及避碰共用实际尺寸。原点／出生点继续使用20／32 DIP固定锚点，并按点击区与留白隐藏碰撞项，优先保留原点、选中、同上下文收藏及主动查询命中；隐藏不删除数据，放大可恢复，显示位置始终来自原版坐标。32格/DIP及以上远景只显示关注地点。弹层自然覆盖地图，不平移地图、不重排其下图钉，也不移动缩放工具组。结构页“查看地点”先释放离开页面的焦点再隐藏检查器，避免在已隐藏的分支中重新分配焦点；区域详情和收藏、图层、图例、历史等弹层共用同一覆盖原则。

生成模式的高级区域使用fresh隔离原版FULL生成，固定TERRAIN屏障、FEATURES顺序和邻区策略；区域范围与生成策略共同属于输入。区域统计包含所选范围全部位置，显示材料默认隐藏空气；矿石方块数不等于带工具/附魔的实际掉落量。点击容器继续使用同一份冻结分析快照，不另生成更小区域；详情临时切到容器高度，返回列表恢复进入前的Y范围，切换容器不覆盖原范围，新结构不继承旧记录。

种子窗口恢复上次可编辑输入与各版本/世界条件草稿，包含预算、切层及显示方式，但不恢复地图、搜索结果或执行状态；无编辑记录时可取最近实际搜索的查询配置，无记录则保持空态，不预填村庄。保存过的空条件不会被历史补回。窗口关闭前原子保存AppStorage.LocalPath中的编辑文档（MSIX包LocalState或无包EXE自有LocalState），普通窗口偏好由AppStorage选择对应存储。按Enter/生成、主动随机、开始或继续筛选均是显式操作；仅打开、恢复、切换条件页面不会生成地图或发起筛种。

`Seeds.GetCatalogAsync`可直接读取完整原版依赖指纹对应的注册表缓存，无须启动原版生成工作进程；`session.GetCatalogAsync`与CLI复用相同缓存。原版67群系/52结构及其维度/群系约束原样保存，本地化标签另读安装资源，不使用快速库或手写候选目录。缓存损坏会重读原版，写缓存失败不阻断有效目录。首次缺失缓存才在无窗口后台Java中初始化原版；App目录加载状态独立于生成状态，输入和顶部选择仍可使用。无条件空态不提前启动JVM；真实命中需要缩略图时才按需准备预览会话。条件骨架为约130 DIP顶部字段卡，不拉伸至整个侧栏。

世界出生点现在通过精确26.3原版新世界初始化计算：`createLevels → setInitialSpawn → PlayerSpawnFinder`实际生成并检查候选地表，读取最终共享`RespawnData`；不是仅取气候候选或原点地表高度。主世界地图和结果缩略图默认居中该出生点，旗标及其独立定位按钮对应；显式地点/收藏视野仍优先。坐标原点(0,0)保留罗盘标记和单独入口，切回原点不会改变出生点。两个锚点靠近或重合时也同时保留，旗杆脚保持真实世界坐标，小罗盘与右上展开的旗面区分，普通图钉避让两者。下界和末地没有这个新世界共享出生点，不直接套用主世界坐标。

新建主世界筛选条件默认以`spawn`为参照，也可以选择`origin`或前序条件；已保存的原点条件保留原意。原版26.3的spawn_target使用Density Function评价候选适宜性（[官方说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3)），但最终地面检查仍须执行。这里计算的是新世界共享出生点，不承诺每个玩家在出生半径内的随机落脚位置，也不读取或替代既有存档里由命令修改的出生点。

多条件按单父引用组成依赖树：独立的原点／出生点条件分别求解，只在真正的子条件失败时尝试所属父条件的其它锚点。同一父条件的子项始终共享一个锚点；结果仍按输入条件顺序保存。末端群系条件找到首个原版确认的命中即结束，有后续引用的群系条件继续保留最多64个候选供回溯。出生点的新世界初始化成本仍存在，不能以原点或气候候选替代最终出生点来加速。

原版选点初始化无法安全地在内部插入取消，因此每个未缓存世界按需启动独立、无窗口的出生点子进程，完成即退出；已完成坐标在引擎及Core缓存复用。等待边界同时检查取消及筛选期限，未完成的候选不推进游标；取消只结束所属子进程，主地图/搜索会话可继续。主/子JVM各有2GiB堆上限，不等于实际占用4GiB；未请求出生点时不启动子进程。缓存位于`cache/seed-explorer/spawns`，完整结果校验后原子写入，损坏重算，缓存写入失败不丢弃有效原版结果。Windows长classpath使用UTF-8参数文件和扩展路径，世界仍在独立内部临时目录中生成和清理。

本机独立原版DedicatedServer生成的`level.dat`与接口逐项对照：seed2/默认为(-32,66,0)，seed0/默认为(-32,69,0)，seed2/大群系为(240,69,432)。最终独立子进程策略下四个新上下文耗时约4.92～5.47秒（含子进程启动），磁盘缓存约4.2～5.5毫秒；主工作进程另有约3.97秒初始化。复用同一出生点JVM曾观察到seed0地表柱及Y在69/70间变化，独立原版存档五次和新进程探针四次均为69，故不保留较快的复用策略；尚未定位到原版内部的确切状态来源。以上是本机已有文件缓存的样本，不能外推为所有种子的耗时，固定海洋等难以找到陆地的预设可能更慢。原点参照的旧性能矩阵不含这笔成本。种子/结构等待使用真实阶段进度：结构按当前阶段的Completed/Total填充，地图上沿按已完成/总瓦片填充；初始化、出生点或网格构建没有总量时才循环扫动。阶段计数不冒充整体百分比，不清空已有地图。

结构内的“定位坐标”在同一冻结预览中聚焦容器，保留结构与物品详情，返回容器列表恢复先前Y范围和相机焦点。埋藏的宝藏的结构装配点Y不一定是箱子高度：预览在其周围5×5柱的维度高度内读取原版FULL方块，只选择X/Z吻合且原版战利品表为buried_treasure的宝箱；以实际高度初始化切层。未找到时保留实际扫描结果，不把附近地牢箱当作宝藏。

原版方块状态、模型JSON及PNG进入Seeds模型解析/网格，App负责D3D绘制、相机、切层与投影图钉。支持原版模型元素/旋转/UV及普通单/双宝箱闭合几何；不支持的特殊渲染模型明确列出，预览隐藏空气/流体。当前26.3原版API路径按真实体素群系、方块状态与模型tintindex取得原版颜色，初始化实际JAR的grass／foliage色图，保留未染色面；保存场景也可只传冻结方块与群系求色，不把玩家存档交给Java。网格独立传递逐顶点RGB，共面草侧面叠层采用LESS_EQUAL深度测试并保留透明孔洞。历史API族尚未全部接入该染色能力；光照、AO、透明排序、动画及加权外观仍简化，不能等同完整游戏渲染。

保存容器只读Items与LootTable，不自动求值。没有物品清单时以共享InfoBar解释原因，并在有表与seed时提供“预测物品”；`WorldMaps.PredictContainerAsync`重新验证实际保存记录及修订，在独立原版上下文创建脱离区块的容器并使用记录的表／seed求值，CLI对应`world map predict-loot --request-file`。预测使用独立结果和槽位，不写真实存档；普通战利品按无玩家/default-luck上下文生成，保留槽位、数量和组件，零loot seed明确标为非固定结果。宝库运行时奖励不伪造固定物品。

地图PNG现在支持冻结当前矩形视野，从已完成的原版瓦片取样、优先使用细瓦片，并保留实际视野/瓦片元数据；未生成像素或混合种子/运行时/维度会拒绝，失败不替换已有文件。它是地图数据导出，不含UI控件或类别插画。

存档实况的外围近景预览复用原版真实地表采样。`WorldMapQuery.Decorated`允许该次补图请求真实材质，默认关闭；适配器提供该能力、查询为地表且瓦片跨度不超过128格时，Core读取真实顶面、树冠、原版染色和水深，再仅填补确实未保存的像素。App只在细化层声明该请求，粗预览继续快速铺图；已保存像素始终保留。较大跨度、切层及不提供该能力的适配器仍走基础预览，不把近景装饰计算扩展到远景。

原生地图平移时只更新保留图层的绘制平移，不在每个指针采样上写整页状态、重新布局图钉或请求瓦片；松手后按同一世界边界提交视野，取消恢复原视野。该路径经过源码审查和正常NativeAOT构建，未使用坐标自动输入或产品探针冒充原生拖动实测，当前不提供修改后的拖动FPS结论。

## 地图性能与远景覆盖

地表采样用同一次原版柱确定表面/地面/流体，粗预览仅覆盖实际视野，较大栅格由两条拥有独立原版上下文的线程采样，完成后统一按行建立palette。结构加载不随栅格跨度直接关闭。JVM使用`ActiveProcessorCount`最多4的工作池提示；这不是OS硬限，也不表示总CPU时间一定下降。

预览瓦片较小，完整栅格继续保持同一目标采样精度。显示将仍在视野内的存档、预测和历史图像采样到同一套世界对齐网格，并按全视野可用覆盖统一细化；缩小时历史近景不能变成局部高清补丁，当前缩放级别的新图覆盖历史重采样结果。原始细图保留供再次放大复用，显示图不进入地图分析和PNG数据导出，图钉或进度更新也不重新生成显示图。当前视野计划中的瓦片不会因缓存容量压力被淘汰，非活动历史按最近使用情况回收。实例存档后台刷新修订时，上一修订的有效画面保留到新细图覆盖完成，仅作绘制底图，不进入新修订的分析与导出；切换存档、种子或生成配置不能复用该底图。实例存档模式在每层先发布可读存档瓦片，再补未探索预览，粗层完成后再细化；单块原版预览不会阻挡同层其它已保存区块显示。栅格就绪后可以导出，结构按独立1024格区域渐进加载和缓存。中近景规划最多8×8个连续区域，从中心向外查询；不在地图绘制自动查询范围线框；已查/计划区域数与范围外未知状态在footer明确显示。远景停止普通结构查询，不再用九块局部样本暗示全图分布；普通标记也不会混入当前范围之外的旧近景缓存。所有标注仍为原版确认的实际拼装结构，只计已确认位置，不承诺远景全量覆盖。平移、缩放和切种子均按同一取消代次丢弃旧结果，显式结构查找会先让出后台地图任务。

## 结构预览交互与性能

结构页将返回和地点信息合入原生标题栏，3D/俯视与高度工具直接位于下方；容器列表、详情和底部状态栏共用连续分隔线。左、右键均支持跟手旋转，松开或取消能在加载状态变化时释放手势。旋转期间暂隐图钉，稳定后按已完成画面的投影恢复。

预览改为GPU直接提交composition swapchain，相机更新不再重建整页状态，取消每帧GPU读回CPU再上传的显示路径；读回只保留给有界的实际像素回归。窗口尺寸变化按实际物理像素调整同一swapchain，关闭时先解除表面绑定，再等待工作线程释放。

## 玩家流程与参考

参考[MinecraftSearch地图](https://minecraftsearch.com/tools/seed-map)与[条件搜索](https://minecraftsearch.com/tools/seed-finder)的种子/版本/维度工具条、可平移缩放地图、图层开关、标记详情、可编辑条件和逐项结果预览。只参考交互组织，不使用网站后端、种子索引、素材、概率数字或准确率承诺。

独立窗口内使用“查看地图 / 筛选种子”两个任务入口，保持同一张地图、版本和世界配置上下文。

- 查看地图：选择已安装且支持的原版版本/预设，输入种子，浏览地表群系与地形；可以定位坐标、切换图层、点选结构、复制种子/坐标/传送指令、收藏、导出已完成的可见地图。
- 筛选种子：选择建筑/群系、数量与范围、距离参照，开始有界搜索。结果随完成逐项出现，每项包含条件命中摘要和地图缩略图；选中后主地图切到该结果并标出匹配位置，条件编辑不修改当前任务快照。
- 停止保留已有结果；预算耗尽时显示检查数量和实际结果，不把“未找到”写成“不存在”。新的地图失败保留上次完整地图及其真实上下文，不能让旧图顶着新种子显示。

## 原版执行与精度契约

C#依赖为CLI / Sprout → Core → 独立`Rodel.Minecraft.Seeds`类库，与`Rodel.Minecraft.Skins`同级；该库不引用Core。类库承接地图/条件/目录契约、生成元数据、校验、栅格/PNG和自有原版Java适配器打包；Core承接版本与Java准备、受控工作进程、文件指纹、缓存、搜索/收藏持久化及文件事务。Core宿主展开随库携带的适配器，调用指定版本原版JAR及依赖。没有独立产品EXE或运行时编译要求；玩家复用启动器已有Java，不安装JDK/Gradle。

Core复用现有实例/版本继承链解析、共享依赖与Java选择；原版计算可以不依赖玩家实例和账号。缺少版本文件时明确显示准备状态，安装复用现有Core任务，仅在用户选择安装后执行。原版类名/初始化并非稳定公共API，按实际注册表、构造器和生成接口形态选择适配；官方映射缺失时从原版字节码中的调用与字段职责识别，不维护逐版本混淆名表，也不将未知版本偷偷映射到最近版本。隔离查询助手要求Java8以上；玩家实例仍可使用自己的Java6／7，由Core另外选择已安装的助手运行时，`SeedExplorerSession.QueryJavaPath`报告实际查询路径。

每份任务和缓存绑定版本/JAR摘要、维度、世界预设、种子和完整生成配置指纹。所有Java版本均纳入兼容目标，版本列表按已安装实例启用，不维护26.3白名单；兼容目标不等于每个版本均已实测。初始不宣称支持修改生成逻辑的模组或自定义数据包；存在这些配置时保留原游戏正常启动，仅限制本工具的准确结果声明。

历史版本的缺失能力如实呈现：没有群系接口时目录为空、瓦片群系索引为-1，地形颜色读取可用的原版资源；没有种子输入或持久种子的有限世界返回`SEED_ORIGINAL_SEED_UNAVAILABLE`，不捏造种子。旧Sky维度保留`legacy:dimension_1`，只有原版确有末地证据才标为末地。原版出生点若还依赖种子以外的随机源，目录报告`SeedBoundSpawn=false`，生成模式不显示伪精确出生点；存档模式仍读取该世界真实保存的出生点。

群系范围不手工裁为常见地表群系：读取原版注册表、各原版BiomeSource的possibleBiomes及对应语言资源。26.3实读67项，默认主世界56、下界5、末地5，另有“虚空”用于特殊预设；HTML完整列出67项，特殊预设项说明其不在默认三维度自然生成。地下四类群系同样可选，并切换到明确Y切片；下界默认Y64而非基岩顶层，末地可显示原版基础岛屿/虚空。产品切片Y应在该维度实际高度范围内可选，当前HTML只内置主世界Y=-32和下界Y=64的真实样本。自定义维度由实际配置及适配能力另行承接，不猜测映射到三维度之一。

“使用原版”仍需明确生成阶段：

| 输出 | 原版计算及呈现契约 |
| --- | --- |
| 地表群系/地形地图 | 原版基础地形列/高度与对应表面坐标的群系；水体由该列实际流体状态识别，不用海洋群系边界冒充海岸线。缩小时按瓦片分辨率采样，放大请求更细瓦片；不是每格都已生成的存档或含树木的卫星图。 |
| 地下群系 | 明确的Y切片或垂直范围，与地表模式分开；不把Y64固定切片标成地表。 |
| 建筑标记 | 原版结构集/placement、完整抽选与排除规则、生成点和需要的原生拼装流程。标记返回真实阶段、结构ID、坐标及可得的范围；不以候选区块即存在，不显示自造的100% badge。 |
| 搜索正向命中 | 保存原版直接返回的群系坐标/结构坐标，半径与距离参照可复查；不使用网站种子库或其他生成库预筛。 |

## Core与CLI纵切

1. 在Core的Worlds功能下新增具体的种子查询服务与typed输入/结果，LauncherClient暴露同一业务入口。Core管理每个会话自身原版工作进程的有界生命周期、请求ID、取消、错误、瓦片缓存和搜索任务；Java封装原版数据，不依赖Sprout/CLI。
2. 规范入口为`world seed catalog`、`world seed map`、`world seed search`。先核对现有world组符号与所有权，命令直接绑定具体映射，后台与前台共用同一参数映射和Core请求；正式帮助和自有错误使用15语言资源，JSON/schema用同一强类型源生成元数据。目前`world seed versions/prepare/catalog/map/export/search start|list|show|resume/bookmark list|save|remove`已接线，CLI说明覆盖15语言；功能边界见本文件顶部。
3. catalog来自实际原版注册表及适配器能力，不维护手写全群系/全建筑目录。seed在JSON/UI中用字符串无损传递，按原版种子输入规则解析，禁止经过JavaScript Number丢失64位精度。
4. 地图按可见范围请求瓦片，先完成低分辨率可见瓦片再细化；缓存键含配置指纹、范围、分辨率和生成阶段，原子发布完整瓦片。移动地图时取消过时请求，以请求代次拒收迟到结果，不将旧种子瓦片拼入新图。
5. 搜索为现有typed任务体系内的只读任务，绑定候选种子序列/游标、条件快照、预算、已检查数、命中见证和结果。按原版可计算成本安排条件顺序，几何候选同样调用原版placement；没有第二套生成模型。多个条件引用同一个匹配对象时保持对象关联，不分别找到两个无关位置就算满足。
6. 首批正向条件包括建筑类型/至少数量/半径、指定群系出现、群系与已匹配建筑的相对距离；任一/全部语义显式。采样发现的群系只提供确证的正向坐标，不承诺穷尽。遍历预算、工作线程和内存有上限，搜索进度报告实际检查数/耗时/结果数，不伪造全种子空间百分比。
7. worker损坏/退出、Java不匹配、版本文件缺失、读权限失败、请求取消与预算结束有不同结果。故障只影响当前任务；重建进程后恢复已提交的搜索游标/结果，不触碰玩家存档。

缩小地图或向外平移时，正式实现自动请求新视野的缺失瓦片；缩小时扩大覆盖范围并降低采样细节，同屏计算量保持有界，放大时再细化可见区域，不预先生成无穷世界或全部存档区块。当前HTML没有运行Java后端，只能显示固定实测范围；缩小后显示“范围外未生成”，不能用重复图块、插值地形或定时器冒充自动扩图。

收藏、搜索历史及导出业务数据归Core；窗口位置、缩放/当前选择、临时面板开合归App。关闭独立窗口解除地图观察并取消过时瓦片，已启动的Core搜索按真实任务生命周期保存；再次打开恢复当前任务。主应用真实退出时停止工作进程并保存合法检查点，不留下无人管理的Java后台。

收藏入口位于标题栏“导出地图”左侧的书签按钮，展开锚定该按钮的360 DIP Flyout，内部用“种子 / 地点”segmented切换，分别显示数量和列表。种子条目可切回地图、复制和移除；地点保存版本、种子、维度、视图、原始坐标及调整后的传送Y，重复操作同一地点为取消/恢复收藏，不重复累加。地点条目可恢复对应地图并定位Popup、复制该地点所属维度的传送指令、独立移除。收藏、图层、全部图例及坐标定位均使用light dismiss，不放关闭按钮；点击外部、再次点击触发按钮或Esc关闭，Esc回到各自入口；点击地图以关闭Flyout时不同时打开位置Popup。方向键切换收藏分段，列表独立滚动。切换地图/维度关闭旧Flyout，不把旧条目操作套到新上下文。

## 独立窗口与HTML评审

承接[皮肤独立窗口](../src/Rodel.MinecraftLauncher.App/Features/Skins/SkinEditorWindow.cs)的单实例、非模态、重复打开激活/还原、首次位于主窗口当前屏幕、独立尺寸位置和语言/主题传播。复用最新main的应用生命周期与懒创建方式，不复制旧Shell职责。窗口保留Sprout原生caption按钮、最大化/Snap及非客户区机制，不另做产品EXE。

布局：单行标题栏；顶部种子、版本/预设和地图动作；中间地图占主要面积；筛选模式左侧为条件与结果，地图持续可见。选中标记使用锚定该坐标的非模态Popup，不再停靠右栏或改变地图宽度；根据边界及缩放控件换边，必要时平移地图保证锚点和操作完整可见。点外部或Esc关闭，相近图钉点击后在同一Popup列出地点，选一项查看坐标。顶部地图上下文和底部图例/比例尺/坐标各自占独立空间，不让图钉压在信息上。图层/全部图例收进轻量Flyout，打开时缩放控件避让；弹层覆盖范围内不绘制可点击图钉。条件卡使用真实可编辑值与清晰距离参照，搜索动作固定于面板底部，结果保持稳定身份。

Popup提供复制坐标和“复制传送指令”，当前26.3格式为`/execute in minecraft:<dimension> run tp @s X Y Z`，由当前维度生成，支持手动调整Y并显示将复制的完整内容。表面采样的传送高度默认在采样方块上方一格，结构保留原版返回Y，切片使用该层Y；不把基础地形列当作最终安全落脚点。按钮只写入剪贴板，不连接游戏或执行指令；旧版本接线时按其实际命令能力适配。三维度语法已通过同版原版命令解析器检查，没有在玩家世界执行。

当前使用119张透明单元素图片，地图标记、底栏/完整图例和图层条目共用精确ID映射；普通主题各缩放保持图片，高对比和世界原点保留功能符号。一个图钉对应一个地点，不合并或显示聚合数字。底部仅保留紧凑状态栏；比例尺叠在地图右下角，采用按缩放计算的1/2/5整数距离和匹配线长，完整目录从图层弹层进入。图钉常态为很淡的半透明底，hover增强背景及边界。图片只表示地点类别，不冒充游戏完整方块渲染；App正常复制发布Assets，不运行时读取design。

沿用[设计规范](../design/DESIGN.md)的方角、暖白/深灰、轻微凸起/内凹、细边界、常规系统字体、键盘才显焦点、每组一个accent及禁用中性表面。800×560仍保留种子输入、地图、搜索/停止和结果入口，条件与结果可通过面板切换而非缩小整张画布。原生App与CLI的可见文案覆盖已有15语言；HTML阶段重点检验中文、Light/Dark/HC、长种子与窄窗。
