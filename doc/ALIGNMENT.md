# 启动器能力与边界

内置AI直接调用Core受控工具，独立CLI保留命令与对外MCP，App不依赖或打包CLI；外部客户端引用明确选择的独立CLI安装。工具schema、技能正文和绑定状态按需加载，保留MEAI循环及Core权限/效果边界。

本表维护当前功能及入口，不记录阶段流水。实现细节以源码和[Core API](CORE_API.md)为准；正式测试入口见[测试说明](../test/README.md)。界面、夹具、发布物和实际游戏运行分别判断，不由某一层通过推定其他层完成。

## 内置模组边界

Rodel UI 从内置列表、分发矩阵和正常 CLI／App 打包撤下，源码保留为独立实验模块。Rodel AI、World Reroll、BetterTools 各自独立，不通过编译引用、运行时声明、反射或启动器 JVM 参数取得 UI 主题／字体／面板。主题开关归各自模组设置。既有玩家安装不自动卸载或禁用。
