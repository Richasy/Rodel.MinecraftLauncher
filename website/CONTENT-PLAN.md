# 文档内容与维护

本站面向玩家，以完整操作流程组织内容；中文与英文使用对应路径。

## 内容入口

中英各27篇，导航集中在`lib/navigation.ts`。新文章加入导航后，静态路由、站点地图、搜索与LLM阅读入口由现有内容管线生成。

| 分组         | 文章                                               | 内容重点                                                   |
| ------------ | -------------------------------------------------- | ---------------------------------------------------------- |
| 启程之前     | 导读、安装、第一次启动、账户                       | 发行版内置Client ID、系统登录、身份与存档的区别            |
| 探索与创作   | 皮肤、AI、种子探索、设置                           | 视角平移、快捷键、选区、透明蒙版、当前在线模型入口与关于页 |
| 实例与服务器 | 实例、迁入、整合包、内容、世界、截图、服务器、联机 | 截图搜索／多选／导出／删除、内容冻结审核与恢复             |
| 内置模组     | 安装、Rodel AI、World Reroll、BetterTools          | 三个独立模组；Rodel UI撤下及既有安装保留                   |
| 遇到问题时   | FAQ、启动问题、日志反馈                            | GitHub issue优先、邮件、启动器与游戏日志分别导出及隐私检查 |
| 关于项目     | 项目说明、微软登录、隐私、使用约定                 | 公开应用标识与服务资格分开、截图和在线AI的数据去向         |

## 写作与图像

- 先写玩家要做的事，再写入口、步骤和操作结果。不同状态给出具体下一步。
- 数据删除与范围授权的提醒放在相应操作旁，避免每段重复通用警告。
- 在线功能和本地文件操作分别说明；房间码不携带游戏环境，包导出不代替世界备份。
- 软件图像来自实际原生App。允许隔离模拟实例、内容、模型响应和联机状态；不绘制UI，不拍私人游戏资料。
- 中英同步功能与链接；图片旁描述其对应动作。图片来源见[ASSETS](ASSETS.md)。

## 检查与发布

维护检查使用`types:check`、`format:check`、`build`和`check:static`，覆盖中英文章路径、内部链接／锚点、图片与内容哈希。更新后的正文和缩略图还需实际查看；不以命令成功替代图像核对。

网站发布仍通过已有Deploy documentation工作流，更新文档不自动部署。原图、UIA结果、来源摘要和隔离清理证据仅保留在本地忽略目录，不作为站点构建或文档读取依赖。
