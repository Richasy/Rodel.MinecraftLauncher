## 这是正式产品吗

RMCL 已发布，是免费使用的实验项目，用来验证 Sprout UI 框架并探索 AI 辅助体验。感兴趣可以用一用，从[安装与准备](/docs/start/install)开始。

## 支持什么电脑

Windows 10 版本 2004（内部版本 19041）及以上，x64 或 ARM64。游戏、Java 和模组有自己的兼容要求。

## 从哪里下载和更新

可通过 Microsoft Store 或 [GitHub Releases](https://github.com/Richasy/Rodel.MinecraftLauncher/releases/latest) 获取 RMCL；对应渠道提供应用更新。完整步骤见[安装与准备](/docs/start/install)。

## 需要付费购买 RMCL 才能玩吗

RMCL 本身免费。Minecraft 的使用资格需按官方渠道取得；可选模型服务也可能单独收费。使用启动器不包含游戏购买或第三方 AI 费用。

## 现在开源了吗

启动器自有代码采用 **[GNU AGPL v3（AGPL-3.0-only）](https://github.com/Richasy/Rodel.MinecraftLauncher/blob/main/LICENSE)** 开源；独立模块与第三方组件保留原许可证。 使用 RMCL 不需要自行构建源码。

## 必须微软登录或配置 AI 吗

不是。已有实例、可用本地场景和手工配置有独立路径。需要正版验证的服务器仍验证对应身份。AI 是可选能力，手动管理和皮肤绘图不要求模型。

## 微软登录要自己申请 Client ID 吗

商店发行版不需要，软件已经内置。直接从账户菜单添加微软账户即可；游戏资格、家庭权限和服务端要求仍然适用。异常时见[微软登录说明](/docs/project/microsoft)，不要照开发教程借用别人的应用 ID。

## 为什么要有多个实例

不同版本、模组与设置分开更清楚，也便于保留稳定环境。实例不是世界：一个实例里可以有多个世界。见[实例管理](/docs/play/instances)。

## 更改数据目录后，原来的游戏不见了

目录修改不自动迁移。先确认当前数据位置和旧目录，保留文件，通过[导入流程](/docs/play/import)复制迁入。不要先删除旧目录。

## 装了资源包或光影却没有变化

在内容页切到资源包或光影包，检查选用状态。资源包可叠加并排序；光影单选，还需要兼容的光影引擎。修改后在下次启动检查效果。见[内容安装](/docs/play/content)。

## 为什么 CurseForge 内容不能在线下载

当前默认不提供 CurseForge 在线服务，保留离线 ZIP 导入与手工补件。Modrinth 在线内容继续可用。见[整合包](/docs/play/modpacks)。

## 服务器在线，为什么我进不去

状态查询与加入是不同过程。版本、模组、账户、白名单、满员和网络都可能影响加入。保留游戏提示，按[服务器指南](/docs/play/servers)检查。

## 为什么左侧没有联机入口

联机默认关闭。在 **设置 → 启动器 → 联机** 打开主开关，左侧才出现入口。房主和加入者的具体步骤见[联机房间](/docs/play/multiplayer)。

## 有房间码，还需要整合包吗

房间码不携带 Minecraft 版本、模组列表或包文件。先问房主用什么环境；已有匹配实例可以直接选，没有则创建或导入房主分享的包。

## 结束房间会把游戏关掉吗

房间主按钮会结束联机并请求游戏正常退出。想保留游戏，展开旁边箭头，选择仅停止联机或仅离开房间。关闭迷你窗口只收起小窗。

## 内置模组需要自己下载 Java 开发工具吗

不需要。在 **内容 → 模组 → 内置模组** 勾选安装即可。选择器按实例匹配包与依赖；游戏本身仍需要适用的 Java。详见[内置模组](/docs/play/built-in-mods)。

## 为什么内置模组里没有 Rodel UI

Rodel UI 已不再内置。当前提供 Rodel AI、World Reroll 和 Better Tools，三者都不依赖它；已有实例里的 Rodel UI 不会自动卸载。具体范围见[内置模组说明](/docs/play/built-in-mods#rodel-ui-已不再内置)。

## 游戏截图在哪里管理

在 **内容 → 选择实例 → 截图** 中浏览、搜索、改名或导出。双击交给 Windows 默认查看器打开；缩略图的裁切不改变原图。删除可选择回收站或明确的直接删除，见[截图管理](/docs/play/screenshots)。

## 游戏里的 AI 对话去哪了

游戏内会话只保留本次游戏进程，退出后清理，不进入启动器历史。同一次游戏中，聊天栏和侧栏共用当前世界会话；`/rai_new` 只清理对话，不删世界。见[游戏内 AI](/docs/create/game-ai)。

## 种子探索器在哪里

打开左上角头像菜单，选择种子探索器。世界菜单也可以直接打开相应存档地图。种子、版本和世界生成设置共同决定预览，使用方法见[种子探索](/docs/create/seed-explorer)。

## AI 说完成了，为什么还没看到结果

看实际工具、任务和游戏状态。入队不是完成，进程启动不是世界就绪；回答中断也不说明此前修改全部没发生。见[AI 助手](/docs/create/assistant)。

## 皮肤画完了会自动应用到账户吗

不会。导出 PNG 后，按适用账户或游戏环境的真实入口使用。保留工程可继续改图层与历史；PNG 不能代替工程。见[皮肤设计器](/docs/create/skins)。

## 能替我玩游戏、自动生存吗

当前没有交付自动游玩或人物托管。AI 重点是解释与辅助处理明确任务，不能把发展方向当作现有能力。

## 还有问题

启动失败请先看[启动问题](/docs/help/launch)。需要人工讨论时，整理必要信息到[项目反馈](/docs/help/feedback)。
