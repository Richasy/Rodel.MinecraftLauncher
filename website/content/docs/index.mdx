RMCL 是一个面向 Windows 的 Minecraft Java 版启动器 PoC，也是用来验证 Sprout 原生 UI 框架的实验项目。它提供日常游戏管理，并持续探索 AI 怎样帮助刚接触 Minecraft 的玩家理解问题、完成准备和尝试创作。

不需要先学命令行。从一套能正常启动的游戏开始，遇到需要的功能再回来查。

> [!NOTE]
> RMCL 免费使用，通过 [GitHub Releases](https://github.com/Richasy/Rodel.MinecraftLauncher/releases/latest) 下载。 启动器自有代码采用 **[GNU AGPL v3（AGPL-3.0-only）](https://github.com/Richasy/Rodel.MinecraftLauncher/blob/main/LICENSE)** 开源；独立模块与第三方组件保留原许可证。

## 先认识三个名字

**账户**是你以谁的身份进入游戏。它关系到在线身份和服务器里的角色，但不是存档，也不会因为添加账户就自动获得游戏使用资格。

**实例**是一套分开管理的游戏环境，有自己的版本、模组、设置和世界。“原版生存”“方块建筑”“朋友联机”可以各建一套。

**世界**是实际游玩的存档。一个实例可以有多个世界。准备更换版本、模组或实例之前，先备份重要世界。

## 第一次使用的建议顺序

1. 确认 Windows 10 版本 2004（内部版本 19041）或更高，使用 x64 或 ARM64 设备。
2. 阅读安装和账户说明，选好数据目录。
3. 先让一个原版实例正常启动，再添加模组。
4. 为重要世界建立备份，然后尝试自己的玩法。
5. 有不明白的地方，可以查手册或请 AI 解释当前问题。
