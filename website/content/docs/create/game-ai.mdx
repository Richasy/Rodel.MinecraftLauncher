## 启用前的三件事

1. 在 **设置 → AI** 添加模型，并设为默认模型。游戏中新消息使用这个默认选择。
2. 确认目标实例的 **游戏数据桥** 没有被关闭。它默认开启；以前关闭过时，在实例入口或 **设置 → 游戏启动** 中重新启用，下次启动生效。
3. 在 **内容 → 模组 → 内置模组** 安装 Rodel AI，再通过启动器重新启动该实例。

安装器会补齐匹配依赖。现代版本提供自己的侧栏和主题设置，不再依赖或附带 Rodel UI；Forge 1.20.1 使用原生全页记录和单行输入。具体组合见[内置模组](/docs/play/built-in-mods)。

## 从聊天栏直接问

打开 Minecraft 聊天，输入：

```text
/rai 我刚进入这个世界，先看看我周围有什么，建议第一步做什么。
```

先看到回应状态，完成后一次显示完整答案。接着输入 `/rai 那我手里的这个物品怎么用？`，可以追问刚才的内容。提交后聊天框保留，按 Esc 仍能退出。

控制台需要更多信息时，助手会用文字询问，下一条 `/rai 消息` 就是接续回答。

## 打开侧栏慢慢聊

在暂停菜单选择 **AI 助手**，或直接输入不带消息的 `/rai`。现代版本右侧显示聊天面板，支持流式回答、查看较早消息、停止与继续提问。

- **Enter** 发送，**Shift+Enter** 换行。
- 向上阅读会暂停追随最新内容，使用 **回到最新消息** 回到底部。
- 助手给出选项时，点击就提交；也可以自己输入回答。
- 问答等待期间发送普通文字，会作为该问题的回答。

普通单人世界使用游戏原生暂停；多人和已对局域网开放的世界仍继续运行，面板会提示当前情况。

## 问整合包里的配方与任务

可以把问题落到当前玩法，例如：

> 我想做这个工作台。看看这个实例实际有哪些配方，需要先准备哪些材料？

> 这个任务要求什么，我和队伍现在完成了哪一步？

> 手册里提到的这台机器怎么开始做？先找对应的手册条目。

游戏桥可以读取适配环境中的实际配方、FTB 任务和团队进度，以及 Patchouli 手册。能读到哪些内容取决于这个包安装的模组与提供的数据；缺少信息时，直接补充物品名或界面文字。

## 对话会保留多久

| 操作                           | 对话变化                         |
| ------------------------------ | -------------------------------- |
| 在同一个世界切换聊天栏与侧栏   | 共用连续会话                     |
| 本次游戏中离开再进入同一个存档 | 可以接续本次会话                 |
| 切到另一个存档                 | 使用另一个世界的会话             |
| 输入 `/rai_new` 或点击新会话   | 清理当前世界的旧对话，不删除存档 |
| 退出本次游戏进程               | 清理该次游戏的全部游戏 AI 历史   |

启动器 AI 页的历史单独持久保存。游戏内对话不会混进那里。

## 让助手操作时

游戏入口已经为本回合提供游戏操作许可，不再逐条询问同类游戏指令。实际命令仍遵守 Minecraft 的作弊开关和玩家权限；连接多人服务器时只读，即使拥有 OP 也不会通过这条入口修改服务器。

文件等精确范围的确认仍单独出现。要尝试改动物品或世界，先在可丢弃的本地世界中使用明确、有限的目标，例如“把时间改为白天”。

## 没有响应时检查哪里

先核对默认模型能否在启动器内回答，再检查这个实例是否启用了游戏桥并已重启。停在标题画面时，等待进入世界是正常状态。模型连接错误看启动器的服务设置；游戏已经执行过的修改先看实际结果，再决定是否重试。
