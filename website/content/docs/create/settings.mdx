## 从搜索开始

进入 **“设置”**，使用搜索查找“语言”“Java”“内存”或“代理”，定位实际选项。搜索不会替你执行操作，也不会搜索私人填写值。

全局设置和实例配置中的有效编辑都会自动保存，不需要另找保存按钮。实例独立配置优先于全局默认值；大部分运行配置影响后续启动。输入无效时先修正对应字段，不要把关闭面板当作已经保存。

## 语言、主题与壁纸

在启动器分类选择显示语言、跟随系统或固定浅色/深色主题，并为两种主题选择壁纸。也可以调整游戏启动后启动器窗口的行为。

App 提供 15 种语言，包括分别可选的简体中文和繁体中文。语言改变后，页面文案随之刷新，实例名和玩家填写的内容保持原样。

启动后的窗口行为可以设为留在桌面、最小化或收进托盘。已经收起时从托盘恢复；恢复主窗不会再启动一份游戏。

## 联机与迷你窗口

在启动器分类打开 **联机**，左侧就会出现联机入口。其下的 **联机迷你窗口** 决定房主最小化主窗后是否显示房间状态，关闭小窗不会结束房间。

活动房间期间关闭联机，会先弹出确认。确认后只停止联机，保留游戏；取消则保持原设置。创建与加入流程见[和朋友联机](/docs/play/multiplayer)。

> [!IMPORTANT]
> 更改数据目录需要重启，不会搬动已有游戏。已有数据的迁入见[导入说明](/docs/play/import)。

## Java 与内存

Minecraft 版本不同，适用 Java 也可能不同。优先使用自动发现与实例准备结果；需要自己管理时，打开 **“Java 运行时管理”**，发现本机 Java、导入已有运行时、下载或设置默认值。

实例指定的 Java 优先。删除托管 Java 前确认它是否仍被其他实例使用；外部 Java 解除登记与删除启动器拥有的文件是不同操作，先读范围。

内存可以按可用内存自动分配，也可以手工指定。更多不一定更好：还要给 Windows、其他程序和原生资源留空间。大型整合包按作者建议开始，再结合实际运行调整。

自动模式下，首页显示当前建议上限，正式启动时会按当时可用内存重新计算。切回手动模式仍可使用先前保存的手动值。

已经在高级参数手写最大内存时，它可能优先于普通设置。不要同时在多个位置填不同数值后只看一处。

## 游戏窗口与快速进入

可设置全屏或窗口尺寸。支持的版本可填写存档文件夹名直接进入单人世界；不支持时正常打开游戏菜单。

快速进入只决定启动目标，不会跳过世界加载和保存。联机目标与游戏自定义参数也可能影响实际行为。

**“游戏数据桥”** 默认开启，也可关闭；此前明确关闭的全局或实例选择会保留。改动在下次启动生效，可读取受支持游戏的信息并在自有本地世界执行有限操作；服务器始终只读。用途和范围见 [AI 助手](/docs/create/assistant#可选的游戏数据桥)。

## 下载与网络

可以选择系统代理、直接连接或手工代理，再按需要调整下载并发与超时。镜像规则适合明确知道来源和目标的用户；第一次使用保留默认即可。

一个在线服务失败，不代表本地实例不可用。更换代理或镜像后，先重试相关任务，不必删除游戏数据。

## 内容、缓存与日志

打开 **内容与缓存** 查看占用，按清理规则检查预计可回收内容后再清理；实际执行会重新确认保留条件。在 **日志与诊断** 中分别打开启动器日志或游戏日志导出，具体步骤见[反馈与日志](/docs/help/feedback)。

旧版游戏日志兼容和输出编码用于日志采集问题，默认自动选择。日志内容乱码时保留原始文件，确认编码后再调整，变更影响后续启动。

## AI 设置与外部工具

模型服务、文件和网络范围、内置能力及外部 AI 工具集中在 AI 分类。普通新对话的初始默认模式是 **“安全”**，可在 **“对话默认值”** 中更改；已有对话保留当前模式。新手可先添加一个模型，并保留默认的 **“安全”** 模式，详见[AI 助手](/docs/create/assistant)。

当前发行版仅提供在线模型服务，暂不提供本地 GGUF 模型入口。旧版本保存的本地模型配置不会因此被删除，也不会自动切换为在线服务。

内置工具和技能随软件提供；当前不提供自定义第三方 MCP 或技能注册。面向 Codex / Claude Code 的启动器接入是另一条可选流程，先预览安装计划。

## 高级参数与恢复默认

额外 JVM 参数、游戏参数和环境变量用于有明确需求的情况。不了解时留空；照搬他人的整套参数可能覆盖启动器已有选择。

恢复默认前先确认当前分类。实例的单独覆盖优先生效，恢复后仍有不同值时，再打开该实例的配置检查。
