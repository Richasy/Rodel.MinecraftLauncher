## 不会画也可以从一件小事开始

皮肤设计器是独立编辑窗口，既可手动画，也能请 AI 协助当前皮肤。先换一件衣服的颜色，比第一次就重画整个角色更容易掌握。

从左上角账户头像菜单进入皮肤编辑器。手动编辑不要求添加模型，也不要求先完成微软登录。

## 1. 新建或导入

打开 **“工程”** 菜单，新建工程，选择名称、基础模板、手臂模型和纹理尺寸；也可以打开已有工程或导入 PNG。

- **标准手臂 / 细手臂**：决定手臂形状。PNG 没有标明模型时，需要自己确认。
- **64×64**：适合常规 Java 账户皮肤。
- **128×128**：用于 HD 纹理创作，不能直接当作标准 Java 账户皮肤上传。
- 旧式 64×32 PNG 可按导入流程转换为现代布局。

导入替换当前内容前看清提示。替换涉及模型、尺寸和图层，但可通过历史撤销。

## 2. 认识视图和工具

主画布可以切换 **3D / 平面**；UV 小窗可与主画布同时使用，编辑的是同一份工程。立体视图用于检查穿在角色身上的效果，平面与 UV 适合处理边缘、小区域和接缝。

| 工具 | 适合做什么                 |
| ---- | -------------------------- |
| 画笔 | 一笔一笔添加像素           |
| 橡皮 | 擦除可透明区域的内容       |
| 填充 | 给区域换色                 |
| 取色 | 从已有像素选颜色           |
| 选区 | 限定区域，复制、剪切或移动 |
| 镜像 | 对称绘制对应部位           |

### 移动视角，不移动像素

| 操作                        | 3D 画布                        | 平面 / UV              |
| --------------------------- | ------------------------------ | ---------------------- |
| 左键拖动                    | 使用当前绘图或选区工具         | 使用当前绘图或选区工具 |
| 右键拖动，或 Alt + 左键拖动 | 旋转角色                       | 平移贴图               |
| Ctrl + 左键拖动             | 平移模型视图，不改变旋转和缩放 | 平移贴图               |
| 滚轮                        | 缩放                           | 缩放                   |

放大后想把脸或衣角移到画布中间，用 **Ctrl + 左键拖动**，不用先取消选区。迷失视角时使用复位。右侧面板边界可拖动调宽，工具选项从顶部当前工具按钮展开。

### 常用快捷键

| 快捷键                           | 操作                             |
| -------------------------------- | -------------------------------- |
| B / E / G / I / R                | 画笔 / 橡皮 / 填充 / 取色 / 选区 |
| M                                | 切换镜像                         |
| 1 / 2                            | 3D / 平面视图                    |
| [ / ]                            | 减小 / 增大笔刷                  |
| Ctrl+Z / Ctrl+Y，或 Ctrl+Shift+Z | 撤销 / 重做                      |
| Ctrl+C / Ctrl+X / Ctrl+V         | 复制 / 剪切 / 粘贴选区           |
| Ctrl+D                           | 取消选区                         |
| Ctrl+S                           | 保存或重试当前保存               |
| Ctrl+Shift+S / Ctrl+Shift+E      | 工程另存为 / 导出 PNG            |

在文本框输入、使用输入法或操作弹层时，快捷键优先交给当前控件，不会把输入的字母当作切换工具。

### 选区与粘贴

使用选区工具拖出范围，之后的绘制只作用于选区内。选区工具在已有选区内拖动，可以移动选中内容；复制或剪切后粘贴，先移动到目标位置，再点击放置或按 **Enter** 确认，**Esc** 取消尚未放置的内容。

画笔、橡皮或填充在选区外的**第一次按下只会取消选区**，这一次拖动不会顺手画上去；再次按下才恢复普通绘制。也可以用 **Ctrl+D** 直接清除选区。剪切或移动背景底层时，按工具选项要求确认源位置填充色。

## 3. 用图层保留余地

身体的 **“底层 / 外层”** 与右侧的 **“绘图图层”** 是两个概念：前者是皮肤表面，后者是编辑时叠加的内容。

给头发、上衣或配饰分别命名图层，方便隐藏对比、调整不透明度或重新排序。修改前可以复制工作层，保留原作。

画不出颜色时，先看当前图层是否隐藏、锁定或完全透明，再看当前选区和绘制部位。外层没有显示时，也要检查显示外层的开关。

## 透明色与可恢复的遮罩

普通橡皮擦除的是当前绘图层；背景绘图层的底层表面仍保留不透明底色。要让最终外观出现透明区域，可以选择 **透明色**：

- 透明色配合画笔，给对应像素添加透明蒙版；底下的背景和绘图层原像素保留。
- 橡皮在蒙版区域会先移除蒙版，重新露出下方已有绘制，而不是把原作擦掉；透明色模式下也可这样恢复。
- 回到普通颜色后继续正常绘图；需要恢复被遮住的内容时，清除对应蒙版或使用撤销。

蒙版参与当前预览、工程保存和 PNG 导出。导出的透明像素是否能在游戏里按预期显示，仍取决于对应皮肤格式与游戏环境；这不代表标准 Java 账户允许任意透明底层。

## 4. 管理常用颜色

色板里可以选择内置配色。内置色板为只读，复制一份后可改名、加入当前前景色、编辑或移除颜色。

自定义色板会在本机保留，跨工程与重启可用。删除色板不会删除已经画在皮肤上的像素。

## 把 PNG 加成一个图层

想把另一张图里的衣服或装饰叠进来，使用图层区域的 **导入 PNG 图层**。它会新建绘图图层，保留现有背景和其他图层，适合导入单独画好的外套、徽记或披风图案。

PNG 需要与当前工程的纹理宽高一致。人物工程使用 64×64 或 128×128；披风工程使用 64×32 或 128×64。旧式人物 64×32 PNG 要先按完整皮肤导入转换，不能直接作为现代人物图层。

图层菜单也可以单独导出 PNG。它导出这一个图层的原始像素，方便在外部工具里修改后再导回；完整角色导出则合成当前可见图层。

| 入口               | 对工程的影响                   |
| ------------------ | ------------------------------ |
| 导入完整皮肤或披风 | 按确认流程新建或替换整份内容   |
| 导入 PNG 图层      | 在当前工程新增一层             |
| 导出图层 PNG       | 保存单层像素，不改变工程       |
| 导出完整 PNG       | 合成当前可见图层，得到游戏纹理 |

## 画披风，再搭配角色看

开始页选择 **空白披风**，或使用 **导入披风 PNG**。披风有自己的正反面、边缘和纹理尺寸，可以使用图层、取色、填充与历史调整。

在编辑面板的搭配区域选择另一件作品：人物工程选择披风，披风工程选择人物。也可以导入搭配 PNG。这样能在同一个立体预览里检查颜色、背部遮挡和整体比例。

搭配只提供预览，当前绘图仍作用于正在编辑的作品。需要修改搭配作品时，使用切换作品；想单独看当前作品，选择独显或取消搭配。工程保存会记住选择，另存副本也保留这项关联。

披风 PNG 是可编辑、可导出的纹理素材；导出文件不会给微软账户增加官方披风资格。应用它时使用实际游戏环境支持的方式。

## 5. 请 AI 协助当前皮肤

先在启动器[AI 设置](/docs/create/assistant#1-添加一个模型服务)中添加可用模型，再打开设计器的 AI 侧栏。

给它一个明确、有限的目标，例如：

> 把这件外套改为深绿色，保留脸和头发。请分开建立衣服图层，并检查背面是否连贯。

> 参考这张图的发型和配色，简化成 Minecraft 像素皮肤。先保持当前人物比例，不要添加太多细碎装饰。

可以从文件添加或粘贴 PNG、JPG、WebP 参考图，每轮最多 **3 张**。所选模型是否理解图片取决于它的实际视觉能力。

> [!CAUTION]
> 皮肤 AI **直接修改当前皮肤**，不会逐笔询问批准。先另存工程副本，再尝试大范围修改。授权范围只限当前皮肤，不会因此获得其他实例或任意文件的管理权限。

## 6. 检查结果与撤销

看一次完整角色，再看头部近景。不要只检查正面，也看看头顶、背面、四肢内侧和外层衔接。

展开 AI 的工具过程，可以查看读取、绘制与保存结果。保存后旋转角色，对照你的要求检查脸部、衣服边缘和背面接缝。

使用 **“历史”**、撤销与重做回到合适的状态。请求中断后先核对已保存修改；结果尚未确认时使用恢复原请求，避免重复绘制。

需要看看角色走起来的效果时，打开动画预览。它展示当前作品与搭配的行走效果，不会改变像素；关闭预览回到编辑。

## 保存工程与导出 PNG

| 操作                | 用途                                               |
| ------------------- | -------------------------------------------------- |
| 保存 / 自动保存状态 | 查看当前编辑是否已落盘                             |
| 工程另存为          | 保留可继续编辑的独立工程，含图层与编辑历史         |
| 导出 PNG            | 得到平面皮肤图片，用于其他工具或适用的皮肤上传入口 |
| 导出为 64×64        | 为适用场景得到标准尺寸图片，导出后仍需检查细节     |

> [!IMPORTANT]
> **PNG 不保留完整图层和编辑历史，不能代替 `.rmcs` 工程文件。** 另存工程用于保留可编辑副本，不包含 AI 聊天与参考图，也不会把后续自动保存位置改到这个导出文件。128×128 是 HD 创作尺寸，不能直接作为标准 Java 账户皮肤上传。

导出不会自动把皮肤上传到账户，也不会自动安装 HD 模组。使用皮肤时按实际账户或游戏环境支持的方式设置。

## 保存失败怎么办

看到保存失败或草稿保留提示时，先保持窗口，检查磁盘空间和文件访问问题，再重试或保留可用副本。不要把窗口关闭当成已经保存。

纯绘图问题通常先检查当前图层、表面、选区与颜色；模型连接问题按[AI 助手](/docs/create/assistant)处理。
