## 先看你正在使用哪项能力

基础游戏管理以本地数据为主。微软登录、第三方认证、在线内容与在线 AI 会分别连接对应服务；不用某项可选能力时，不必先配置它。

以下按当前实现说明，不承诺其他服务的数据处理方式。

## 本机保存的数据

默认数据目录是用户文件夹中的 **.rmcl**，保存实例记录、游戏内容、相关配置、账户登记、备份、AI 对话与任务记录等。包应用偏好还保存在当前 Windows 应用包的数据位置。

皮肤工程保存可编辑内容与历史；AI 对话中已经发送的参考图会随相关记录保留。未发送文本属于当前窗口草稿，不能当成已保存对话。

启动器的 AI 历史持久保存；Rodel AI 的游戏内会话按本次游戏进程、实例和世界暂存，游戏退出后清理，不加入启动器聊天列表。`/rai_new` 只清理当前世界的游戏对话。

种子探索器在本机保存可编辑草稿、搜索记录、收藏和生成缓存。实例世界地图读取相应存档，地图图片导出不包含完整世界。皮肤与披风的搭配选择也保存在本地工程中。

游戏本身和模组也会在各自目录写入配置、存档与日志。

## 凭据

账户和 AI 服务的秘密凭据使用 Windows DPAPI 进行本地保护。正常模型请求仍需要把相应 API 凭据交给所选服务；本地保护不等于请求无需认证。

不要把数据目录、账户配置或完整日志当作可以直接公开的资料。重装系统、换设备和删除本地资料可能影响凭据可用性。

## 账户与在线内容

微软登录按微软和相关 Minecraft 服务的实际流程通信，外置账户连接你选择的认证提供者。

在线内容搜索、版本查询和下载会请求 Modrinth 及其实际文件来源。游戏与 Java 准备也会访问所用版本和下载来源；代理和镜像会改变相关网络路径。

当前默认不启用 CurseForge 在线服务，也不读取 CurseForge API 密钥；离线包的来源信息仍会保留。

## 在线 AI 会收到什么

所选模型服务会收到本次对话、系统提供的任务说明，以及为完成任务实际加入的必要上下文。按任务可能包含实例信息、错误、工具结果、已授权读取的文件片段和你提交的图片。

相关内容由所选服务按自身规则处理。使用前阅读其隐私和计费说明，不要把私人资料、他人秘密或不愿交给该服务的文件放进请求。

选择可访问文件夹不会自动上传整目录。实际访问仍受目录、读写与工具许可约束；已有读取内容也可能出现在后续对话上下文中。收窄目录范围不能撤回已经发送给服务的数据。

当前发行版暂不提供本地模型入口。使用在线模型时，上述请求会发往所选提供者；关闭网页工具不会让模型推理变成本地处理。

## 截图与分享

截图图库读取所选实例的本地截图，不会自动上传图片。重命名、导出和删除针对你明确选择的文件；复制到剪贴板后，接收内容的应用按自身规则处理。向 GitHub issue 或邮箱附图、附日志前，请自行检查并去除私人信息。

## 网络检索和网页读取

AI 网络检索可能请求 Mwmbl 搜索服务；网页读取会访问目标站点，网络处理还可能涉及 Cloudflare 公共 DNS。接收方按实际请求获得查询、地址或相应网络信息。

关闭 AI 的网络工具不等于切断在线模型本身。文件访问与网络访问也有各自独立的开关。

## 联机时交换哪些信息

陶瓦联机组件会连接发现服务，并与参与端建立网络连接。连接所需的网络信息、成员显示名等用于加入与展示房间；对方的游戏仍按 Minecraft 的认证和客户端协议通信。世界文件继续保存在房主实例中。

房间码是加入凭据，应私下发送。启动器用 Windows DPAPI 保护本地保存的码；这不妨碍拿到有效码的人尝试加入。导出连接记录或反馈截图前，删去邀请码和不想公开的地址。

分享整合包是独立的文件导出，不会因为创建房间就自动上传存档。联机分享排除世界、个人选项和服务器收藏；自定义共享配置仍需自己检查。

## 这个文档网站

文档网站没有接入分析器、广告或远程搜索服务；主题选择保存在浏览器中，搜索读取静态索引。访问网站不会读取本机游戏目录，也不会把启动器对话发送到这个网站。托管服务可能处理常规访问请求信息，本站不据此建立玩家画像。

## 删除与分享

可以通过对应功能管理账户、对话、实例和工程。移除账户登记、删除游戏文件、删除对话与清理备份各有独立范围，不要把一个入口理解成删除所有相关副本。

已经导出的文件、你另行保留的副本、公开反馈和第三方服务收到的请求，需要按各自位置处理。分享日志或截图前，按[反馈指南](/docs/help/feedback)检查密钥、私人地址和个人路径。
