## 微软登录用于什么

拥有适用游戏资格的玩家，可以用微软账户完成 Minecraft Java 版身份验证。RMCL 使用登录结果与相关服务取得游戏资料，并为所选身份准备游戏启动所需信息。

启动器不出售或赋予 Minecraft 游戏资格，不会因为创建了本地账户就获得官方在线身份。

## 登录与服务访问

**正式发行版已经内置 Client ID，可以直接从账户菜单添加微软账户。** Client ID 是用于识别应用的公开标识，不是你的账户密码或令牌。普通玩家不需要自行申请应用、填写 Client ID 或设置环境变量。

自行编译的开发版本是否带有该标识，取决于构建配置；开发者配置步骤不是发行版用户的安装前置条件。

微软登录仍依赖微软与 Minecraft 服务的实际响应、游戏资格和账户权限。内置标识不意味着每个账户都能通过验证，发行也不等同于第三方服务审批或官方背书。

RMCL 是独立启动器。本页解释登录用途与访问错误，不表示 Minecraft 或 Microsoft 对项目提供认证、赞助或背书。

## 登录时怎样操作

从左上角头像菜单添加微软账户，按 Windows 系统账户登录窗口提示完成验证。只有系统登录组件初始化失败时，才提供浏览器替代入口。核对页面来源和申请的权限，不要把账户密码、验证码或设备登录码发给项目维护者或公开反馈区。

如需了解微软账户本身的情况，使用[Microsoft 账户支持](https://support.microsoft.com/account)。游戏购买、下载与账户帮助以[Minecraft 官方网站](https://www.minecraft.net/)为准。

## 提示应用未配置或服务访问失败

先确认使用的是 GitHub Releases 正式发行版，并检查是否有更新。保留 **设置 → 关于此应用** 中的版本、错误原文和发生步骤；应用配置或服务访问问题可按[反馈指南](/docs/help/feedback)提交 issue，不能靠删除存档、切换 Java 或反复登录解决。

如果以前为开发版本设置过 `RODEL_MICROSOFT_CLIENT_ID`，这个环境变量仍会优先于内置值；错误或空白的覆盖不会被静默忽略。先确认是否还需要该开发配置，再修正或移除它，普通发行版用户无需新增此变量。

不要借用其他启动器的 Client ID，也不要按来历不明的教程填写应用密钥。网络暂时失败可以保留账户后重试；家庭权限、游戏资格或服务拒绝要按具体错误处理。反馈时删除令牌、验证码和个人资料。

## 孩子账户与联机

家庭管理、Xbox 隐私权限和服务器本身的规则可能影响联机。需要时由账户拥有者或家庭管理者通过相应官方页面处理，启动器不能替代这些决定。

## 暂时不使用微软登录

仍可管理已有实例、手动设置运行环境、编辑皮肤，以及在适用条件下使用本地身份。服务器或其他在线服务若要求有效官方身份，仍需满足其要求。
