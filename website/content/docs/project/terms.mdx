## 当前提供什么

RMCL 是已发布、免费使用的 Minecraft Java 版启动器，也是验证 Sprout UI 框架与探索 AI 辅助体验的 PoC。感兴趣可以在适合自己的环境中使用。

功能会持续调整，实际可用范围以所用版本、界面提示与任务结果为准。项目没有固定支持周期、响应时间或所有版本与模组的兼容承诺。

## 免费与开源许可

**RMCL 本身不收费。** 启动器自有代码采用 **[GNU AGPL v3（AGPL-3.0-only）](https://github.com/Richasy/Rodel.MinecraftLauncher/blob/main/LICENSE)** 开源；独立模块与第三方组件保留原许可证。

Minecraft 游戏资格、服务器、内容平台和 AI 服务各有自己的条件与费用。它们不包含在启动器的免费使用中。

## 与 Minecraft 的关系

RMCL 是独立项目，并非 Minecraft、Mojang 或 Microsoft 的官方产品，不宣称认证、赞助或背书。

启动器不提供游戏购买资格。账户、在线服务和服务器的使用仍需符合各自适用要求。

## 使用第三方内容

模组、整合包、资源包、光影、Java、认证和 AI 服务由相应提供者负责。下载和分享前查看来源、许可与使用条件。

导出整合包不意味着自动取得其中所有文件的再分发权。分享前检查配置中是否包含私人信息。

## 对自己的数据留副本

> [!WARNING]
> 重要世界在升级、降级、改变模组、迁移或恢复前先备份。不要只保留一个副本来试验不确定的组合。

启动器的恢复能力以实际保留的记录为基础，不能替代独立备份。文件删除、游戏保存和外部手动操作的恢复边界也不同。

## AI 的使用

AI 是可选辅助。回答可能错误，模型输出不等于工具已经执行或游戏已经就绪。变更后核对实际目标与结果。

你选择的模型服务可能收费，并按其规则处理请求。数据去向见[隐私说明](/docs/project/privacy)。

## 更新与反馈

安装更新时保留重要数据副本，核对应用名称、版本和发布者。遇到问题请按[反馈与日志](/docs/help/feedback)说明操作经过，提供必要信息并移除私人内容。
