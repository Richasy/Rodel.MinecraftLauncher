title: 安装内置模组
description: 选择 Rodel AI、世界重开与工具魔方，自动准备匹配的包和依赖。

RMCL 随软件携带三个可选游戏模组：Rodel AI、World Reroll 和 Better Tools。在 **内容 → 模组 → 内置模组** 中选择要用的功能，不需要另外找下载页或安装开发工具。

## 选择并安装

1. 在内容页选中目标实例，确认游戏版本和加载器已经准备好。
2. 切到 **模组**，打开 **内置模组**。
3. 勾选所需项目，匹配的内置依赖会一并准备。
4. 核对勾选项，点击 **安装所选**，在内容页查看进度和结果。
5. 完成后启动该实例。游戏已经运行时，先正常退出再重启。

取消勾选只是调整本次安装选择。移除已经安装的模组，仍在普通内容列表中操作。

## 更新已有实例

更新启动器会带来新的内置包，已有实例的模组要在这里单独安装更新。先保存并退出 Minecraft，再选择原实例、勾选要更新的项目并点击 **安装所选**，完成后重新启动游戏。

已有内容与新包不同时，项目会重新变为可勾选，即使显示的版本号没有变化；已经匹配且启用的项目保持勾选，不能重复选择。安装会替换该模组的旧包，兼容的共享依赖继续保留。多人服务器也需要使用匹配的更新包。

## 选哪个模组

| 模组         | 用来做什么                   | 详细指南                            |
| ------------ | ---------------------------- | ----------------------------------- |
| Rodel AI     | 从暂停菜单或聊天栏连续提问   | [游戏内助手](/docs/create/game-ai)  |
| World Reroll | 保留玩法设置，换一个世界开局 | [世界重开](/docs/mods/world-reroll) |
| Better Tools | 十格主备工具、战斗持剑与锄地 | [工具魔方](/docs/mods/bettertools)  |

三个模组可以分别选择，均不依赖 Rodel UI；各自的主题选项由自己的模组设置管理。安装器只准备当前版本与加载器实际需要的依赖。

## Rodel UI 已不再内置

Rodel UI 已从内置列表和正常发行包中撤下，源码仅作为独立实验模块保留。安装 Rodel AI、World Reroll 或 Better Tools 不会再附带 Rodel UI，也不需要它提供界面。

更新启动器不会自动删除或禁用实例中已经安装的 Rodel UI。如果此前安装过，可自行决定是否保留；需要移除时，在普通模组列表中核对目标后操作，而不是反复取消内置安装器的勾选。

## 当前可安装的组合

| 游戏与加载器                          | 内置项目                       |
| ------------------------------------- | ------------------------------ |
| 26.3 · Fabric、Quilt、Forge、NeoForge | 三个内置模组                   |
| 26.2、26.1.2 · Fabric                 | 三个内置模组                   |
| 1.21.11 · Fabric                      | Better Tools 工具魔方          |
| 1.20.1 · Forge                        | Rodel AI，使用该版本的原生界面 |

Fabric 与 Quilt 的匹配 Fabric API 随包提供。选择器会根据当前实例给出可安装项目或不兼容原因；1.20.1 Forge 的 AI 使用该版本的原生界面。其他实例仍可以使用普通模组安装流程。
