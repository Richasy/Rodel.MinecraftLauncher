## 开始前向朋友确认三件事

拿到的是陶瓦房间码时，直接看[和朋友联机](/docs/play/multiplayer)。本页用于收藏普通服务器地址，以及管理对应客户端。

先问清 **服务器地址、Minecraft 版本、是否需要整合包或特定模组**。服务器本身要由服主提供；这里管理连接用的客户端，不负责新建或托管服务器。

服务器和 Java 版是否兼容、是否需要正版身份，都由实际服务器要求决定。

## 收藏一个地址

在首页切换到 **“服务器”**，选择 **“添加服务器”**。

1. 填写方便识别的名字，例如“林间小屋”。
2. 输入域名或 IP；朋友提供端口时一起填写，如 `play.example.com:25565`。
3. 保存后刷新状态。
4. 需要修改地址时使用编辑操作。

这里需要的是游戏服务器地址，不是整合包下载链接。示例域名不提供可游玩的服务器。

收藏保存在启动器中，不会自动改写游戏原有的多人游戏列表。

## 选对客户端实例

点击连接时选择一个匹配的实例。需要特定模组时，先准备服主提供的客户端包；只改实例名称并不能让版本和模组变兼容。

可以把一个实例记为该服务器的首选，下次减少选择步骤。普通关联只记住选择，不改游戏文件、版本或世界。

## 普通关联与专用客户端

| 方式             | 适合场景                     | 启动表现                     |
| ---------------- | ---------------------------- | ---------------------------- |
| 关联已有实例     | 偶尔用同一套游戏连接多个地方 | 普通本地启动仍保留原来的含义 |
| 服务器专用客户端 | 一套配置主要服务一个服务器   | 默认启动会连接所属服务器     |

在 **“管理客户端”** 中添加已有客户端或新建客户端。把本地实例移入服务器管理时，不复制或移动文件，但它的管理归属和默认连接目标会改变，先阅读提示。

专用客户端也可以使用 **“普通启动（不连接服务器）”**。不再需要归属时选择 **“转为本地实例”**。

## 使用本次身份连接

确认本次账户，点击 **“连接”**。启动器准备游戏，再交给游戏处理加入。

在线人数、延迟和图标来自状态查询。状态查询失败时仍可尝试连接；显示在线也不代表你一定能进入，白名单、身份、版本和网络仍可能影响结果。

“游戏已启动”只说明启动阶段的结果，实际是否入服以游戏画面与明确连接提示为准。

## 下载中断、连接失败或取消

- **准备阶段失败**：查看任务中缺失文件、下载或 Java 的提示，修正后重试。
- **版本或模组不匹配**：核对服主的要求，使用对应实例，不直接覆盖常玩的世界环境。
- **身份验证失败**：确认账户可用；微软应用访问错误见[应用状态](/docs/project/microsoft)。
- **服务器不可达或满员**：查看游戏提示，向服主核实地址和开放状态。
- **取消后**：等当前任务的最终状态，再决定重试；游戏已经打开时先检查实际窗口。

保留出错信息后，可以请[AI 助手](/docs/create/assistant)解释，或按[反馈指南](/docs/help/feedback)整理证据。

## 移除收藏会删游戏吗

移除收藏会移除它的关联，所属专用客户端转回本地管理，游戏文件和世界保留。删除客户端文件是另一项有明确范围的实例操作。
