Better Tools 把常用装备收进 **工具魔方**。看向方块时选择适用工具，瞄准 32 格内无遮挡生物时准备武器，让快捷栏少占几个位置。

## 合成一个魔方

在工作台的四角放铁锭，四边放铜锭，中间放木棍。

## 放进常用装备和备用

在物品栏里，光标拿着装备点击魔方即可收纳。每类先进入主用格，再进入备用格。悬停魔方可查看两行十格，每类最多放两件原装备：

| 位置     | 从左到右           |
| -------- | ------------------ |
| 上排主用 | 镐、斧、铲、剑、锄 |
| 下排备用 | 镐、斧、铲、剑、锄 |

悬停时滚动鼠标滚轮，在已有装备间选择；空光标右键魔方，把选中的装备取到光标，再按普通物品栏方式放置。左键可以拿起整个魔方；拿着魔方点击已有装备也能收纳，右键空物品格可以取出一件。

不属于镐、斧、铲、剑或锄的物品，以及已经放满的类别，会留在原位。

### 交换主用和备用

滚轮选中一件工具后按 **Tab**，交换该类别的主用与备用位置。黄框跟随同一件原装备，上方详情显示名称、真实耐久和当前主备位置；另一格为空时也可以移动。再次按 Tab 可换回，附魔、属性和各自的耐久不会互换或重置。

### 切换浅色和 Dark 模式

从模组列表打开 Better Tools 的设置，或在客户端输入 `/bettertools config`，选择浅色或深色后点击 **完成**。设置保存在当前游戏实例，取消则保留原选择。两种模式使用相同的格子和操作方式，选中态只显示黄框。

## 拿在手里使用

把魔方放在快捷栏并选中。切换会立即显示实际工具，并保留已经积累的攻击蓄力；正常挥砍仍会消耗原版冷却。

### 采集与工具回退

看向方块时，先选能正确采收的同类主用工具，再考虑同类备用和其它有效工具。主用能完成工作时，备用不会因为等级更高就抢着使用。

缺少对应类别、没有有效工具或准心对空时，先保留当前可用工具，再回退最近使用或其它剩余装备。只有没有可用装备才显示魔方；例如没有斧子时看向木头，不会把手里的镐收回去。

回退不会改变原版采收和掉落条件。需要特定等级镐子的矿石，仍需魔方里有能正确采收的装备。

### 战斗时保持武器

准心对准 **32 格内无遮挡的生物** 就会提前准备武器，不必先走到贴身距离。受到实体攻击时也立即准备武器；实际攻击距离仍按原版规则。

优先使用剑；没有可用剑时，依次考虑斧、镐、铲和锄，每类先主用后备用。

**挥剑就进入战斗保持，挥空也算。** 期间准心扫过地面或墙壁都不会切走武器；每次战斗挥砍或受击重新计算五秒（100 游戏 tick）。目标死亡，或五秒没有继续攻击／受击后，才重新根据准心选择工具；如果仍瞄着生物，就继续拿武器。

### 用锄子耕地

右键可耕作土壤时优先使用锄子，而左键采集仍按方块选工具。原版土壤、朝向和上方空间校验保留；没有锄子时执行现有工具的原版右键动作。战斗保持期间不为耕地切走武器。

### 耐久与备用接替

消耗的是实际装备的耐久，附魔、自定义属性和独立损耗都保留。主用损坏后，同类备用接替；同类耗尽后仍会选其它可用装备。耕地中锄子损坏也沿用这套接替，备用不会继承主用的损耗。

快捷栏显示当前或最近使用的工具，并带有魔方角标和该装备的耐久条。打开物品栏编辑时，自动切换暂时停止，方便整理。

## 更新已有实例和魔方

更新启动器后，已有实例中的模组需要单独更新：

1. 保存并正常退出 Minecraft。
2. 在 **内容 → 模组 → 内置模组** 中重新勾选 **Better Tools**，点击 **安装所选**。
3. 完成后重新启动该实例。

有新内容的旧包会重新变为可勾选，即使显示版本号相同。已有八格魔方会保留原装备并扩展为十格，不需要取出重装。多人游玩时，客户端与服务器都要更新到匹配的包。

## 和朋友一起用

多人游戏的服务器与客户端都要安装 Better Tools。当前提供的版本和加载器组合见[安装与版本选择](/docs/play/built-in-mods)；它可独立于 Rodel UI 和 Rodel AI 使用。
