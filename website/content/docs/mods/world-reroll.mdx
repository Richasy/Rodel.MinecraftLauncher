---
title: World Reroll：世界重开
description: 保留玩法设置，换一个世界开局；也可以直接在村庄附近出生。
---

刚开始一个世界，想换一片地形再试试？World Reroll 可以沿用当前玩法设置，生成一个新种子的世界，再把你带过去。

## 选择新的开局

在单人世界按 Esc，点击 **重开**。设置页有两种出生偏好：

| 选项     | 新世界的开局                                   |
| -------- | ---------------------------------------------- |
| 随机出生 | 从新种子的自然出生点开始探索                   |
| 村庄附近 | 在村庄附近的安全地面开始，寻找村庄需要一些时间 |

重开沿用游戏模式、难度、游戏规则、生成设置与数据包，主要变化是种子。村庄选项需要启用结构生成。

## 看清确认页再重开

点击 **继续** 后，确认页会显示当前世界名称和重开动作。此时仍可以取消或按 Esc，回到刚才的设置。

> [!CAUTION]
> **新世界就绪后会永久删除来源世界的建筑、背包和进度。** 只对准备舍弃的开局使用；想保留当前进度，先[备份世界](/docs/play/worlds)。

创建或村庄定位失败时，来源世界保留。先阅读当前错误，返回原世界或调整条件后再尝试。多人服务器和已经对局域网开放的世界不能重开。

## 只想在村庄附近出生

新建世界时，在 **世界** 分类启用 **在村庄附近出生**。这条路径使用你填写的种子，在生成后调整初始出生位置，不删除其它世界；同样需要开启结构生成。

## 安装与外观

从[内置模组安装入口](/docs/play/built-in-mods)选择 World Reroll。它独立运行，不需要 Rodel UI；主题选择归自己的模组设置，不读取 Rodel UI 的配置。移除 Rodel UI 不会取消世界重开本身的功能。
