## 安装 RMCL

RMCL 是免费使用的 Minecraft Java 版启动器，通过 [GitHub Releases](https://github.com/Richasy/Rodel.MinecraftLauncher/releases/latest) 分发。Microsoft Store 不再提供后续更新。

<ReleaseDownload />

1. 打开上方下载链接，选择最新稳定版本。
2. 在 Windows“设置 → 系统 → 系统信息”确认系统类型，下载对应的 `RMCL-<版本>-win-x64-setup.exe` 或 `win-arm64-setup.exe`。
3. 运行安装向导，安装完成后从开始菜单打开 RMCL。

安装遇到问题时，保留完整提示，按[反馈与日志](/docs/help/feedback)提供系统版本、安装包文件名和发生步骤。

## EXE 安装包

安装包支持 x64 与 ARM64，以当前用户身份安装，不需要商店、管理员权限、额外的 .NET 或手动信任 MSIX 证书。安装包未进行 Authenticode 签名，可使用同页 `.sha256` 文件与 PowerShell `Get-FileHash` 核对下载摘要。

已有商店版与 EXE 版分别保存应用偏好，游戏数据沿用所选 Core 数据根。切换前记下自定义游戏目录，在 EXE 版设置中选择同一目录并重启；不要先卸载旧版或假定偏好会自动迁移。

## 更新 RMCL

RMCL 启动后会静默检查 GitHub 的最新稳定版本，检查失败不影响使用。有更新时，最小化按钮旁显示更新图标；点击可阅读当前语言的说明，按钮从左到右为“更新”“跳过此版本”“取消”。取消不会记为跳过；跳过只影响这一个版本。

更新会下载适合当前应用架构的安装包并显示进度。下载并校验完成后，RMCL 退出，再打开安装向导供你手动完成更新；向导结束后删除下载的安装包。有未完成任务或编辑器更改时，先完成或保存再重试。也可以直接从 GitHub Releases 下载新版安装包覆盖安装。

游戏、模组和整合包的更新仍在启动器相应页面处理。

## 卸载 RMCL

在 Windows“设置”的应用列表中找到 RMCL，选择卸载，再确认卸载提示。

> [!WARNING]
> **确认卸载后，此安装目录下正在运行的 RMCL 会被强制关闭，包括托盘中的实例，未保存的更改会丢失。** 正在进行的任务或编辑器草稿不会阻止卸载，请先完成操作并保存内容。

取消最初的卸载确认不会关闭 RMCL。卸载只移除程序及其安装登记，不关闭其他目录的 RMCL，也不删除已经落盘的游戏、存档或应用偏好。

这一强制退出行为由新版卸载器提供；旧安装需要先用新安装包覆盖安装后才会生效。

## 电脑要求

支持 **Windows 10 版本 2004（内部版本 19041）及以上**，支持 **x64 和 ARM64**。

这是启动器的系统范围。Minecraft、Java、模组和光影还有各自的硬件与版本要求；启动器能打开，不代表任何大型整合包都能流畅运行。

- 留出游戏、下载资源、世界和备份所需空间。导入已有游戏还需要完整副本的空间。
- 首次准备游戏通常需要网络；已有本地内容可按实际情况继续使用。
- 微软登录、第三方内容和 AI 是独立的可选能力，不必先配置 AI 才能管理游戏。

## 选择游戏数据目录

默认目录是用户文件夹中的 **.rmcl**，保存启动器管理的实例与相关数据。空间紧张时，可以在设置中选择其他磁盘。

> [!WARNING]
> **更改目录在重启后生效，不会自动迁移已有数据。** 已经有游戏时，应使用[导入已有游戏](/docs/play/import)复制迁入，确认可用后再处理旧副本。不要把数据目录设为会被自动清理的临时文件夹。

## Java 要先装吗

Minecraft 需要 Java，但第一次使用不必先研究参数。按创建实例的准备流程选择合适运行环境；已有 Java 也可以在[Java 与内存设置](/docs/create/settings#java-与内存)中添加、发现或管理。

游戏版本不同，需要的 Java 可能不同。优先按实例的准备结果处理，不要为了新游戏把所有旧实例都切到同一份 Java。
