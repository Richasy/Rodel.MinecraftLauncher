## 账户与存档是什么关系

账户告诉游戏本次由谁进入。切换账户不会搬动世界，也不会合并服务器里的背包和权限。一个实例可以由不同身份启动，但游戏可能把它们视为不同玩家。

点击左上角头像，进入账户菜单添加、选择或管理身份。

## 微软账户

**正式发行版已内置微软登录所需的 Client ID。** 普通玩家不需要注册 Azure 应用、填写自己的应用 ID 或配置环境变量，直接添加账户即可。

选择添加微软账户，会打开 Windows 的系统账户登录窗口。按窗口提示选择账户、登录并完成验证，RMCL 随后确认游戏资料与可用资格。

只有系统登录组件初始化失败时，才会提供浏览器替代入口。遇到网络失败，保留账户后重试当前登录；应用配置或服务访问错误按下方说明处理。

内置 Client ID 不代替游戏购买、家庭设置或服务端权限。发行版提示应用未配置或服务访问失败时，先核对是否已更新到最新 GitHub Release，保留错误原文并参照[微软登录与应用状态](/docs/project/microsoft)反馈，不要借用其他启动器的应用身份。

密码与验证步骤应在可信的微软页面完成。孩子账户的联机能力可能受家庭与 Xbox 隐私设置限制。

## 本地账户

1. 选择添加本地账户。
2. 填写一个容易记住的玩家名，例如“林间旅人”。
3. 添加后从账户列表中选中它。
4. 回到首页，确认当前身份再启动。

本地身份用于可用的本地游戏场景，不验证微软账户，也不会赋予游戏使用资格。需要正版验证的服务器和其他在线服务，仍按各自规则验证身份。

为已有存档更换本地身份前先备份。更名或换身份后，游戏可能把你视为另一位玩家。

## 外置账户

已经使用 LittleSkin 或兼容第三方认证服务时，可以选择外置账户，按该服务提供的地址与登录方式操作。不使用这类服务可以直接跳过。

> [!WARNING]
> 第三方认证由其提供者处理。确认地址来源，使用该服务的独立凭据，不要把微软密码填写到外置账户的密码框。

## 切换与重新登录

第一次成功添加的身份会自动选中，之后添加其他身份不会替换当前选择。没有账户时首次点击启动，启动器会先让你填写离线玩家名；有账户但尚未选择时，先选本次身份，再接着启动。

启动前看一眼当前账户。正在运行的游戏不会随启动器切换身份，下次启动才使用新选择。

凭据过期时按提示重新登录；网络暂时失败时可以保留账户后重试，不必先删除所有记录。移除账户只移除本地登记，不会注销微软或第三方账户，也不删除世界。

关于本地凭据的保存方式，见[隐私说明](/docs/project/privacy)。
