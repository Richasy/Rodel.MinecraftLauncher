## Install RMCL

RMCL is a free launcher for Minecraft: Java Edition, distributed through [GitHub Releases](https://github.com/Richasy/Rodel.MinecraftLauncher/releases/latest). Microsoft Store no longer provides future updates.

<ReleaseDownload locale="en" />

1. Open the download link above and select the latest stable release.
2. Check System type in Windows Settings → System → About. Download `RMCL-<version>-win-x64-setup.exe` or `win-arm64-setup.exe` to match.
3. Run the installation wizard, then open RMCL from Start.

If installation fails, keep the complete message and include your Windows version, installer filename and steps in [Feedback and logs](/en/docs/help/feedback).

## EXE installer

The x64 and ARM64 installers run per-user without the Store, administrator privileges, a separate .NET runtime or manual MSIX certificate trust. They are not Authenticode-signed; compare PowerShell `Get-FileHash` output with the matching `.sha256` attachment.

App preferences remain separate from the old Store edition; game data uses the selected Core data root. Before switching, record any custom game folder, select it in the EXE edition and restart. Do not uninstall the old edition first or assume app preferences migrate automatically.

## Update RMCL

RMCL silently checks GitHub for a newer stable release at startup. Check failures never interrupt normal use. When an update is available, an icon appears next to Minimize. Open it to read localized notes. The buttons are Update, Skip this version and Cancel, from left to right. Cancel does not mark a release as skipped; skipping applies only to that release.

Updating downloads and verifies the installer for the current app's architecture and shows download progress. RMCL then exits and opens an interactive installation wizard; the downloaded installer is deleted after the wizard exits. Finish active operations and save editor changes before retrying. You can also download and run a newer installer directly from GitHub Releases.

Game, mod and modpack updates remain in their respective launcher pages.

## Uninstall RMCL

Find RMCL in the apps list in Windows Settings, choose Uninstall, then confirm the uninstall prompt.

> [!WARNING]
> **Confirming uninstall forcibly closes every running RMCL instance from this installation folder, including those in the system tray. Unsaved changes will be lost.** Active tasks and editor drafts do not block uninstall, so finish your work and save changes first.

Cancelling the initial confirmation leaves RMCL running. Uninstall removes the program and its installation registration. It does not close RMCL instances in other folders or delete games, worlds or app preferences already saved to disk.

This forced-exit behavior is provided by the updated uninstaller. Older installations must first be updated by running the new installer over the existing installation.

## Computer requirements

**Windows 10 version 2004, build 19041, or later**, on **x64 or ARM64**.

These are launcher requirements. Minecraft, Java, mods and shaders have their own hardware and version requirements. Opening the launcher does not guarantee smooth performance in a large modpack.

- Leave space for games, downloaded resources, worlds and backups. An import needs space for a complete copy.
- Preparing a game for the first time normally needs a network connection. Existing local content can be used where supported.
- Microsoft sign-in, third-party content and AI are separate optional features. AI setup is not required for game management.

## Choose a game data folder

The default is **.rmcl** inside your user folder. It stores managed instances and related data. Choose another disk in launcher settings if needed.

> [!WARNING]
> **Changing the folder takes effect after restarting and does not move existing data.** Use [Import an existing game](/en/docs/play/import) to copy it in, check the result, then decide what to do with the old copy. Avoid temporary folders that may be cleared automatically.

## Do I need Java first?

Minecraft needs Java, but you do not need to study launch arguments first. Choose a suitable runtime during instance preparation. Existing Java can be discovered, registered or managed in [Java and memory settings](/en/docs/create/settings#java-and-memory).

Different game versions may need different Java versions. Follow the instance's preparation result rather than switching every older setup to one runtime.
