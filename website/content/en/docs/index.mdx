RMCL is a Windows launcher PoC for Minecraft: Java Edition, created to try out the Sprout native UI framework. It covers everyday game management and explores how AI can help new players understand problems, prepare a game and try creative tasks.

You do not need to learn the command line first. Get one game running, then return for the features you need.

## Three names to know

An **account** is the identity you use for a launch. It affects online identity and your character on a server. It is not a world, and adding one does not grant a game license.

An **instance** is a separate game setup with its own version, mods, settings and worlds. “Woodland Survival,” “Build Practice” and “Friends Together” can each have an instance.

A **world** is a saved game. One instance can contain several worlds. Back up important worlds before changing versions, mods or instances.

## A useful first-time order

1. Check for Windows 10 version 2004, build 19041, or later, on x64 or ARM64.
2. Read the installation and account notes, then choose a data location.
3. Get one vanilla instance running before adding mods.
4. Back up important worlds, then try your preferred setup.
5. Look up unfamiliar steps here, or ask AI to explain a specific problem.

## Using this guide

Pages are grouped by tasks. Search at the top looks through titles and text; on narrow screens, open the menu to see the directory. Names in screenshots illustrate the steps. Your own list will reflect your setup.
