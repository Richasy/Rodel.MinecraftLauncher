## Why RMCL exists

RMCL is a Windows launcher PoC for Minecraft: Java Edition. It began as a practical desktop scenario for trying the Sprout UI framework, connecting accounts, preparation, instances, content and worlds into usable flows.

It is not intended to compete with or replace other launchers. If native desktop UI or AI assistance interests you, follow progress and try it in an environment that suits you.

It targets Windows 10 version 2004, build 19041, or later, on x64 and ARM64. RMCL is free and available through [Microsoft Store](https://apps.microsoft.com/detail/9MW9ZMS2K47C) or [GitHub Releases](https://github.com/Richasy/Rodel.MinecraftLauncher/releases/latest). See [Install and prepare](/en/docs/start/install) for installation and updates.

## Everyday features

The project works through common beginner tasks: creating and migrating instances, accounts, runtime preparation, content installation, modpack import, server favorites and connection, and world backup and recovery.

## Explore and create

Use [Terracotta rooms](/en/docs/play/multiplayer) to invite friends into your world. The [seed explorer](/en/docs/create/seed-explorer) previews terrain, searches for openings and displays saved-world maps.

The [skin designer](/en/docs/create/skins) supports characters, capes, PNG layers, transparency masks, outfit previews, history and AI editing. [Screenshot management](/en/docs/play/screenshots) browses, organizes and exports images by instance. [Built-in mods](/en/docs/play/built-in-mods) provide Rodel AI, World Reroll and Better Tools for matching instances.

**AI assistance** is a growing focus: helping new players understand terms and errors, gather evidence for a specific instance and handle preparation, content, problems and skin creation within a clear scope.

Inside Minecraft, use `/rai` or the pause-menu sidebar for follow-up questions. Supported modpacks provide actual recipes, quest progress and handbook information. See [In-game AI](/en/docs/create/game-ai) for setup.

**Native UI** continues to develop around everyday tasks. Rodel UI is no longer bundled; its source remains a separate experiment. The other included mods do not depend on it, and the launcher does not automatically alter existing player installations.

## Advanced entry points

Alongside the native app, a command-line entry point supports scripts, diagnosis and external AI integration. Ordinary players can use the app and this guide without learning commands.

The optional game bridge supplies current game information and limited local-world operations. Servers remain read-only. Setup and in-game entry points are covered in [In-game AI](/en/docs/create/game-ai).
