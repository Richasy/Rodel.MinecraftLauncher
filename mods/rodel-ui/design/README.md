# Rodel UI 设计参照

`index.html`是用户认可的主菜单设计快照，含宽屏、800×560和640×560窄屏、明暗材质及边距标尺。正式游戏实现位于项目的`src`，HTML不作为运行时依赖，也不能替代Minecraft实机评审。

## 模组配置

Rodel UI 设置归模组列表中 Rodel UI 条目的原生“配置”动作。配置页使用 Minecraft 原生滚动列表和开关，页首说明重启生效，页尾固定保存与取消，关闭后返回触发的模组列表。各组开关及文件位置见[配置说明](../README.md#配置菜单)。

## 工作站 PoC

熔炉与工作台共用 178×212 的直角面板，header 高 24，方块与原版绿书图标为 12×12，标题适度缩小并垂直居中。小图标仍由原版模型与资源包渲染，仅最后的 16→12 缩小使用线性采样，避免最近邻缩小导致斜边不均；背包、原版 HUD 与方块纹理的采样不变。工作区、背包和快捷栏共用 8 单位左右内边线，背包标题从同一边线起。操作、背包和快捷栏各自成组。背包用低对比 3×9 棋盘格；快捷栏只画九个独立凹槽，以深槽底、上左阴影和下右细唇表达下凹，不在外面再套托盘或边框。

工作区输入格为 22×22，九宫格合计 66×66；背包格保持 18×18，结果井为 32×32，形成明确的操作层级。九宫格、18×12 箭头与结果框共用水平中心线，箭头两侧各留 6 单位；熔炉输入／燃料沿九宫格中列排列，火焰居中，箭头在输入与结果之间等距。物品保留原生绘制，扩大的是井及真实命中范围。操作区上下留白随网格扩展，不压缩背包或增加 header。石材边框具有程序绘制的分段接缝、内侧暗面与细高光；木框使用立柱、横梁接合线及低对比纹理线。结果描边与真实进度使用材质强调色。熔炉火焰由透明背景的像素轮廓绘制，按实际燃料余量从底向上裁切，不使用带不透明灰白底的原版进度贴图。

宽屏配方书为 148×212 的完整浅色侧页，与工作站上下对齐，间隔 6 单位，组合整体居中。搜索与筛选在 header，分类收进左侧窄列，二十个原生配方按钮排成四列五行，首行与操作区输入框顶边对齐，翻页随面板底部定位。搜索框取消黑底、斜体提示和阴影；分类、筛选和右键配方选项共用同一材质及状态层级。重新定位的是实际原生控件，搜索、分类、可合成筛选、翻页、右键选项与配方填入仍走原回调；绘制与点击共用真实几何。窄屏配方书独占中间，Esc 回到当前工作站。放不下完整工作站的短窗口使用原版布局。

棋盘格参考 [CozyUI+ 的公开预览](https://modrinth.com/resourcepack/cozyui-plus/gallery)。其公开仓库 `3c49bcbe9a98ebe0417bbcca77df6ae0f5524d15` 的 `SourceCode 源代码/005.psd` 和 ZIP 属于材质包素材。工作站表面使用代码与原版物品图案。

## 整体复核后的实施规则

最新反馈要求保留首屏布局，修正按钮的厚重边框，并审查整页内容分配。按钮通过唯一的 `ButtonSurface` 绘制浅立体表面：细外缘、上左受光、下右阴影和左上角小直角高光，按下时转为内凹；所有装饰位于原按钮矩形内，不增加第二层底座。禁用态去强调，高对比度关闭装饰。标题页只更新共享材质，不改变已认可的布局或尺寸。

页面审查按亲密性、对齐、重复、对比进行。返回按钮和标题/副标题作为同一个组测量；列表行的头像、字号、角色标签、操作按钮及点击区共同响应原生 GUI 预算。不得只缩字、保留旧测量和巨大的原生控件，或把编译成功当成视觉验收。

暂停菜单与自有首页/设置采用同一提示规则：完整文字按钮不弹tooltip，只为实际截断文本和纯图标用途提供提示。保留控件原始提示元数据和旁白；其他原生菜单的状态、校验提示及第三方配置保持各自语义。

资源包与数据包使用上方共享搜索、对齐的双栏标题/列表和下方拖放说明。两栏按未过滤模型的较大条目数取得同一自然高度，超出预算时滚动；过滤不使面板跳动。世界浏览、统计和进度树仍保留稳定内容视口，不能仅因条目少就一律收缩。布局密度由 `MenuDensity` 给出，所有最终尺寸仍跟随 Minecraft 的 GUI 缩放。

扩展显式接入边界见 [UI 复用设计](../doc/EXTENSION_UI.md)。第三方业务页不加入原版 Screen 白名单；通过共用表面和同源文字测量接入，保留自己的模型、预览渲染、输入与生命周期。

## 世界选择与新建（已获准按修订布局实施）

“游戏 / 世界 / 更多”移到标题右侧，释放正文高度。原生实现继续保留真实Screen、TabManager、字段对象、状态监听器和操作回调，实施状态见模块README及模块说明。下述设计稿自身仍无游戏或文件操作能力。

`worlds.html`、`worlds.css`、`worlds.js`提供两个独立页面，从主菜单“单人游戏”或评审工具切换。列表沿用模组/资源包管理器的条目语言：宽屏96行高、64图标、16内沿、24图文间距，名称18/说明14，只有选中条目填色；搜索、数量和条目外缘对齐。保留搜索、键盘选择、进入、编辑、重新创建和删除入口。新建按26.3实际的游戏/世界/更多组织字段，包含名称、模式、难度、命令、种子、世界类型、结构和奖励箱；相关控件右对齐，正文滚动、页头与操作固定。

世界列表只读加载忽略目录`.local\game-ui-design\worlds.json`及图标，来源为本机实际存档的有限摘要，不提交名称、图标或其他私人存档数据。新建的世界类型来自26.3客户端实际`world_preset/normal`标签，不把所有WorldPresets字段都显示为正常候选。缺少摘要或遇到未知候选会明确报错，不填造世界。明暗背景共用忽略目录中的Minecraft原版六面资源与Three.js，产品不再携带自定义全景；高对比度关闭背景。顶部工具支持1280×720、800×560、640×560、主题、空列表和暂停全景。

**HTML自身不接入Java或游戏存档。** 重命名、删除只改变浏览器内存，刷新恢复；进入、重新创建和创建只说明原生操作意图，不假装生成了世界。地形自定义、游戏规则、数据包和实验性功能只演示入口，子页面继续走原版。创建预览说明框不是拟加入游戏的额外确认步骤。

## 设置页候选

### 当前游戏实现（待视觉评审）

设置默认字体全字符雅黑优先，首页英文像素风格不动；所有控件整体**右对齐**，不把不同类型强行左对齐。tip只在实际文本trim或纯图标按钮时出现；focus border仅键盘输入模式显示，数据选中框另算。外层箭头只退出整个设置，子页在详情标题旁提供明确“返回”，只回真实父页。视频显示参数按窗口/全屏、帧率/同步、界面显示分组，真实显示模式用原生枚举工厂下拉；具体来源及原生生命周期见模块README。尺寸以实际控件及当前规范为准。

Java已对首页进入的原版设置及受支持`OptionsList`页面实施侧栏/详情布局，数据与控件来自游戏而非下述HTML目录。宽屏详情面板上限800设计单位，与208宽侧栏、28间隔整体居中；标签/控件间隔24，简短行上下各6，控件高52。宽屏正文与控件文字18、原生说明14；窄屏控件高48，正文16。

最新评审修订：布尔轨道52×28、滑块20×20、命中区104×44，采用方角WinUI式开关；普通选择宽160，不再撑大主手按钮。多选一弹层直接列出真实候选，文字块按条目实际高度垂直居中；使用独立GUI stratum和不透明底色，不让下层控件穿透。无说明的简短选择项连续至少四个时宽屏双列、列间32，窄屏依序纵排。主手另用两张160方形图片卡，实际选择以高亮边框表达。

表单右侧控件靠行右缘，描述使用剩余宽度，消除闲置右栏；不显示“完成”，不预留无用底部操作区。鸣谢/Mod Menu放右上角。首分组高36、后续56，标题位于分组底部以贴近下属字段；说明完整内联，所有自有设置悬浮tip关闭。侧栏与正文轨道从视口getY开始，不使用已经包含滚动偏移的scrollBarY重复计算。

详情头标题按实际单/多行文本块垂直居中，原版辅助功能指南按钮位于头部右侧。主手标题在两卡上方居中，图片区域横向填满8单位内沿、等比裁剪，文字下方也留8。侧栏滚动位置属于设置会话：切页/返回恢复原偏移和选中分类焦点，不允许初始焦点自动把侧栏拉回顶部；缩放保留设计单位偏移。

滑块使用独立轨道和真实数值，禁止重复“标签：值”。其他字段保持单列，共享标签与控件对齐线。选中分类用上左暗缘/下右反光表达内凹，标题、正文、说明用字号和对比建立层级，不额外编造说明。

语言/按键绑定保持原生列表控制器并现代化；资源包与模组浏览使用独立现代页面，不能嵌入设置侧栏。搜索、列表、选择、配置/提交由真实原生控制器负责；第三方自有配置仍完全不换肤。原生警告/确认及鸣谢在限定入口应用同一表面，回调与取消逻辑不变。浏览行图标四周留出呼吸感，名称/描述共用文字起点，不做装饰性缩进；描述更小且使用真正常规字重，正文与标题保持层级。主菜单已认可，新增页面仍待实际视觉评审；游戏截图与行为记录仅存本地`artifacts`及验证目录。

最新间距评审：模组搜索工具行的顶部与两侧内距一致；条目外框左缘与搜索框/数量说明对齐，右缘与筛选按钮对齐，真实列表视口和命中范围同步。图标和文字之间单独留白，小型tag不得与名称争夺层级，边框内必须留出独立呼吸空间。资源包工具行与下方两栏共用列网格，左列搜索、右列常规字重说明，按实际文字块垂直居中；窄屏改为上下排列。结构面板和输入框使用等厚细线，不在顶部叠加粗线；按钮仍保留认可的微立体材质。资源包条目与模组条目统一：行高96、图标64且四周留16、图文间隔24、标题18/描述14，名称和描述共用文字起点；选中时有细边框，键盘焦点另用focus色。绘制内距与原生动作热区同步，不允许图标贴着选中背景边缘。

### 已撤回的HTML设置目录

**20:02需求纠正：手写设置目录已撤回，控件已停用，仅保留布局参照。** 真实配置值不等于游戏实际暴露的选项，不能用本页列表、手写枚举/范围或options.txt字段生成产品设置。此前的HTML交互检查只说明原型可操作，不代表满足游戏设置覆盖要求。

后续必须从26.3原版实际创建的Screen/OptionsList/OptionInstance控件及其回调生成界面，保留校验、延迟提交、onClose/removed保存语义。用户20:13最终确定第三方配置一律原样打开，包括使用原版控件的页面；只做Rodel风格的Mod Menu入口，不按配置框架或控件类型转换/换肤，不扁平化或猜测设置结构。Fabric没有统一涵盖所有模组配置字段的API，Mod Menu21.0.0已支持26.3，当前实机入口直接打开其原生ModsScreen。

新增`settings.css`和`settings.js`，从主菜单“设置”、右下语言/辅助功能图标或评审工具进入。设置页承接启动器的左分类/右详情、分组设置行、独立滚动和选中内凹；内容改为界面、画面、声音、操作、语言、辅助功能、聊天、资源包、隐私与在线、关于。窄屏保留侧栏，将详情行控件放到说明下方。

此设置页仍是**待评审HTML设计，不是已接入游戏的新设置页面**。控件初始值来自本机`.local\game-ui-design\settings.json`的真实评审实例配置快照；缺少或读取失败会明确报错、禁用未读取项，不补造默认值。修改只留在浏览器内存，切分类保留预览值，刷新即清除，不写入options.txt。版权入口归“关于”，原版复杂页面入口只演示导航说明，不伪造已执行结果。

快照只保留选定的界面、画面、音量、操作和隐私设置，不复制整个游戏配置或身份信息；本地导出入口为忽略目录中的`scripts\verification\game-ui\export-settings.ps1 -GameDirectory <评审实例目录>`。正常模组构建不依赖这些设计文件或快照。

当前规则：

- 保留原版动态全景，不用启动器静态壁纸替换。
- 主操作左下、语言/辅助功能/主题三图标右下；宽屏同一组左/下或右/下外距为72，窄屏为32。
- 窄屏次要操作在顶部两列；标题、说明、版本和主操作共用左对齐线。
- 主按钮参考启动器双层按钮面，上左亮、右底暗、短影，按压变暗内凹但外框稳定；不做粗银框和黑厚底。
- 只在标题上方保留JAVA EDITION，不显示RODEL或重复底部版本；版权访问归设置。
- 中文及中文标点使用微软雅黑真实粗体，英文/数字保留原版像素字。HTML浏览器字体只作排版参照。

浏览器全景预览使用仓库根忽略目录`.local\game-ui-design`中的六面原版游戏贴图，以及`.local\design-tools`中的three.js。这些是本机开发资料，不随Git分发；缺失时页面明确报错，不能用静态图冒充动态背景。可以从仓库根启动本地静态HTTP服务，再访问`mods/rodel-ui/design/index.html`；正常模组构建和运行均不需要这些文件。
