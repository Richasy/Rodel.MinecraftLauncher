# Rodel UI

**已撤出启动器内置列表和正常打包，保留为独立实验模块。其它第一方模组不再引用、反射或继承本模块的主题／字体／面板。**

由启动器内部持有并随包提供。玩家在“内容 → 模组 → 内置模组”勾选Rodel UI，点击“安装所选”；Fabric API自动补齐，安装时不访问社区。下文Gradle命令用于开发构建。

Minecraft Java **26.3、26.2、26.1.2、1.21.11 的 Fabric／Quilt／Forge／NeoForge** 客户端界面模组。发布版本统一为0.0.1，各游戏目标分别构建。菜单与设置复用 Rodel 的直角面板、微立体按钮与焦点边框，沿用 Minecraft 原版动态背景和资源包。各目标及 PoC 范围见[兼容性矩阵](../COMPATIBILITY.md)。

## 配置菜单

在游戏里打开 **模组 → Rodel UI → 配置**。Fabric／Quilt 使用 Mod Menu，Forge／NeoForge 使用加载器自带的模组列表。各项默认开启，可独立关闭。

| Minecraft | Fabric／Quilt 验证使用的 Mod Menu 版本 |
| --- | --- |
| 26.3 | 21.0.0 |
| 26.2 | 20.0.3 |
| 26.1.2 | 18.0.2 |
| 1.21.11 | 17.0.1 |

| 开关 | 控制范围 | 配置键 |
| --- | --- | --- |
| 游戏主菜单 | 标题页布局和主题切换按钮 | `titleScreen` |
| Minecraft 选项 | 原生选项、其子页及从选项打开的资源包页 | `settings` |
| 世界管理 | 世界选择、新建、编辑、相关对话框及加载页 | `worlds` |
| 暂停与多人菜单 | 暂停、多人、Realms、统计和进度页 | `menus` |
| 模组浏览 | Mod Menu 列表与详情的 Rodel 外观 | `modBrowser` |
| 字体平滑 | Rodel 系统字体的 8 倍字形采样和线性过滤。关闭后使用 4 倍采样和游戏默认的图集采样 | `fontSmoothing` |

保存后重启 Minecraft 生效。取消或按 Esc 放弃这次编辑并返回模组列表。设置写入当前实例的 `config/rodel-ui.properties`。Fabric／Quilt 未安装 Mod Menu 时，可在退出游戏后创建或编辑该文件，例如写入 `fontSmoothing=false` 关闭字体平滑。

## 熔炉与工作台 PoC

26.3 的 Fabric 兼容包在普通熔炉和工作台上绘制 178×212 直角面板、棋盘格背包、九格下凹快捷栏和 32×32 结果井。工作输入格为 22×22，九宫格、箭头与结果井共用中心线，背包格保持 18×18；放大格子的命中与悬停同步。两侧内距为 8，header 高 24，快捷栏没有额外外框。熔炉采用炭灰与琥珀色，工作台采用浅木色，材质接缝与细高光均由程序绘制；像素火焰按实际燃料余量显示，背景透明。紧凑图标单独过滤缩小，背包物品仍用原版采样。绿书按钮打开原生配方书，宽屏采用与工作站等高的完整侧页，内置分类列、四列五行配方和底部翻页，窄屏居中并可按 Esc 返回。外观由 `src/workstationPoc` 按原生 GUI 整数坐标绘制，真实搜索、筛选、配方填入、物品和熔炼状态沿用 Minecraft。野外 HUD、其它工作站、容器、书籍和浮层使用原生外观。

## 安装

26.x游戏实例需要Java25，1.21.11需要Java21；Fabric Loader为0.19.5及以上，Quilt已验0.31.0-beta.4，均需匹配目标的Fabric API。四版本原生包均已分别实测，确切Forge／NeoForge版本见兼容性矩阵，不携带Fabric入口。启动器自动选择对应目标；开发默认`build\libs\rodel-ui-0.0.1.jar`仅用于26.3 Fabric／Quilt，其他Fabric目标通过`-Pminecraft_target=26.2`等选择，产物在`build/targets/<版本>/libs`。随包脚本仅生成UI所需运行JAR，常规模块`build`仍生成源码归档。Forge／NeoForge由`../loader-build`按相同`-Pminecraft_target`打包，低版本只构建UI；产物位于各加载器的`build/targets/<版本>/libs`，26.3仍为`build/libs`。1.21.11原生包共用上游Mixin注解编译及官方命名空间，保留格式75的资源范围声明。不要安装sources JAR或混用不同Minecraft目标。

本项目位于启动器仓库的`mods\rodel-ui`，使用自己的Gradle构建，不加入.NET解决方案，也不依赖启动器进程。为兼容已有配置与资源，内部mod ID和资源命名空间仍保留`rodel_game_ui`；显示名称与产物统一为Rodel UI。

共享按钮表面集中在 `controls.ButtonSurface`：细外缘、浅立体明暗及左上角小直角高光，按下时转为内凹，禁用态为灰色。布局和输入矩形由原控件所有者决定，绘制器不添加外部底座或额外命中区。显式的扩展 API 与 Artifact Blueprint 接入设计见 [EXTENSION_UI.md](doc/EXTENSION_UI.md)；它提供按钮表面及同源文字测量/裁切/绘制，尚未迁移 Artifact 的业务页面。

原生按钮的文字、图标、开关与下拉内容由 `controls.NativeButtonRenderer` 绘制；`AbstractButtonMixin` 只保留原生绘制接入、当前页面归属及主手选择等专属回调。绘制继续读取真实控件的启用、悬停、焦点和值，不创建替代按钮或接管输入。

重排和绘制原版主菜单控件，保留原版单人、多人、Realms、好友、选项、语言、辅助功能与退出操作，以及权限、禁用原因、键盘导航和旁白。版权入口归入设置页既有的鸣谢/版权按钮，保留原版目标页面。

标题页在原生初始化及Fabric `AFTER_INIT`结束后适配，普通追加按钮保留原对象与回调。发现未知输入控件、独立绘制项、额外内联文字操作或布局容纳不下的按钮时，整页保留原生布局、绘制和输入；现代化后控件树再次变化时，恢复原控件的几何、提示和回调，移除自有主题按钮并恢复版权入口，不重建Screen或吞掉新控件。第三方后来修改的值继续保留，第三方TitleScreen子类原样运行；从回退首页直接打开的原版设置保持原样；Mod Menu的`minecraft`配置工厂例外仍按下文处理。此兼容路径不等于任意第三方自绘/布局逻辑均已实测。

## 世界选择与新建

从自有主菜单进入的原生`SelectWorldScreen`与`CreateWorldScreen`使用独立现代页面。世界列表复用原版异步加载、过滤、图标及验证、旁白、选择与全部操作回调；条目、缩略图、内距及字号使用共享密度角色，紧凑时为32原生GUI单位行高、20单位图标和6单位内沿，图标的原生悬停/点击坐标同步映射。原版提供的锁定、版本、备份、损坏及符号链接处理仍保留，不根据文件名或锁文件的存在自行判断是否可进入。

新建页将原生“游戏 / 世界 / 更多”切换放在标题右侧，不再单独占用正文行。字段来自实际Tab创建的控件及其原始状态监听器，复用原版`WorldCreationUiState`、实时预设候选、禁用条件与创建回调；没有新造世界设置模型。原生编辑框、模式/难度/世界类型选择、开关重排进独立滚动正文，底部只保留创建操作，左上返回执行原版取消与临时数据清理。返回子页面时保留当前分类与原生草稿，移除的分类控件不会继续接收输入。

创建、进入、编辑、删除、重建、备份和确认仍走原版流程；不增加HTML稿中的设计说明确认框。原生EditWorldScreen已有现代编辑页，保留构造时创建的名称框、保存/取消、重置图标、世界/备份目录、备份及优化入口；不自己取得存档锁或复制重命名/备份逻辑。编辑面板按内容高度收口，四边使用相同内容内距，窄屏滚到末尾也保留底部内距。超平坦地层/预设、生物群系选择、实验确认/详情以及限定的数据包失败、存档恢复、文件修复/中止页面已有各自原生适配；仍不宣称全部游戏界面已换肤。`design/worlds.html`只作为布局参照，不作为产品数据或运行依赖。

自有世界流程的准备、备份等待、优化确认/实际进度、地形加载和关闭窗口保存等待共用主题对话面与方块脉冲/进度动画，延续当前真实全景，不闪回原版背景。无可用进度时只显示不定进度；优化取原WorldUpgrader的状态/计数，地形取LevelLoadTracker，服务器生成结束不冒充客户端已就绪。原生tick、旁白、完成检查、存档关闭与进度屏stop清屏分支保留，不增加取消或跳过准备/落盘。GenericMessage/LevelLoading自有背景覆盖也需取消，避免与统一背景重复执行每帧唯一的blur。用户明确要求的Fabric缺失内容警告和详情是限定例外，保留真实缺失项、详情入口、备份/继续/取消及其原始回调，不扩大到其他第三方配置。

“更多”中的游戏规则、实验性内容和数据包已有独立现代子页面。规则仍使用原版注册表生成的分类、搜索、原始控件、规则副本和数值反序列化校验；名称、说明与默认值来自实际GameRule，非法数值显示错误状态并由原版禁用完成，取消不提交副本。实验项直接复用原生特性包开关及描述、风险说明和提交/取消回调，不手写实验清单。数据包复用既有资源包管理器的双栏/窄屏上下布局及条目样式，保留真实包模型、兼容性确认、选择/优先级、拖放、目录监视、应用与重载；此页“完成”和Esc仍按原版提交，不能擅自改成丢弃。

“更多”使用与设置一致的左侧导航、右侧内容，顶部保留游戏/世界/更多。右侧始终是各自原生Screen，不把多个Screen嵌套渲染或复制其业务；共用导航只负责调用原始入口、完成/取消及真实TabManager。规则/实验未应用的修改在切页前可选择应用、放弃或继续编辑；无效规则不提供应用选项，继续编辑不会重建Screen或丢掉原始输入。数据包切页仍执行原生提交/验证。明确完成或返回后回到新建主表单；宽度不足时详情字段改为上下布局，原生输入与滚动热区同步。

设置与世界创建侧栏共用SidebarNavigation绘制器，不再各自维护选中面、四边内凹、字体、悬停和键盘焦点；导航背景透明，不额外套侧栏面板。数据包与资源包共用列表面板布局：共享搜索在双栏上方，对齐的栏标题和列表在中间，拖放说明紧随面板。两栏按未过滤模型的较大条目数保留共同自然高度，超出可用预算才滚动；搜索过滤不改变预留高度，原生条目和滚动热区仍同步。可用/已选业务双栏不被误改成模组列表/详情模型。

这些页面只在自有世界创建流程内应用外观，经过原生确认/加载中间页仍保留来源；回到标题或新的世界根页面不继承旧子页标记。其他游戏规则入口、第三方配置不被接管。返回父页保留创建分类与草稿，布局缩放同时转换输入与IME坐标，不复制或重建业务模型。

## 原版设置

从本模组主菜单进入的设置使用“左侧分类 + 右侧详情”。分类来自实际原版导航按钮；支持的原版`OptionsList`页面直接复用游戏创建的控件、`OptionInstance`记录、取值、禁用状态、提示与回调，不另造配置系统。切分类执行原版关闭/保存生命周期，当前游戏页面仍是原版Screen，保留视频设置的专用处理。

标签和原生说明在左，实际控件在右；表单使用详情区的完整宽度，数值控件只显示真实值，不重复标签。连续四个及以上无说明的简短选择项在宽屏采用紧凑双列，窄屏按原顺序纵向排列。布尔项使用方角轨道/方形滑块，多选一使用下拉框，候选项来自原生CycleButton的实时列表与格式器，选择只触发一次原生回调。弹层支持键盘方向键、确认、Esc、滚动和点击外部关闭，条目文本按实际行高垂直居中；不替换当前原版Screen。

各类控件整体右对齐，滑块轨道与右侧值保持紧凑间距。视频设置按窗口/全屏、帧率/同步、界面显示组织真实控件；全屏、独占全屏和分辨率连续排列。分辨率与刷新率由原生整数范围生成原生枚举控件，复用同一OptionInstance、校验、格式器、监听器及模式切换生命周期，不列举猜测的显示模式。“游戏界面缩放”显示“自动/4 倍”等真实倍率，并统一影响Rodel菜单/设置、HUD、物品栏及使用原版GUI缩放的模组界面。

自有首页/设置/暂停菜单的悬浮提示只用于**实际截断的文本**和**纯图标按钮**。完整文字按钮不再沿用原生悬浮提示；设置的真实说明完整内联展示，不重复弹提示，原生提示元数据仍保留供取值和无障碍使用。其他原生菜单的状态与校验提示、第三方配置不受此规则影响。焦点边框仅在键盘输入模式显示，不清除控件真实焦点；数据选中边框仍保留。分类显示去掉原版末尾省略号。移除多余的“完成”，更改直接走原版设置回调；不强制提前应用原版本就需要延迟或重启的设置。分组标题上方留白大于下方，滚动条轨道固定在各自视口。

现代上下文内的原生EditBox保留原输入、选择、光标、格式器、responder及IME流程，只在绘制时关闭正文、补全文字和文本光标的像素阴影；placeholder使用另一个默认开启阴影的原生重载，也单独关闭。不能只调用setTextShadow(false)便假定placeholder已处理，更不能以全局修改字体或重画输入内容代替原生编辑框。离开现代上下文后仍按控件本来的阴影设置绘制。持久选中与瞬时按钮按下使用不同色角色：Light选中为浅砂金，不能拿较深的按压底色长期填满列表条目。

输入框默认正文色随当前主题Ink、默认只读/提示/补全文字随Muted，仅在绘制时映射原生默认色，不永久改写控件字段或覆盖自定义颜色；规则校验红色等语义色必须保留。不能遗漏世界列表、包管理等直接使用原EditBox而未经过设置页缩放包装器的入口。

切分类、返回、重建或缩放时保留侧栏滚动位置；当前分类按真实页面及父级归属更新，不只记住最后点击的tab。外层左上图标只退出整个设置区，鼠标/字体/按键绑定等子页在详情标题旁显示明确“返回”，只回实际父页并执行原生保存回调。详情页头标题垂直居中，辅助功能指南等原版操作在页头右侧，不占滚动正文。主菜单语言/辅助快捷按钮也进入同一现代设置壳。

主手设置为左/右两张方形图片卡，点击或方向键选择，边框反映真实HumanoidArm值，标题在两卡上方居中。图片等比裁剪并填满卡片内沿，内容四边统一留白。两张512×512贴图由用户指定的Azure ImageGen生成左手母图后镜像派生，采用原创通用方块风格，不读取玩家皮肤、不复制游戏角色贴图；普通构建与运行不依赖Azure。

目前覆盖设置首页、受支持原版`OptionsList`页面，以及语言和按键绑定的原生列表。语言搜索、选择、资源重载和应用仍走原版逻辑；搜索框只做缩放输入/绘制适配，转发字符、IME预编辑、键鼠及旁白到原EditBox。按键绑定保留原KeyMapping、重绑输入、冲突计算和重置，冲突说明内联。资源包使用下述独立页面；尚未完成全部游戏界面覆盖或用户视觉验收。[HTML设计稿](design/index.html)的手写目录已撤回，仅作布局参照。

## 独立资源包与原生提示页

资源包管理独立成页，不挂入设置侧栏。保留原生可用/已选列表、真实搜索、包模型、兼容性确认、文件拖放和监视器；只调整双栏布局、行内图标、描述、动作与滚动条。窄屏上下排列。标题区“返回”和内容下方的原“完成”按钮均执行原生完成回调，保留提交、关闭监视器与资源重载，不以直接切屏代替。原生列表标题改为固定栏头，避免滚动时重复出现；包图标的启用、停用和优先级热区映射回原生输入。

从自有UI进入的限定原生确认/警告页面、好友设置授权警告、鸣谢/版权及遥测说明采用统一表面；保留原生按钮、延迟启用、复选框、链接和取消行为。不是对任意Screen全局换肤，也未接管所有在线社交页面。离线身份下遥测入口的原生禁用状态不绕过。

Realms的通用错误（包括会话失效）、原生确认、版本不兼容及家长许可提示也在限定范围内；原生错误/权限信息、按钮和返回回调保留，不绕过认证。手工绘制的错误文字以真实Component接入居中提示卡，保留错误颜色并使用雅黑常规正文。Realms主列表、管理、邀请、备份及其原生子流程采用下述菜单适配；离线/虚构数据的界面审阅不代表真实账号、购买、上传/下载等在线业务已经端到端验收。

## 菜单链路与游戏内页面

菜单现代化按页面职责重新编排，不以通用换材质和大面板作为主要页面交付。暂停页使用真实游戏画面、自然高度卡片、主继续按钮、进度/统计、设置/世界、社交及追加模组操作分组，保存退出独立固定；宽度或高度不足时只滚动操作正文。真实原按钮、启用状态、好友请求数、举报草稿、音乐通知及原始回调保留。统计页有独立页头/标签和统计表，数值仍取原StatsCounter与原格式器。

进度页使用独立页头/返回、实际原生进度分类侧栏及自适应树视口；空状态采用居中图标/原版提示，不保留灰色像素窗口和黑底。节点、连线、实际解锁/进度、旁白/说明、监听与服务端选择/关闭通知仍来自原ClientAdvancements及AdvancementTab/Widget。放大的视口同时用于裁剪、首次居中、滚动范围、鼠标命中、拖动及提示范围，缩放窗口保留树的观察中心；不伪造进度或手写分类目录。

世界选项按真实原生控件生成左侧名称/说明、右侧值/开关/下拉，难度锁与选择器成组；游戏内规则保留服务器数据、权限、等待及应用流程。进入设置继续复用同一设置外壳，不因入口是ESC而退回另一套设置。多人页区分工具行、真实服务器列表及选择后的操作；添加/编辑/直连是按实际输入组成的自然高度表单。好友按真实好友/请求标签、列表和添加区布局；Realms主列表与管理正文分别编排，管理宽屏使用左侧真实标签、右侧原生正文，窄屏调整导航。没有虚构服务器搜索、复制好友/存档模型或替换远程任务。

世界选项重排原生外层分组时移除其旧的8单位单元格padding，并按ScrollableLayout实际预留的滚动条空间测量内容宽度；不能只扩大背景框或让滚动条/控件越过面板内距。Realms列表的版本与真实状态标识共用单行右对齐布局，提示命中范围与实际小标识一致，开/关/到期判断仍由原生流程提供。

原生页面/行的自绘内容、头像、世界槽预览和业务生命周期保留。新菜单共有画布同时处理渲染、鼠标、滚动、拖动距离、IME和原生延期绘制，tooltip保留自身背景/文字对比及验证原因；原生下拉候选来自当前CycleButton，外部未绘制名称的控件保留完整原消息。事件注册但非renderable的输入框也参与布局，不改变其手工绘制所有权。

好友和Realms的原生图标操作使用统一线条图标及按钮表面，保留实际SpriteIconButton/ImageButton、loading和原回调，不把小图标按钮的文本裁成省略号。滑块完整替换轨道/滑块外观，值仍由原控件实时提供并紧邻轨道；Realms设置与世界槽选项共用左名称/说明、右控件的表单结构，地区偏好保留动态当前值/服务质量图标并将原选择按钮置于右侧，ComboBox弹层与触发控件等宽。禁用accent使用灰色表面；图片预览采用主题边框、无像素文字阴影，订阅说明使用主题表面而非原黑底。举报中的玩家名称和Realms在线名称按当前主题强调色显示，避免浅色背景上的荧光黄/绿。当前身份使用纯平底色、无描边/投影、常规字重tag；旁边独立图标按钮保留原生op/deop操作和“设为…”提示，移除按钮保留完整水平padding。tag本身不注册点击动作，原权限条件与旁白不变。

游戏内菜单、统计、设置和确认默认保留真实游戏画面，遵守原生模糊选项并保留字幕。主菜单及原生使用全景的等待页沿用游戏背景。工作站 PoC 独立于菜单改造。

Rodel与HUD、原版及使用游戏GUI缩放的第三方页面共用Minecraft原生“界面缩放”，不再按窗口尺寸额外放大/缩小Rodel画布。设计单位仅作固定的2:1原生GUI单位换算，最终像素倍率由游戏提供；窗口空间不足时调整排布/滚动，而不抵消玩家选择的倍率。默认使用原版自动（0）；玩家已保存的手动选择保留。原视频设置的回调、保存与自动随窗口调整行为不变，第三方页面的外观/交互仍原样保留。

世界浏览/表单/编辑、设置侧栏与选项、包管理、通用对话及游戏内菜单共用`MenuDensity`语义尺寸。低GUI预算下使用更小的标题、正文、控件、行与内距，而不是重新缩放整个画布；主界面保留单独已认可的密度布局。缩放输入使用保留原`EditBox`的`NativeTextBox`，鼠标、光标选择、键盘和IME预编辑同步变换，原responder、校验色和禁用状态不被替代。模组原生内容图标与进度树数据节点不一律缩成控件图标。

自有微软雅黑/Segoe UI字形的oversample从4提高到8，仅`rodel_game_ui`命名空间的灰度字体图集使用原生缓存的线性采样；原版像素字体、彩色字形和图像材质仍使用原有采样。继续复用26.3原生字形缓存/纹理管理，兼容现有Vulkan路径，不引入旧OpenGL字体渲染器。这不是旧版[bre2el Smooth Font](https://www.curseforge.com/minecraft/mc-mods/smooth-font)的移植：官方资料描述清晰缩小/分数缩放、高分辨率及灰度字形图像管理，但未核实可公开复用的实现源码，不能据此宣称其具体算法或本模组帧率收益。

互斥操作组只突出一个有明确语义的推荐操作，不把所有并列按钮涂成accent。备份后优化、恢复、应用/完成和举报提交按原生动作确定主操作；危险的直接继续、删除等不因排在前面而获得强调。推荐操作不可用时保留原生禁用状态，不把其它操作自动提升为主操作；普通导航/候选选中仍使用独立选中色。

好友/Realms无法用真实账号审阅时，可按用户授权在隔离实例中加载验证专用伴随模组；原生界面使用强类型虚构DTO，持续显示MOCK标识，F8返回预览目录。真实在线写入、举报、状态发布和外部账号/购买链接被拦截。伴随模组、虚构身份、模型和预览入口只在忽略的验证工具/独立实例内，正式Rodel UI不包含这些数据或开关。

Windows的目录打开有一处限定兼容处理：现代页面的原生目录目标仍来自游戏/Mod Menu，但现有目录的`file:` URI使用系统`explorer.exe`及独立路径参数打开，避免本机原SDL文件URI通路失去响应。资源包和模组目录共用此处理；不经过命令解释器。启动失败记录具体错误并显示原生通知。网页链接、普通文件、第三方自有配置页及非Windows平台仍走原版路径。

## Mod Menu 可选入口

安装适用于26.3的[Mod Menu](https://modrinth.com/mod/modmenu)后，设置页右上方会出现Rodel风格的“模组设置”入口，与原版“鸣谢与著作权说明”并排，不占分类栏。它通过公开API进入独立现代模组浏览页，复用Mod Menu真实列表、搜索、过滤、选择、详情、链接与配置工厂，不统合进设置侧栏。**各第三方模组的配置、字体、交互和保存均原样保留，即使使用原版控件也不转换**。用户明确例外的Minecraft自身配置采用现代设置：仅在公开工厂请求ID为`minecraft`且结果为确切原版OptionsScreen时标记所属上下文，不按控件外观推断。现代化浏览外壳不代表接管Mod Menu自有配置页。

未安装时不显示入口，也不会加载Mod Menu专用API类。当前编译/实机对照版本为21.0.0，依赖是`compileOnly`，不打包或强制安装Mod Menu。Mod Menu自身添加的主菜单按钮也保留原有回调，在其初始化完成后纳入首页布局，避免错位或被覆盖。没有图形配置页的模组仍由Mod Menu按其原有规则展示，不为它生成表单。

本功能只改变浏览外壳及配置入口，不扫描配置文件或尝试转换第三方表单。图标、标题和描述保留一致内距，名称/描述共用文字起点；仅真实子模组保留层级缩进。配置按钮采用普通操作材质，不作为启动主操作。

底部半明半暗图标切换明暗材质，游戏主题偏好保存在实例的 `config\rodel-ui-theme.txt`。读取失败会记录日志并提示，使用浅色；保存失败保留原主题并提示。独立手工启动仍可显式指定初始主题；游戏内再切主题后，进出设置或重建页面不会反复套用初始值而回跳。游戏内的高对比度设置优先于动态背景。

## 游戏背景与材质

不提供自定义全景、CubeMap替换或实时壁纸同步。标题及无世界菜单沿用Minecraft原版动态背景；游戏中的菜单继续使用实际世界、原生模糊与遮罩。资源包仍通过Minecraft原生资源生命周期生效。启动器自身壁纸图库独立保留，不再注入游戏 UI 主题参数。

旧游戏内拟物层的 45 张材质 PNG、采样元数据和准备脚本已移除。当前熔炉与工作台使用程序绘制表面，复用原版物品图案，不随包携带工作站背景图片。GUI 几何、物品和字体继续使用游戏原生倍率及各自采样。

界面按本项目的[设计稿](design/index.html)实现，布局使用固定2设计单位/原生GUI单位，跟随游戏实际GUI视口响应重排，而不是强行把窗口拟合为1280×720画布。主界面将横竖布局与密度分开：横向窗口保留左下主区/右侧操作卡，原生自动倍率较高、GUI空间较少时使用更紧凑的字号、按钮、图标和面板；不因为逻辑视口小便改成上下堆放。真正窄长比例才采用上下两区/两列操作。绘制、图标、文字、原生输入和IME共享游戏倍率；不强制覆盖玩家已保存的GUI设置。右下角为语言、辅助功能、主题图标，主操作在左下。原版字体的像素字形与浏览器参照仍有正常差异。

## 字体

用户授权的 Artifact Blueprint 字体兼容现已接入：仅对该模组七个确切自有页面替换默认字体，正文使用常规字形，bold 使用真实粗体；字体测量、换行、绘制和原生 EditBox 共用同一字体管线。不将这些页面加入现代布局接管，不改变 GUI 缩放或输入坐标，建筑蓝图也不依赖 Rodel。安装旧 Rodel JAR 不包含该兼容。范围、实现与验证边界见 [建筑蓝图字体兼容](doc/ARTIFACT_BLUEPRINT_FONTS.md)。

主菜单中文和标点使用本机Windows的**微软雅黑粗体**（`%WINDIR%\Fonts\msyhbd.ttc`），8倍采样，英文数字仍保留原版像素风格。现代设置与独立浏览页的默认字体统一使用雅黑，覆盖英文、数字及原生输入的绘制/测量；雅黑缺字时优先用系统Segoe UI回退，再走Minecraft原版字体链。标题/正文与次级描述分层：描述使用更小字号及真正的常规`msyh.ttc`/`segoeui.ttf`，不是对粗体文件关闭bold标志。不使用游戏伪粗体重复描字；除上述明确授权的建筑蓝图例外外，不改变第三方配置字体。

虚拟画布的原生编辑框、IME预编辑和系统候选区共享缩放/平移；候选区域按原生left/top/right/bottom端点转换，不误当宽高。既有菜单的输入变换仍限定当前拥有现代样式上下文的页面；上述建筑蓝图例外只增强字体，不引入输入坐标变换。

字体通过限定资源ID的读取钩子直接从系统字体目录打开，不复制字体、不将微软字体文件打进JAR。其他资源仍走原版读取路径。缺少Windows或字体文件时，Minecraft字体加载器记录具体错误，并由字体链回退到原版，不能将回退当作微软雅黑已生效。此前的中文像素字体候选已撤下。

## 构建

设置 `JAVA_HOME` 为 JDK 25，然后在本目录运行：

```powershell
.\gradlew.bat build
```

使用 Minecraft 的 `GuiGraphicsExtractor` 和原版渲染管线，不直接调用 OpenGL 或 Vulkan。渲染后端由游戏选择；可在启动参数中使用 `--graphicsBackend vulkan` 明确选择 Vulkan。本模组不静默更改玩家的渲染设置。

动态背景沿用游戏本身的绘制管线与原生资源系统，不依赖启动器进程或`design`目录。材质参考仓库根目录`design\prototype.css`的`surface`/`launch-button`/`button-face`和`design\themes.css`的Light规则：上/左亮边、右/底暗边与短影，按压变暗内凹但保持外框尺寸/位置，不用粗银框或外凸黑厚底替代。认可稿已作为本项目设计快照迁入，不要求主菜单运行时读取HTML或共享启动器控件。
