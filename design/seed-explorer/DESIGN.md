# 实例世界地图 · 设计审阅稿

## 地表可辨识度

地表地图以实际顶面材质、草木染色与相邻高度表现地貌；群系示意色只属于群系层。颜色不能按整个森林区域统一染绿，水面不能抹掉真实水色与水深。近景需要辨认树冠、山坡、陡坎与岸线；远景保留快速预览，补细节不改变视野或移动已有图钉。未知区块透明，不用缺失高度制造假断崖。绝对海拔不作为统一明暗，平原与同材质的高台保留相同底色。

素材、植被和高度均来自所选数据源，不从参考截图绘造或随机摆树。原生与导出共用着色，加载中保留有效瓦片；实际生成成本及适配器能力由Core承接，不增加玩家需要理解的开发参数。截图验收须区分真实保存地图、原版生成预览和HTML固定样本，不能由示意图通过推定实际渲染完成。

缩放后，存档、预测与历史瓦片先合成为同一套世界坐标对齐的显示采样网格，缩小时不能留下局部高清补丁。整个视野按可用覆盖统一细化，当前缩放级别的新结果覆盖历史重采样结果；再次放大可恢复仍在缓存中的原始细节，显示采样不得破坏源图或伪装成新的地图数据。当前视野计划中的瓦片保留在缓存，容量压力只淘汰非活动历史。存档修订后台刷新时保留同一存档与生成配置的上一帧有效地图，直到新修订细图覆盖完成；该保留画面只用于显示，不参与当前修订的分析与导出。存档实况在每个采样层先发布全部可读存档瓦片，再等待未探索区域的原版预览；粗层覆盖完成后才细化。取消后的迟到预览不能回填旧视野。

实例世界的近景细化与输入种子复用相同的原版真实地表采样：支持该能力的运行时在地表瓦片跨度不超过128格时，读取实际顶面、树冠、染色、水色和水深，不能一直以群系图例色拼接真实存档。粗预览保持快速铺图，远景、切层及未提供该能力的旧适配器继续按基础预览的能力呈现，不把装饰生成扩大到无界远景。

来源／世界／玩家定位共用地图上下文，不设第三排工具栏：地图内容及视图合入输入行，玩家入口归地图覆盖层，版本／种子及复制归footer。整合包的世界生成与地图兼容留待后续。共用视觉与原生边界继续以[当前设计规范](../DESIGN.md)为准。

## 基线与范围

先以主分支`637eb39`的实际控件树对齐HTML：独立窗口及应用图标、标题栏“查看地图／筛选种子”、单行42 DIP输入栏、地图左上悬浮工具、右侧缩放／出生点／原点、右下比例尺与固定底部状态栏。保留现有筛种侧栏、收藏入口与结构子页，不增加独立地图产品或新的主侧栏项目。标题栏和窗口按钮仍由Sprout／Windows承接，HTML里的caption只用于示意。

新的世界来源复用同一地图工作区。正式产品入口继续保留头像菜单；内容／世界管理的单个世界操作可增加“查看地图”，明确点击后打开独立窗口并带入该实例和存档。直接打开探索器只恢复选择与草稿，不自动读图或生成；通过明确的“查看地图”操作打开某个世界可直接执行该次读取。

审阅HTML保存在仓库外，不进入产品构建或成为正式文档依赖。它包含“当前App基线／世界地图方案”对照，以及运行、离线、数据桥关闭、断线、跨维度、不同世界、缺少位置／种子、刷新失败和空列表场景。地图沿用已有26.3原版固定样本；实例、已保存区块轮廓、玩家建造和位置是模拟数据，不能当作对应存档或其他版本的真实结果。

## 输入来源与地图内容

“查看地图”顶部增加“输入种子／实例世界”来源选择。输入种子保留现有版本、种子、维度、地表／群系切层、预设及生成入口；来源切换保留各自可编辑草稿和已完成视野，不把另一个来源的地图标成新上下文。

实例世界只有一排输入工具栏，依次为来源、实例、世界、维度、存档实况／生成预览、视图／可选Y和读取动作，控件表面共用42 DIP高度及垂直中线。初次读取和再次刷新共用一个末尾动作，不重复两枚效果相同的按钮。小于1100 DIP时视图／Y移到地图右上覆盖层，为实例／世界名称保留空间，不新增工具栏行。下拉与Y输入已经具有自身表面，直接浮在地图上，不再套额外描边、阴影或亚克力外框。

地图普通地点图标随比例尺连续缩放，标记与命中框限制为24～56 DIP，越近越大，图像留出控件边缘；避碰按变化后的实际尺寸计算，保持原始世界锚点。原点／出生点保留固定尺寸。完整图例来自当前安装原版的资源目录，并合入实际保存的未知ID，不能只保留当前采样条目。

玩家定位菜单加入地图左上悬浮工具组，紧邻坐标定位左侧，玩家状态卡仍在地图左下。只读版本／种子及复制移到固定高度footer左侧，实际快照／操作状态居中，采样与中心坐标在右侧；长文本省略并可查看完整值，反馈变化不增高footer。世界种子与版本来自实际存档／实例，不开放为可误改存档的输入框；切实例／世界后先显示新上下文及待查看状态，旧异步结果不得覆盖新选择。

| 地图内容 | 数据含义 | 可用操作 |
| --- | --- | --- |
| 存档实况 | 已保存区块优先，未探索区域补充对应原版生成预览 | 保存地形始终保留玩家改动；footer、地点详情及预览结构说明预测来源，不写入真实世界 |
| 生成预览 | 对应原版运行时按种子和生成配置计算 | 状态栏明确不包含玩家建造／挖掘；不能覆盖或写入真实世界 |

存档实况的未探索区域使用生成预览补齐。只填补确实缺少保存地形的区域，损坏、权限错误或无法解析的已保存区块不得被预测掩盖；无法准确复现保存配置或缺少种子／原版运行环境时，保留可读存档并说明外围预览不可用。纯生成预览继续可单独查看。

游戏运行不构成只读查看的统一禁用条件；地图监测落盘修订，自动重新读取已保存数据，玩家内存中尚未保存的改动不冒称已显示。更新、失败与重试保留最后有效画面及视野，拖动、框选、结构详情或导出期间延后替换。预测结构与实际记录独立保留，地点及3D详情标明来源；存档结构搜索、材料／库存分析继续只承诺已保存数据，不将预测战利品当成现有物品。

拖动期间地形、结构、出生点、玩家、查询准星与世界选区共用同一个保留平移变换；图标层不得单独提升后脱离祖先变换。地图工具和比例尺固定，松手才提交中心并补图，取消恢复原视野。加载卡在有限宽度中布局，副文本单行截断并仅在实际截断时提示完整内容。

## 版本选择

存档模式的结构搜索、XYZ材料统计、容器、3D／俯视与切层、物品组件、收藏和导出沿用现有控件。数据源改为实际保存快照，页内说明“存档快照”及未知格。容器没有保存物品清单时以共享InfoBar解释原因，不凭LootTable断言玩家从未开启；有实际表与seed时提供“预测物品”按钮，手动调用原版逻辑。预测结果使用独立槽位，明确无玩家／默认幸运值及零seed的不确定性，不覆盖保存库存、不写玩家世界；失败可重试、取消或切换后旧结果不得回填。收藏恢复精确实例与存档，搜索结果只承诺已有记录。切换来源／世界清除旧分析及结构结果，未完成请求不能跨来源提交；种子筛选与历史继续归生成来源。

兼容目标包含所有Minecraft Java版本，包含正式版、快照及历史Alpha／Beta等目录类型；26.3不能成为长期版本门槛。版本候选复用Core已有游戏版本目录，结合本地实例登记解析出的原版版本，不另维护一张静态支持版本表。

- 列表保留全部候选，搜索和类型筛选用于查找；只有已有实例对应的已安装版本可选，其余禁用并标明“未安装实例”。只有缓存或探索器私有运行时不等于已有实例。
- 同一原版版本对应多个实例时版本候选去重；选择实例世界后版本由该实例／存档决定。加载器版本不冒充原版版本，模组世界预测仍在后续范围。
- 无已安装实例时全部版本禁用，生成不可执行；不再默认下载26.3来绕过此规则。实例／世界选择与空态提供明确的下一步，不自动创建或启动游戏。
- 不因为版本早于26.3就禁用已安装项。该版本原生不存在的维度、结构、预设及存档字段不伪造；有真实缺失时在对应能力说明，不能把具体缺失扩大为整个版本不可用。

本稿版本目录使用Mojang版本清单快照和模拟安装状态，只验证选择规则。实际后端已按原版API族扩展；各历史族仍须真实JVM验证，不把可点击旧版本或复用样本图记为已支持。

## 玩家定位

定位状态与地图内容分开，实时玩家标记可以叠在最近落盘的存档地图上。右下仍为比例尺；左下使用紧凑玩家卡显示身份、位置来源与XYZ，地图右侧加入定位玩家按钮，玩家定位菜单承接显示／跟随与低频操作。不在页面堆积独立连接面板。

| 状态 | 表现与行为 |
| --- | --- |
| 数据桥连接、相同世界 | 实心朝向标记，文字标为实时；允许一次定位及跟随 |
| 游戏未运行 | 保留清晰实心标记，卡片标明最近保存时间；允许定位，不允许跟随 |
| 游戏运行但数据桥关闭 | 保留最近保存位置；“启用实时定位”说明下次启动生效，不Attach当前游戏 |
| 连接断开 | 冻结最后观察位置，明确标为断线／最后观察；停止跟随，不冒充最近保存或仍在实时更新 |
| 玩家在另一维度 | 卡片显示真实维度；明确定位或启用跟随时才切换地图维度 |
| 游戏在另一个世界 | 不叠加该游戏的位置；当前世界菜单说明上下文不匹配 |
| 没有位置数据 | 隐藏玩家标记与卡片，禁用定位；不把0,0当成玩家位置 |

玩家定位默认可显示，有实时数据时才可跟随。朝向箭头使用绿色轮廓、随主题切换的黑／白实心填充，保证覆盖结构图标时可辨识；位置来源由卡片文字明确说明。手动平移停止跟随但保留位置更新，缩放保持玩家标记真实坐标。切世界、断开或离开游戏撤销旧归属；历史位置始终附带对应实例、存档、维度及采样／保存来源。离线有多个玩家时可选择可读取记录，不能用当前账户名称猜位置。切入存档后关注锚点同步实际保存出生点，清理旧生成预览的出生旗标，不能同时展示两个来源的出生点。

## 交互与验证边界

筛选条件卡与结果卡各自使用10 DIP条目间距，间距由实际重复器的布局提供，外层分组间距不能替代条目间距。结果悬停只在常态与悬停表面之间淡入淡出，透明端保留悬停色相，避免移动时出现额外亮闪／暗闪。

群系采样间隔使用与半径同款的可编辑NumberBox，范围4～256格，默认32格。它是整次查询的共用值，任一群系卡修改后同步所有群系卡，并随现有草稿及历史查询恢复；查询执行中禁用编辑。更小间隔提高采样密度、增加成本，更大间隔可能漏掉较小群系，不能把采样未命中当作不存在。

保持现有方角、微立体、主题角色和42 DIP表面。ComboBox菜单与触发框等宽；地图工具按地图宽度切图标，浮层覆盖地图，不平移地图、重排图钉或挪缩放组。轻量Flyout以点外部／Esc关闭，键盘关闭回焦点；版本禁用项不能由鼠标或键盘选中。800×560下通过布局收紧与必要的两行上下文保留地图空间，不缩放独立画布。

HTML已经用真实浏览器检查来源与版本选择、玩家显示／跟随／手动平移、跨维度定位、断线／不同世界隔离、缺少种子与空态、刷新恢复、结构子页返回及键盘关闭，并查看Light／Dark／HC和800×560截图。它们是交互设计核验，不是原生UI、真实存档、全版本生成或实时数据桥接线验收。

后续实现仍遵循CLI／Core先行：Core提供typed世界读取、快照来源、玩家归属与原版运行时能力，CLI实际可操作后Sprout调用同一契约。跨版本方案应解析／绑定所选原版运行时并按真实API形态处理变化，不逐版本重写生成器；官方映射、历史命名和存档格式的差异仍须验证。移除版本判断、静态目录全开或同一张样本图都不能证明全版本支持。实际功能边界见[种子契约](../../doc/SEED-EXPLORER.md)。
