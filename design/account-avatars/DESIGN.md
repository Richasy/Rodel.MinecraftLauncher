# 本地账号头像 · 已认可设计

已认可本页交互与头像方向，并确认微软账户使用在线图片、本地账户才可修改头像。入口为[交互原型](index.html)，[完整图库](gallery.html)提供大图查看。原生头像选择已接入同一交互；已有“需要重新登录”状态使用12 DIP Critical色，认证语义继续由Core维护。

## 用户流程

1. 点击主侧栏头像打开快速切换菜单。每个账号左侧显示自己的方形缩略头像；名称右侧为 Microsoft 四色标或电脑图标，悬停与无障碍名称分别说明“微软账户”“本地账号”。保留微软在前、本地在后的分组及当前账号下凹选中态，不增加类型文字行。
2. 当前是本地账号时，菜单下方提供“更换头像”。账户管理中可点击任一本地账号的头像，或从该行省略号选择“更换头像”；编辑其他账号不切换当前身份。微软账号继续展示账号皮肤头像，不提供本地覆盖入口。
3. 选择器沿用 440 DIP 的账户 Popup。顶部显示目标账号、64 DIP 草稿预览和头像名称；来源分为“预制头像”“自定义图片”。正文为唯一滚动区，页头与底部操作固定；底部保存在左、取消在右，两列等宽，无重复关闭按钮。
4. “预制头像”以 7 列 × 4 行展示全部 28 个。每项仅显示图片，悬停提示名称；选中边框、内凹表面及角标明确草稿选择。点击只改预览，保存才同步主侧栏、切换菜单和管理列表。默认选中史蒂夫，无独立通用账号图标。
5. “自定义图片”支持选择和拖入 PNG / JPG / WebP。实际在浏览器中解码，以居中 cover 起点裁成正方形；可拖动或用方向键移动、用滑块缩放、重新选图。裁切边界不暴露空白区域；保存直接应用裁切结果，不再二次确认。不把皮肤纹理 PNG 猜成脸图，上传的图片本身按玩家选择裁切。
6. “恢复默认”将草稿切为史蒂夫，仍需保存。取消或 Esc 丢弃本次草稿并回到来源菜单/管理列表。保存返回同一来源；编辑未选中账号保留当前启动身份。

“仅更改启动器头像，不更改游戏皮肤”保留为本次选择所需的用途边界。头像不改变名字、UUID、认证状态或游戏皮肤。

## 素材

用户最新要求为 **4 批、每批 7 个，正面方形像素脸**。最终使用内置 ImageGen 生成的四张平面脸图，分别裁切为 28 张 `256×256` PNG；最初的侧面半身图不采用。Azure 返回 401 后用户说明服务次日恢复，并明确同意改用当前图像生成工具。

| 人物 | 史蒂夫（默认）、Alex、少年、少女、白胡子爷爷、银发奶奶、红帽男孩 |
| 饰品与角色 | 眼镜女孩、青色头巾、王冠、矿工、探险家、女巫、海盗 |

素材均为生成的 MC 风格正面脸，不宣称是从官方皮肤纹理提取。各批原图的空白第八格不进入图库；裁切文件随 HTML 保存于 `assets/`，不依赖生成缓存目录。

史蒂夫眼睛使用接近经典皮肤的深蓝紫色，避免亮蓝或青色。实例预制方块保留透明背景与阴影，按可见主体重新裁切留白，在相同图片槽中接近自定义方图的视觉大小；不改变玩家上传图片的裁切结果。

## 交互与恢复

- 图片加载失败显示明确错误、保留旧头像与已有草稿；文件选择取消不改变草稿。异步解码后校验本次选择及面板生命周期，关闭后不应用迟到结果。
- 原生主窗口注册 Windows 文件拖放；自定义区域接收单个文件并进入同一解码和裁切流程，多文件与文本拖放不接收。预制页不接收自定义文件。
- 未产生变化时保存禁用。切换预制头像与图片不写入账号；每个本地账号的草稿和应用目标独立。
- 预制网格支持方向键、Home/End 与真实 radio 选择状态；来源页签支持左右键；Esc 取消，原生 HTML dialog 负责焦点圈定。正面像素头像使用 nearest / pixelated，自定义图片正常采样。
- 主题沿用现有浅色、深色及高对比度模拟角色、方角和微立体控件；不另做页面或圆角卡片风格。
- 原型账号与自定义图片仅存本页内存，刷新重置；不读取玩家目录、不上传自定义图片、不调用登录服务、不修改真实设置。

## 已有真实状态与状态色

`IdentityService.RefreshMicrosoftAsync`在验证会话与启动获取凭据时刷新微软会话；仅`AUTH_LOGIN_REQUIRED` / `AUTH_CACHE_UNAVAILABLE`落盘为`login-required`，网络失败与超时不误标。重新登录成功恢复`ready`。原生账户列表已读取此状态，12 DIP副文字改用共享Critical角色`LauncherTheme.Error`；HTML菜单与列表同样显示Critical小字。微软头像仍取账号官方Minecraft皮肤，本地预制或自定义图片不得覆盖微软账号的在线来源。

原生偏好与图片文件已接线；OS手势 / RTL边界仍未完整验证，不由HTML状态推定为通过。

菜单宽度：快速账户菜单固定360 DIP，窄窗保留16 DIP边距，不按短名称自动收窄。本地账户的更换动作使用铅笔图标，管理头像常显小角标。原生选择、存储与图片裁切已实施。实例图标复用同一选择器，使用28张透明投影方块图片，入口在实例溢出菜单，持久化归既有Core图标接口。

头像菜单在头像右侧展开并顶部对齐，菜单宽度与HTML统一为360 DIP；边缘避让沿用原生Popup定位。预制头像/图标与自定义图片通过共享segmented控件切换，使用启动器统一的轨道与选中材质，不以两个独立按钮拼装。
