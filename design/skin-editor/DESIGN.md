# 独立皮肤编辑器 · UI / UX 设计

本设计承接启动器[当前设计规范](../DESIGN.md)，面向 Windows Sprout 的独立编辑窗口，以手动绘画为主要任务，AI 作为可展开的辅助工具。[HTML 原型](index.html)用于评审布局、绘制手感与修改审核；[社区参考](RESEARCH.md)记录参考项目与取舍。原生窗口使用D3D11视口，工程、笔画保存和撤销重做共用Core。HTML不接入Core、模型或MCP。

能力核对基于主线提交 `9bd6cd5`。文中“现有”指该提交的库、Core 或 CLI 契约；“原型”指浏览器内交互；“后续接入”指正式实施所需工作。三者不能互相充当验收证据。

修订：3D / 平面使用启动器共用的原生 Segmented 单选控件，各自保留观察状态。平面模式隐藏展开图入口和UV小窗，3D恢复原开关偏好，隐藏小窗不占输入区域。绘图层按真实堆叠顺序显示独立缩略图、名称和选中行，删除底部图层数量/图层选项整行；绘图层区底边不加分割线。工具悬停/按下/选中采用普通按钮共享浮雕，选中与选中悬停保持内凹。镜像置于左侧工具栏独立组，使用对称图标和同一按下材质，标题栏不留镜像文字按钮。Alt拖动采用抓住人物的方向，右拖人物向右转。

按住 Ctrl＋左键拖拽在屏幕 X/Y 平面平移模型视图，局部放大后无需复位；保持当前旋转、缩放、工程像素与选区。按下时锁定平移，拖动途中松开 Ctrl 不切换为旋转或绘制，松开鼠标结束；不抢占已有绘制／保存手势。Alt／右键继续旋转，平面及 UV 小窗同样支持 Ctrl 拖动平移，各视图保留独立观察状态。显示、选区轮廓和拾取共用平移后的相机，复位同时清除平移。

原生框选已接入：`R`选择矩形工具，平面及UV按贴图像素拖拽，可从未映射空白起拖，最终只保留当前底层/外层及可见部位的有效像素；3D在起始命中面内拖拽，离开该面保留最后有效终点。三个视图共用同一绝对贴图选区与持久黑白虚线轮廓；切换工具、视图和普通撤销保留选区，工程切换、成功导入或模型/尺寸改变清除。画笔、橡皮、填充与镜像最终写入均受选区限制，空选区不允许写入。使用画笔、橡皮或填充时，在画布选区外左键按下只取消选区，不绘制、不擦除、不填充，也不在同次拖动或松开时补画；下一次新按下才正常编辑。取色、选区移动、浮动粘贴及Alt／右键导航保持原语义，工具栏和UV面板上的操作不透传为画布取消。框选不修改工程或增加撤销记录；Esc取消正在拖拽并恢复前一个选区，完成后Esc / Ctrl+D取消选区，工具选项提供同一命令和像素计数。捕获丢失、窗口停用及观察配置改变取消当前手势，避免旧坐标继续写入。

选区转移：选区工具内按住已选像素拖动为移动，面外起拖仍框选；3D锁定起始面，平面/UV使用绝对贴图位移。三个视图共享活动层草稿、选区与轮廓，松手一次提交；非法移动保留最后合法位置，不丢源点。Ctrl+C复制实际层RGBA与mask至Windows自定义皮肤选区格式，Ctrl+X剪切、Delete删除；复制不进入历史，移动/删除/粘贴进入既有统一历史。Ctrl+V进入浮动预览，点击或Enter放置，Esc取消；弹窗和文本输入仍接管自身按键。原像素1:1跨模型/尺寸粘贴并裁到真实有效目标，不自动缩放。背景Base删除/移动提供显式“源位置填充色”字段，其他层/外层清透明；透明数据贴入背景Base整笔拒绝并反馈实际原因。

图层与选区布局：图层行不显示拖动图标，也不保留其空列；整行继续用Sprout ItemsView排序和动画。32 DIP缩略图配四边12 DIP内距、8 DIP列距、56 DIP行高。选区工具菜单采用标题/像素数量同一行，命令为等宽两列、34 DIP高有边框按钮；源位置填充色由独立背景/边框分组，取消选区为整行同样式按钮。浮动粘贴只呈现并排放置/取消，放置为唯一accent；不堆不可用普通命令或额外说明文本。

颜色浮层：色谱、色相条、透明度条和HEX输入框统一240 DIP宽、共用左右起点；内部与外部纵向间距均12 DIP。色谱和两条渐变轨道使用直角，三个选择标记采用白外框/黑内框的方形轮廓，沿用原HSV/Alpha输入几何、键盘和无障碍range语义。通过Sprout公开外观参数配置，不改为App重画一套选色逻辑，也不全局修改其他ColorPicker默认样式。

披风使用独立 Cape 工程、64×32 或 128×64 纹理及 10×16×1 几何。人物与披风共用新建对话框，五个人物模板之外提供一个空白披风模板，选中后显示矩形尺寸。空白人形与空白披风共用可编辑的逐面灰度及一逻辑像素淡灰边线。近期工程卡片占据右栏命令区下方剩余高度，标题固定、内容内部滚动，左侧模板独立滚动。人物搭配仅在披风编辑栏提供，导入、共享选择及单独查看见[当前规范](../DESIGN.md#披风独立作品与搭配预览)。人物和披风分别保存及导出。

## 预览

固定模板卡片使用随App打包的Assets/SkinTemplates六张1024×1024 PNG，由真实模板纹理/模型一次性GPU抗锯齿渲染生成，显示采用高质量缩小采样，保留纹理像素。开始页直接加载图片，不在窗口打开时逐张生成；模板纹理或模型变化时同步重生成对应图片。新建对话框继续使用真实模板文档与实时3D预览，预览图片不作为编辑纹理输入。

标题栏的“预览”打开独立模态Popup，仅显示完整人物的MC标准走路循环。渲染区域零内距铺满Popup、不另加内框，关闭图标叠放在视图内部右上角；预览按实际DPI渲染并做轮廓抗锯齿，保留贴图像素。没有模式切换、速度、进度或说明区域；打开即循环，首尾位置及速度连续，外部点击不关闭，关闭按钮/Esc手动返回原工程与编辑观察状态。读取打开时的完整合成，不受编辑部位隔离影响，不修改纹理或历史。原生支持拖动观察与滚轮缩放；HTML只模拟当前浏览器内的合成，不能替代原生渲染验收。

走路交替摆动相反手脚，禁止肢体严重穿模。检查完整循环与两种手臂宽度，肩/髋正常接合和衣物接缝不等同于严重体积穿插；默认镜头容纳全身运动。

在仓库根目录启动静态服务，然后访问 `/design/skin-editor/index.html`：

```powershell
python -m http.server 8776 --bind 127.0.0.1
```

不需要 npm 或外部 CDN。顶部评审条支持浅色、深色、高对比度、AI候选与冲突示例，也支持 `?theme=dark&scenario=proposal`；它不属于正式窗口。脚本使用ES module，因此通过HTTP打开。画笔、填充、取色、单面矩形选区、独立UV小窗、图层拖放/行内改名、历史回溯与PNG导出在本页实际执行。自定义色板及当前色板选择保存在浏览器 localStorage；皮肤像素、绘图层和历史只在内存，不会写入Core，刷新会重置。

默认使用“经典蓝衫”基础人物模板：Classic `64×64`、4像素手臂，具有基础五官、头发和简洁衣物，外层及贴图未使用区域透明。另有推荐 Slim 的“Alex 风格”橙发绿衫模板；这些人物纹理由本项目原创像素生成，不使用官方 Steve / Alex 皮肤图片。新建可组合任一模板、Classic / Slim 和64 / 128尺寸，空白素色也是可选模板；选择色板或前景色不会自动给人物上色。

## 玩家任务与窗口职责

玩家能够从已有 PNG 开始，也能创建一张标准或HD皮肤；在身体模型上画大轮廓，在平面贴图上处理像素细节，随时查看正背面和外层效果。完成后按目标环境导出 PNG，继续编辑则保留含图层与历史的工程。AI按玩家明确目标直接编辑当前皮肤，修改进入相同历史并保留原作图层；不要求先连接模型才使用手动工具。

启动器中的皮肤编辑入口打开独立的非模态窗口。编辑器不复制启动器主侧栏，也不成为独立助手产品。整个应用只保留一个编辑器窗口；重复进入激活已有窗口，最小化时先还原。窗口独立记录正常尺寸、位置与最大化恢复状态，首次打开在主窗口当前所在屏幕；后续恢复编辑器自己的位置，显示器变化由Sprout校验可见范围。工程切换在同一个窗口内承接。

原生已保留单行标题栏、左工具、右侧编辑/AI/历史与footer，并接入真实D3D11视口、Classic/Slim × 64/128工程新建/打开、3D画笔/橡皮/填充/取色、镜像、显示隔离、相机与单笔保存/撤销重做。保存期间有界缓冲下一笔，冲突保留两笔并允许明确放弃后重读。主平面/UV编辑及投影足迹已接同一会话，绘图层已可选择并显示真实缩略图；图层管理、PNG导入导出及历史回溯已接线；AI已接共享管线与受限候选审核。下方原型模拟与产品契约分别判断，不以单项通过替代全部验收。

建议初始客户区 `1280×800 DIP`，最小 `960×640 DIP`，跟随系统 DPI。HTML 的 UV 展开图在所有宽度下都是独立小窗，窄窗调整其尺寸及工具间距，用来检验空间压力；这不是手机适配承诺，也不改变原生最小窗口建议。

## 视觉承接

沿用启动器的方角、薄浮雕边缘、短投影、暖白 / 深灰半透明材质、连续线条图标和品牌绿。窗口背景可以保留弱化、模糊的世界场景，绘画区域采用安静的主题底色，保证肤色、透明棋盘格和像素边界可辨；背景不能参与取色或被导出。

中文使用正常 UI 字体，英文名称与玩家输入保持原样。面板标题、字段值、辅助说明有明确字号和 Primary / Secondary 层级；HEX、像素坐标可使用等宽字体。正文不使用像素字体，不引入彩色 emoji 工具图标。

同一操作组最多一个主动作使用绿色。工具选中、当前绘图层、当前页签使用共享选中面，不能看起来都在催促执行。禁用主按钮使用灰色禁用面；悬停、按下、选择和键盘焦点各有独立状态。浅色、深色、高对比度整体切换，不能只替换画布背景。

编辑对象优先于管理动作。名称、颜色等可直接修改的内容在原位编辑，添加入口贴近集合末尾，低频操作收进上下文菜单；只有需要独立提交的流程才提供单独的主按钮。不能为每项能力常驻一个大按钮，也不能在有效编辑已即时生效的面板底部再放一个没有独立提交语义的“完成”按钮。

原生标题栏使用 Sprout 自带 caption 与非客户区机制，保留最大化、Snap、拖动及系统关闭行为。HTML 的窗口按钮仅为外观和关闭流程示意，不作为原生实现。

## 窗口结构

| 区域 | 内容与交互 |
| --- | --- |
| 单行标题栏（48 DIP） | 开始页显示应用图标和「皮肤编辑器」纯文本标题。工作区在图标旁显示工程名下拉菜单，另有工具与大小摘要、撤销 / 重做、预览和导出。两种状态均保留拖动区域和原生窗口按钮 |
| 工程菜单 | 新建工程、文件选择器打开、工程另存为、导入 PNG；存在未保存草稿时才显示放弃更改。每项带图标，logo本身只展示图片 |
| 工具选项 flyout | 大小、N×N 方形足迹示意、随工具变化的说明、当前绘制目标、快捷键。镜像是左侧工具栏独立组的图标 toggle |
| 左工具栏 | 画笔、橡皮、填充、取色、选区；底部前景色直接打开 color picker。3D 旋转不另占一个工具 |
| 中央工作区 | 主画布在 3D / 平面之间切换；网格与展开图各是独立开关。展开图为可编辑 UV 小窗，主视图切换不影响其开关、缩放和平移状态 |
| 右侧面板 | 编辑、AI、历史三个页签，初始为编辑。AI 不占据默认主工作区 |
| 状态栏 | 工程保存状态、选区摘要、必要的版本变化提示。修订号可供诊断，不成为玩家操作前必须理解的概念 |

标题栏菜单 / flyout 默认关闭且互斥，锚定触发器下方；展开不增高标题栏、不推动画布。支持 Enter / Space 开关、Esc 关闭、外点关闭与内部 Tab 循环，关闭按钮 / Esc 后回到触发器；外点关闭保留新点击位置的焦点。新建、导入、快捷键先收起浮层，再进入对应流程。切换工具保留大小 / 镜像；绘图层数量、修订与目标随编辑更新。镜像不使用下拉框，按下状态表示左右对称已经启用。

工程另存为使用原生文件保存选择器与`Ctrl+Shift+S`，生成可继续编辑的`.rmcs`快照，保留图层和现有撤销/重做，不改原稿，不打包AI会话。当前工程继续在库内自动保存，不与另存文件建立实时链接；重新打开外部文件仍迁入独立身份。取消不改状态或文件，覆盖由选择器确认，失败保留当前工程并显示原因。原型只示意入口，不伪造Core工程文件。显隐、改名与排序保留同一历史/失败恢复，复用像素未变的缩略图；不能靠跳过保存、丢历史或减少图层掩盖延迟。

窄窗压缩间距、截断过长作品名，保留工程菜单、工具、镜像、导出和全部 caption；不增加第二行。被截断的名称可通过截断tooltip查看完整值。原生实施使用真实最小窗口约束和文字缩放，HTML 的 48 CSS px 只是布局参照。

### Sprout 标题栏对照

标题栏保持 `CaptionButtons = CaptionButton.All`，通过 `Window.SetTitleBarContent(Control / IView)` 挂载一份可交互布局；不再显式固定 `WindowSpec.TitleBarHeight`，48 epx 是内容的最小高度，文字缩放时由 Sprout 按真实内容自然增高。框架从 band 布局中扣除 caption 宽度，应用不重复预留。Button / DropDownButton / Slider 等真实交互节点自动从拖动区剔除，纯文本和布局空白保持窗口拖动。保留 `Window.Title` 供任务栏、Alt-Tab 与读屏使用。

工具参数使用 `DropDownButton` 挂载 `Flyout`，显式设置 `Placement = PopupPlacement.BottomEdgeAlignedLeft`、`ShowMode = FlyoutShowMode.Standard`、`ShouldConstrainToRootBounds = true`。Sprout Standard 默认取焦点、Tab 约束在浮层内、light dismiss 与 Esc 关闭，关闭恢复先前焦点；不使用不取焦点的 Transient 模式。标题栏文字按钮、分段及颜色输入均采用自然高度／最小尺寸，不能由外层固定行高再次裁切；图标相对最终行高垂直居中。真实225%和窄窗验证不能由100%画面代替。

源码入口（相对于 Sprout 仓库）：`src/Sprout/Windowing/Window.Content.cs`（SetTitleBarContent）、`Window.Layout.cs`（band 可用宽度）、`Window.Lifecycle.cs`（交互 carve-out）、`Configuration/TitleBarHeight.cs`、`src/Sprout/Host/TitleBar.cs`、`src/Sprout/Popups/Flyout.cs`；行为说明见 `docs/guide/flyout.md`、`docs/guide/dropdown-button.md`，示例见 `samples/Sprout.Cookbook/Windowing/TitleBarSearchApp.cs`。这里只核查源码，未以 HTML 测试替代原生 Snap / DPI / UIA 验收。

主视图和独立 UV 小窗共用文档、活动绘图层、颜色、工具与表面。切换主视图不清空选区；两种主视图分别保留观察变换，小窗保留自己的缩放 / 平移。缩放只影响观察与输入换算，不改变像素尺寸。底层 / 外层目标始终位于右侧身体部位面板，不依赖小窗是否打开。移除画布底部坐标 / 缩放提示条和右侧底部泛用提示，保留滚轮、复位与实际保存状态。

右侧编辑页依次为颜色、身体部位、绘图图层。当前原型在窄窗缩减面板宽度和内距，保持面板可见；颜色、部位和图层共用一个属性正文滚动区，图层按内容自然展开，不另限高或产生第二根纵向滚动条。页签、主操作、画布布局切换与状态保持可达，不将整窗缩小来容纳内容。

绘图图层作为编辑页最后一个区域，底部不再添加分割线，保留上方身体部位的区域分隔。原生承载、模型复用、透明与拾取的当前实现和验证边界见[原生渲染路径](RENDERING.md)。

## 原生开始页、工程菜单与状态栏

## 手动编辑主流程

### 新建、导入与输出

从工程菜单或开始页打开“新建”，原生对话框与PNG导入共用左右分栏：标题后紧接共享Segmented切换平面/3D实时预览，标题最右侧为关闭按钮；左预览和右元数据面板上下边完全等高平齐。右侧独立滚动的名称、模板、模型和尺寸，创建按钮固定在右下，不重复提供底部取消按钮。模板选择通过下拉菜单呈现，使用实际模板像素更新两种预览，选择不创建工程。HTML原型的单选卡片仍展示五个模板的真实人物缩略预览：经典蓝衫、Alex 风格、日常白衫、基础人形、空白素色。前四个具有基础五官、头发和简洁衣物；Alex 为橙发、绿色上衣与棕色长裤，空白素色的底层统一为不透明 `#D6CFBE`。所有模板外层初始透明，均可搭配 Classic / Slim 与 `64×64` / `128×128`。模板入口留在新建流程内，不在编辑画布旁增加常驻模板工具栏。

手臂模型与纹理尺寸是独立字段。标准 Classic 对应4像素手臂，细手臂 Slim 对应3像素手臂；这是64基准下的模型比例，128纹理将每个方向的纹理采样加倍，人物几何大小不变。选择 Alex 建议 Slim，其他模板建议 Classic；仅在本次对话框中尚未手动选择模型时自动采用建议，一旦手动选择便在后续模板切换中保留。尺寸始终由玩家选择，模型或尺寸变化立即刷新真实缩略预览。

选择模板、模型和尺寸只更新对话框预览，不修改当前文档。点击“创建皮肤”才替换本页草稿、清空原历史并开始新工程；取消保留当前作品、图层和历史，应用模板不影响自定义色板或色板选择。创建前说明当前草稿将被替换，使玩家能返回导出。缩略预览由同一份实际模板像素生成，不用无关人物图片代替。新建后的模型与尺寸是文档属性，当前没有就地模型转换或缩放流程；未来转换应说明有损区域与保留原工程的方式，不能把元数据标签做成看似无损的切换。

原生 PNG 导入确认采用左右分栏：页头标题后的共享 Segmented 在左侧平面纹理和可旋转、缩放的3D预览之间切换；右侧显示文件尺寸、手臂模型、工程名称（无工程时）、替换说明和错误，右上角关闭，底部仅固定主操作按钮，左右面板边框等高平齐。正文需要时独立滚动，窗口高度随内容和可用高度约束，不留下竖向大块空白；PNG 不携带可靠模型信息，模型选择实时更新预览。

原型导入接受 `64×64` 与 `128×128` PNG，按图片实际尺寸建立预览，再让玩家选择对应手臂模型；不能仅靠像素尺寸可靠猜出 Classic / Slim。确认导入才替换本页绘图层，模型、尺寸、像素与图层作为同一事务保存到历史，可一次撤销恢复原工程；原文件不改写。取消或读取失败保留原作品。底层 alpha 按既有不透明背景规则规范化，外层保留透明度。原型尚不转换旧 `64×32`；当前 Core 已支持 `64×64`、`128×128` 和 Classic 旧 `64×32`，原生导入已接同一会话历史。

`128×128` 以完整像素分辨率参与3D / UV绘制、足迹、选区、图层、历史与PNG导出，不只是把64图放大显示。新建尺寸旁与HD导入 / 导出说明“128用于HD纹理，Java版账号皮肤需使用64×64”；保留HD选择和导出，不将账号用途限制变成编辑门槛，也不静默降采样。此区别有[官方账号页面及HD资料依据](RESEARCH.md#模型分辨率与用途边界)。当前Core与独立库已支持128文档及正式回归，不代替原生验收。

原生新建 / 导入完成后得到 Core 文档 ID。后续每次事务完成即保存工程，因此不设置一个必须点击才持久化像素的“保存”主按钮。导出 PNG 是独立动作：选择路径、核对覆盖目标、成功后提供实际输出位置；PNG 只含合成纹理，不含绘图图层与历史。

导出不修改正版账号、不安装皮肤模组、不改变游戏中当前人物，也不保证联机其他玩家可见。界面使用“导出 PNG”，不提供“应用到 Minecraft”按钮。

### 透明图层 PNG 分享

图层标题行在添加按钮旁提供“将 PNG 导入为新图层”图标，已有工程才可用。文件选择完成即添加一个以文件名命名、可见且未锁定的顶层并选中，保留原有模型、尺寸、图层与当前选区；整次导入进入一条可撤销历史。接受与工程同尺寸的64×64或128×128方形PNG，不静默缩放、镜像、裁切、猜测手臂模型或补实透明底层。尺寸不符、损坏、取消或保存冲突不改变原作品。完整皮肤导入继续保留原有替换语义。

图层行更多菜单提供“导出图层 PNG”，导出被操作图层的原始RGBA和完整画布位置，不合成其他层，不乘图层透明度，不受隐藏/锁定影响；背景层也按实际像素输出，不臆造透明区域。使用原有保存选择器确认覆盖与Core原子发布，不修改工程、选择或历史。普通附加绘图层的未绘制区域保持透明，披肩PNG可以直接分享并再次作为图层导入。原型用行内图标演示相同操作；浏览器canvas不作为透明RGB字节保真的验证依据。

### 画布操作

左键按当前工具编辑，按住 Alt 临时显示手形：3D 拖动旋转，主平面与 UV 小窗拖动平移；松开 Alt 恢复原工具。拖动期间用抓取手形，未按 Alt 的绘制使用与实际覆盖像素一致的 N×N 方块轮廓，大小随工具参数与视图缩放变化，3D 轮廓遵循真实面投影；到面边缘按实际范围裁切。右键旋转保留为附加手势，侧边不设置旋转模式。滚轮缩放，标准正 / 背 / 斜视角与复位按钮提供可点击替代入口。导航操作不进入文档撤销历史。

一次按下到释放的绘制手势是一笔事务。拖动过程中即时预览，提交成功才更新已保存状态；不能为每个指针采样点生成一条持久化历史。取消当前未提交笔划可以丢弃预览，已成功提交的笔划通过撤销恢复。

3D 拾取和 UV 编辑必须使用同一身体 / 表面 / 面映射。身体左右以角色自身为准，正面观察时不能按观看者左右改名。未命中模型不绘画，也不落到默认部位。正在编辑外层时，空透明区域必须仍可拾取，否则玩家无法从空白画帽子或衣物。

“显示外层”是观察状态，“绘制位置：底层 / 外层”是编辑目标。二者分开。关闭正在编辑表面的显示时，要保持明确的目标反馈；正式实施优先重新显示当前目标或要求先选择可见目标，不能在不可见表面悄悄绘制。

单侧肢体的相对面按当前面的法线穿过长方体反射，保持该面内的实际空间位置；四个直立面翻转面内X，顶底面因真实UV方向相反而翻转Y。不能只对同一面的左右列取反，导致正面同时出现两个画笔。显示轮廓与实际像素共用同一结果，背面的轮廓应被不透明模型遮挡；纹理阴影不改变六面几何，也不能拿它解释错误的同面双落点。

复制范围按当前可见表面，而非“绘制位置”：始终包含底层，显示外层时同时包含外层，隐藏外层则保留对侧外层。来源为所有可见绘图层按各自不透明度合成后的RGBA，目标仅是当前选中绘图层，用替换而非再次叠加写入；不新增、合并或复制图层，不改其他图层及文档透明蒙版。透明像素也替换目标层对应像素，背景底层仍遵守既有不透明保护。整次复制只产生一个可撤销事务，不受局部选区裁成残缺肢体。

首次复制先显示自然高度的原生覆盖确认，正文说明只覆盖当前绘图层的对侧对应区域、其他层不变且可撤销；提供“下次不再提示”复选框。底部两个等宽按钮，复制为次级，取消为主色且获得初始焦点，Enter默认取消，Esc同样取消，不重复放标题关闭X。仅在明确确认且复制成功后把勾选保存到App的SkinEditor偏好，跨工程及重启保持；取消及失败不保存免提示选择，不写入工程或撤销历史。忙碌、活动草稿及不可绘制图层沿用现有守卫。

原型矩形选区用于验证平面操作和范围反馈，完整产品应限制或拆解为明确的面内选择，不把 UV 图上跨多个身体面的框直接作为已有单面 `SkinSelection` 发送。隐藏无关身体部位只改变视图；是否限制编辑需要由当前目标 / 选区明确决定。

### 两种“层”

Minecraft 底层 / 外层决定像素贴在哪一层身体几何上；绘图图层是当前文档完整尺寸（原型为 `64×64` 或 `128×128`）的 RGBA 画布叠加。一个“围巾细节”绘图层可以同时在底层和外层包含像素。右侧标题固定为“绘图图层”，表面切换固定为“绘制位置”，不用两个都叫“图层”的无说明标签。

图层行显示真实 RGBA 着色缩略图（透明处为棋盘格）、名称、显隐、锁定和选中状态；不透明度在所选层属性中。名称双击、F2 或点击重命名入口即可行内编辑，Enter / 失焦保存非空名称、Esc 取消。拖动手柄排序，以插入线反馈位置；同时提供上移 / 下移按钮，以及手柄聚焦时的 Alt+方向键。背景固定底部，额外图层不能移到背景下面。重命名与排序进入同一撤销历史，缩略图随实际像素更新。复制、删除、向下合并属于后续完整图层菜单。

必需的背景 `background` 不能删除，也不能当成普通图层调整显隐 / 不透明度。其底层区域保持完全不透明；擦除或剪切时使用玩家确认的底色。额外绘图层在底层区域也允许透明。锁定拒绝绘画、删除与合并，不把当前实现的锁定误描述为禁止所有属性或排序变更。

颜色区和前景色浮层提供「透明色」。选中后用画笔标记当前模型表面的镂空像素，保留模板、底色和各绘图层。选中透明色时使用橡皮可擦除遮罩。从已镂空像素起笔的橡皮手势也只清理遮罩。每笔共用笔宽、镜像、选区和撤销历史。3D 编辑视图沿镂空边缘显示低强调线框并保留几何命中，平面及展开图显示透明棋盘格。成品预览使用实际镂空像素，合成 PNG 导出保留其零 alpha，工程文件保存可恢复的遮罩和底稿。

勾选「透明色」时，禁用前景色浮层的色谱、色相、透明度和 HEX 输入，以及颜色区的前景色 HEX 输入。取消勾选后恢复编辑，并显示勾选前的前景色。

显隐与不透明度影响合成、导出、合成取色和透明感知拾取。向下合并会烘焙参与层的可见性与不透明度，但可通过事务撤销；提示描述结果，不重复增加所有普通图层操作的确认弹窗。

### 自定义色板

初始提供五套不同风格的内置色板，每套16色：森林自然（`forest`，保留原16色）、日落暖调（`sunset`）、深海冷调（`ocean`）、柔雾粉彩（`pastel`）、霓虹夜色（`neon`）。预设颜色仍通过复制后编辑，但预设本身也可以删除；删除选择随App偏好保存，不在重启、创建其他色板或删除最后一板后自动补回。全部删除后显示“暂无色板”，仍可直接新建。选择或删除色板不修改当前人物像素或前景色。

色板选择器旁提供独立加号菜单，只有“新建空白色板”和“从参考图新建色板”两项，不要求先进入管理。空白新建保留真正的空集合；名称预填可用且不重名的建议值，同页可加色，不另设命名步骤。创建一次提交名称和全部颜色，取消不修改旧集合或前景色，创建成功直接返回编辑器。

两个新建菜单项各有对应的20 DIP连续线条图标：空白色板用色块网格加号，参考图色板用图片框叠加滴管。两项保留同宽图标列、同一文字起点和继承的菜单前景色，不再混用普通加号与无图标条目。图标包装只把显式颜色作为覆盖值，继承颜色走可更新通道，不能在构建时冻结普通前景，导致悬停或高对比度选择后与文字失配。

管理页以名称行和色块网格为主体。自定义名称旁的小铅笔进入行内编辑；复制和删除留在省略号菜单。网格末尾的 `+` 用当前前景色创建新的独立颜色项并直接打开选色器；初始值与已有色相同也不去重或改写旧色。选色器支持可视选色及可选的精确输入，无效或未完成输入保留并提示、不写入色板；删色位于选色器头部。管理页从头部关闭，不保留底部编辑行、大按钮组或“完成”footer。

从参考图创建时先选本地PNG、JPEG、WebP或BMP，再打开同一新建草稿：名称、参考图、颜色网格及创建／取消按任务顺序排列。图片按EXIF方向和sRGB解码，保留完整分辨率的直通RGBA供采样，显示位图与源像素分离。自动提取使用Windows WIC中位切分量化，最多16色，不强行补足数量；跳过全透明像素，在非透明原像素中做确定性的有界蓄水池采样，避免固定网格漏掉周期性像素，再把量化中心匹配到实际样本并去重。全透明图允许空结果，玩家仍能手动添加；16色不作为手动加色上限。

预提取结果再按Oklab感知色差合并近似色：优先保留在原图样本中代表更多像素的真实颜色，不平均成图中没有的颜色。近灰与有色颜色分别处理，避免把同明度的肤色／衣物色并入背景灰。整理后先排近灰色，由深到浅；其余按相邻色相归为跨度不超过60°的色系，同系由深到浅，跨0°的红色仍可归为一组。合并阈值0.05和近灰色度0.018是本产品色板整理取舍，不宣称低于阈值的色差不可见；不为凑满16色回填相似色。此整理仅应用于自动提取，不重排既有色板、手动加入或编辑的颜色，也不改写原图采样值。

参考图工具行提供专属滴管、缩小、放大和复位。滚轮围绕鼠标缩放，非取色状态直接拖动平移；取色时Ctrl＋拖动或右键拖动仍可平移，复位恢复完整图片的适应视口状态。放大不改变源像素；缩小显示的平滑混色不作为取色结果。取色时实时显示11×11原像素放大镜、像素网格、黑白中心框及完整RGBA值，浮层避开工作端并在图片区内翻转／约束，不挡住底部色板。单击或Enter把真实样本加入草稿并退出取色；方向键每次移动一个源像素，Esc先退出取色、不直接取消整张草稿。图片外留白不采样。

参考图片仅由本次新建面板持有，创建或取消后释放；保存的是色板名称和颜色，不上传图片、不保存来源路径，也不把参考图写入皮肤工程或AI会话。已有颜色和手动采样可继续通过共享HSV／Alpha选色器编辑或删除。HTML使用浏览器本地中位切分演示同一流程，不冒充Windows量化或原生输入的验收。

空色板仍以网格末尾 `+` 提供直接加色路径。删除某色不清空前景色，也不改变已经绘制的像素。内置只读状态和复制入口必须清楚；自定义色板可新增、复制、改名、删除和逐色编辑，操作都不创建皮肤历史。

原型将自定义色板和当前色板选择保存在浏览器 localStorage；加载坏数据时回退内置色板，保存失败保留本页数据并提示。此持久化仅为本机色板偏好，皮肤工程本身仍是内存草稿。原生对应 App 偏好存储，不能把色板交给皮肤业务 MCP 重做。

原生新建由选择器旁加号进入；管理省略号提供复制及删除，删除同时适用于预设与自定义色板。命名确认前不写入，取消保留当前选择。新建从空网格开始，复制完整颜色顺序后进入可编辑副本；内置预设永不原位覆盖。逐色编辑接受`#RRGGBB`及`#RRGGBBAA`，保留透明度，保存成功后才发布新集合；失败保留输入、原集合及旧偏好并显示原因。自定义集合和所选稳定ID一起保存在当前包的`SkinEditor`偏好中，跨工程、关窗及重启保留，不进入`.rmcs`或皮肤撤销历史。管理页只有正文一个滚动归属，色块按自然高度展开；返回管理时清除命名/删除阶段的最小高度，四边统一12 DIP内距，不把上个表单的高度变成网格下面的大块空白，也不保留左右20/上下12的混合内距。

管理页直接点击自定义小色块就打开共享原生HSV/Alpha ColorPicker，不再提供底部编辑按钮或HEX编辑行；精确色值仅作为选色器中的可选方式。该选色器与前景色共用240 DIP色谱、色相/透明度及字段几何，删色在选色器头部；内置色块只取色不原位编辑。管理弹层四边12 DIP内距，操作按钮沿标题顶部对齐，不随名称/色数两行整体居中；加号使用完整四边的原生线框按钮，不让末行边界裁掉下沿。删色按钮与删除色板菜单图标使用共享critical角色，高对比度保留系统配对。HTML以直接打开浏览器选色器示意，删色放在管理菜单；不把其RGB范围或细部控件位置当作原生规格。

管理头部的编辑、更多、关闭统一28×28 DIP命中区、16×16 DIP图标画布和零内距；不因关闭入口复用另一共享style就混入32 DIP按钮。同组选色器头部的删色/关闭保留24 DIP命中区，图标同为16 DIP。

双按钮确认保留一个明确的primary：新建/复制以创建为primary、取消为secondary；删除确认以取消为primary、删除为secondary，安全路径优先。两列仍等宽，不因主次变化改动几何。

管理/新建/复制/删除共用全宽1 DIP Edge页头分割线，有footer时也提供全宽顶部Edge分割线。header、body及footer各自四边统一12 DIP内距，不叠加外层padding。关闭入口互斥：无footer的管理页保留右上关闭；新建/复制/删除有底部取消时不再显示右上关闭，Esc沿用当前取消语义。

空白／参考图新建、复制和删除确认的单行标题在固定标题行内垂直居中，水平方向保持leading对齐；不以标题高度小于行高为由顶齐，造成上下留白不等。管理页的名称／色数双行组及操作按钮仍保留已认可的顶部对齐，不整体改为居中。

左侧底部色块在按钮旁就地打开 HSV 选色 flyout，不切换右侧编辑 / AI / 历史页签。浮层提供饱和度 / 明度二维区域、色相滑块、当前色预览与六位 HEX；调整即时同步前景色，关闭无需另点应用。二维区域可用方向键微调，Shift+方向键增大步长；无效 HEX 保留输入并就地提示。Tab 在浮层内循环，Esc / 关闭按钮回到左下色块，点击外部关闭；浮层位置在窗口边缘内调整。当前原型没有颜色 alpha 输入，RGBA 缩略图展示的是绘图层已有像素的真实透明度。

## AI 辅助流程

极简的是操作与工具呈现，不是删掉聊天：只保留模型选择、输入和发送/停止；直接修改当前皮肤，不显示范围配置、审批、候选对比。正文按时间保留全部用户消息、思考、流式回答和工具调用，不能只显示最后一条。思考沿用真实内容及展开状态。连续工具调用合为一个默认折叠的Expander：确有未完成工具时header为“调用工具中…”，完成显示实际步数，不把后续模型推理标成仍在调用工具；仅严格相邻的工具归组，思考独立显示并中断前后工具组。

皮肤会话允许响应中继续发送，提交后进入Core队列。普通聊天与皮肤队列均提供“立即发送”和取消；立即发送停止同会话当前响应，将所选消息排到下一轮，其余顺序保留。输入框保留独立控件子树，避免流式状态布局干扰输入焦点；Enter与IME仍交给原生TextBox。输入上方复用AI Chat三点响应动画，待回答/审批时暂停，删除记录尾部重复的处理中提示。UV小窗外框顶部内距由8缩至2 DIP，其余内距和24 DIP标题行不变。

工具组和思考沿用AI聊天共用的非动画内部展开头，不换成另一个外观不同的原生Expander。展开内容只占当前聊天布局，不另开内层滚动；展开与折叠按组头锚定阅读位置。思考、工具、回答都是同一轮响应的组成部分，回答不加“响应”小标题、复制按钮或其他重复装饰。

展开正文四边统一12 DIP内距，包含顶部；思考第一行和工具第一步不能贴着展开头下缘。折叠不残留该正文内距。

展开后逐步呈现真实用途：读了哪个身体部位/底层或外层/面，画在哪个绘图层、用了何种形状/坐标/颜色，新增/复制/隐藏了哪个图层；跨面笔画按实际采样点表面分别说明。不把模型label冒充效果证据，成功/失败及具名错误独立展示，不再让一堆相同的“查看皮肤/编辑皮肤”淹没主流程。header的展开状态与阅读位置按真实组ID保留。模型服务与凭据仍归全局设置。

Enter发送、Shift+Enter换行沿用原生TextBox的SubmitOnEnter及IME处理，不显示常驻快捷键提示。发送/停止图标采用零padding、水平和垂直居中，不沿用文字按钮的内容内距。无历史消息时在正文实际剩余视口居中显示低强调图标、短标题和单句提示；无模型与加载/错误分别呈现，不能把读取失败或加载中当作空聊天。流式更新仅在用户原本位于底部时追底，向上阅读、展开思考和切换页签保持阅读位置；虚拟化同时改变内容范围不能让用户上滚失效或被拉回底部。

输出达到服务或显式预算上限时显示“未完成”及真实原因、保留部分消息和安全继续入口，不笼统称“请求失败”。同一目标已有后续继续回合时，旧回合隐藏过时警告和继续按钮，不能让上一轮截断看起来仍是当前错误；原记录及工具证据不删改。原生入口不再注入4096等默认输出限制；输出容量由统一Core复用真实provider/models.dev信息，未知不猜测。重开工程仍恢复同一chat，不通过清历史掩盖失败。

右侧编辑/AI/历史共用可调整宽度的侧栏。原生使用Sprout Sizer覆盖在画布与侧栏边界，静止细线、悬停可拖，保留键盘及UIA RangeValue。宽度在240–640 DIP及画布剩余空间内夹取，不缩放整窗或挤掉主画布。HTML提供相同的拖动与键盘示意。

AI复用统一Core会话/MEAI管线与同一套Core皮肤工具，不新建Agent或复制绘图库。宿主只授权当前文档，`DirectEditing`让`skin_propose`立即提交同一批typed动作并返回原子接受回执；皮肤编辑不再叠加通用安全模式的逐次审批，也不更改全局或普通聊天权限。模型不能扩大到别的工程、任意文件路径或启动器管理。通用受限候选API仍保留原契约，但编辑器不再展示它。

每个皮肤工程只保留一个当前AI会话。输入框底部在已有对话时显示“气泡＋”新会话图标，沿用相邻参考图／发送按钮的大小与材质；空对话不显示也不占位。点击先确认清除当前工程对话并停止活动回答，取消为primary，开启新会话为次级；取消或Esc不改变会话。确认经Core精确删除旧对话，再建立同工程、同模型的空白会话，不保留另一条可重新载入的旧会话。已保存皮肤、图层及绘图撤销历史保持原样，失败保留旧会话并显示真实错误。

生成时暂时避免手绘/工程切换与AI写入互相覆盖；观察到真实工具结果后有界重读工程，更新3D、平面、UV及统一撤销历史。完成或取消后仍保留已提交动作；失败如实显示，未知效果与同clientKey恢复沿用Core，不盲目重放。用户用现有撤销/重做调整结果，没有独立“撤销AI”入口。

参考图是制作皮肤的正常输入：只提供一个图片图标按钮，位于发送按钮左侧、模型选择之后；粘贴不设按钮、只在输入框Ctrl+V时识别图片，输入框焦点使用AI聊天共用的Focus暖黄色角色；接受PNG/JPG/WebP，每轮最多3张，超过时明确反馈而不是静默截取。草稿显示实际冻结图的缩略图、文件名和移除；发送后的图片留在对应用户消息中，重新打开聊天仍可查看。输入框聚焦时Ctrl+V可附加剪贴板图片，文本粘贴和画布选区粘贴不被抢走。图片进入实际模型多模态内容；文件名不是图片理解，选择不代表允许模型访问任意路径。服务不接受图片时保留真实错误，不伪造已看图。

随包`skin-editing`技能由Core在皮肤回合自动加载：优先按身体部位/服饰职责建立独立绘图层，不默认绘画到背景或覆盖已有原作。替换已有层时保留像素，可复制成工作层并隐藏原层；原层跨多个部位时同时保留无关可见内容，不能为了帽子就隐藏整个人物。按一个有意义的部件完成整批动作与可见性变更，提交有描述性label，原生历史直接呈现该AI标签；不能按单像素、单面、单色制造碎片历史。技能是规范指引，不伪称绘图库增加了无法绕过的图层策略门禁。

人物参考提供身份，用户认可的MC成品提供目标设计语言；技能处理的是通用审美转译，不维护角色配方。五官、刘海、脸区留白和深浅视觉权重一起构图，像素密度保持一致；不默认补齐写实眉/鼻/嘴或把虹膜夹在粗重上下横线之间。按当前模型/UV画可辨识像素簇，头部近景和正常全身尺寸都实际对照，不能只匹配配色或靠衣服细节掩盖脸部失败。长发与衣摆可在既有几何的不同部位表面连续表达，Outer选择性增加厚度；连续发套检查六面，不把透明缺盖误判为网格漏面。风格图的附加模型、摆姿与光影不能冒称普通皮肤已实现；真实质量与取舍按实际预览判断。

HTML仅演示固定本地配色并直接加入本页历史，不连接模型或MCP，不作为真实模型质量与原生功能的验收证据。

## 工程状态、历史与恢复

现有 Core 每次 `EditAsync` / `RestoreAsync` 在文档写租约内重读、检查 revision、执行并保存。单批 1–512 个动作原子提交，失败不发布部分像素；有实际变化才增加修订并清空 redo。撤销 / 重做也增加修订，最近 32 个完整状态可恢复。像素与绘图层设置共用历史。

历史面板每个步骤可点击回溯，当前步骤有选中态，后续步骤变淡但仍能点击恢复。查看旧步骤、切换工具 / 色板 / 相机、选中图层不会丢弃后续历史；只有有实际变化的像素或图层事务提交才在当前步骤分叉并丢弃原后续步骤。空笔划不截断历史。原型用同一快照链执行跳转，保留32步上限；正式 Core 接线需基于真实 undo / redo 与修订顺序推进，不能把跳转位置直接当成旧 revision 写回。

原生状态至少覆盖“已保存”“正在提交这一笔”“保存失败”“检测到其他客户端修改”。写入失败时保留尚未提交的笔划预览并允许用户选择重试或放弃，不能把未保存结果标成已完成。冲突先保留本地草稿与最新快照，再由明确策略重新处理，不能静默覆盖外部 AI 或其他窗口的成果。

关闭时已提交工程无需重复确认；存在未提交笔划或保存失败时，按实际未完成内容提供保留 / 丢弃 / 返回编辑。导出失败不影响可编辑工程。工程损坏或缺失时展示真实错误，不自动用空白皮肤替换同一 ID。

历史页显示事务来源与简短动作摘要，点击保留范围内任一步骤即恢复该步完整状态，不是按来源选择性撤销。原型为本页操作生成摘要；当前Core历史提供真实Transaction.Kind/Source及模型、尺寸；面板本地化实际动作类型，不虚构作者或时间。SkinEditingSession.History原子返回同一版本与保留条目；点击以显示时revision调用RestoreToAsync，成功才发布会话并同步所有视图和图层。

HTML 的“修改仅保留在本页”和内存历史是原型生命周期；刷新或关闭不等于 Core 的持久化语义。原型工程名称只是设计示例，不新定义正式工程格式。当前.rmcs工程采用JSON序列化，包含图层与历史，PNG 是独立的平面输出。

## 原型与实现边界

原型的评审范围是单行独立窗口标题栏及默认折叠的菜单 / flyout、五种原创基础模板、Classic / Slim 与64 / 128的组合创建、Canvas 绘制与真实方块足迹、主3D / 平面与独立可编辑UV小窗同步、Alt导航、面内连通填充、取色、平面矩形选区、HSV就地选色、五套预设与自定义色板编辑 / 本地保存、图层拖放 / 行内改名 / RGBA缩略图、保留后续步骤的历史回溯、对应尺寸的PNG导入 / 导出，以及固定 AI 换色候选的应用 / 放弃 / 对比 / 冲突反馈。以实际浏览器核验记录为准，不把存在的按钮当作功能已完成。

两种模型与两种分辨率在本页共用编辑、图层和历史；确认新建才替换像素并重新开始历史，确认导入则作为可撤销事务保留原工程快照。旧 `64×32` 导入、已有文档的模型转换 / 尺寸调整、工具高级范围参数、图层复制 / 删除 / 合并、非矩形选区、剪贴变换、跨缝、软笔刷、像素颜色调整、键盘像素编辑、持久化工程、真实模型与 MCP 均尚未在本页实现。已有的模板预览、工具 flyout、图层编辑与 HSV 前景色选择不代表这些高级能力已交付；Core、CLI与MCP当前已支持128文档；不能由此推定原生所有编辑流程通过。

后续原生实施按真实玩家流程验证：新建 / 导入后编辑并重开、3D 与 UV 的同一像素、Classic / Slim × 64 / 128与内外表面、单笔撤销 / 重做、跨模型 / 尺寸导入及撤销恢复、图层合成与同分辨率导出、透明区域与背景保护、保存失败恢复、外部 MCP 与手绘修订冲突、AI 候选过期与未知效果。窗口还需验证最小尺寸、DPI、浅深主题、高对比度、键盘和 UIA。

原生图层管理现已接同一Core会话：新增、删除、行内重命名、显隐及拖动排序均为独立可撤销事务。行内选择、眼睛和菜单有独立命中区；整行由Sprout ItemsView提供原生选择和拖动排序，拖柄仅作为垂直居中的被动图标；拖动项跟手、邻项实时让位，关闭重复源拖影，保留让位动画。列表在属性正文中自然展开，统一由外层滚动，不限高或建立第二个有效纵向滚动区；异步保存期间仅乐观展示待保存顺序，失败还原显示且保留实际草稿恢复语义。只有有效落下提交一次，取消、原位落下不记历史。背景层固定底部，只允许改名；隐藏/锁定层保持选中且拒绝绘画。名称Enter或失焦提交、Esc取消，保存失败保留输入并允许重试/明确放弃；排序也提供菜单及Alt+方向键替代。复制、合并、锁定和不透明度的界面仍未接线。

## 原生交互统一

图层整行仅一份选择表面，缩略图/名称不嵌套可点击按钮；双击行或F2开始改名，Enter/失焦提交、Esc取消。溢出菜单锚定实际按钮，全部菜单项带图标；背景仍固定在最底部。所有视口左上操作为28 DIP方形、14 DIP连续线条图标、零内距居中；画笔大小沿用原生Slider输入与RangeValue语义，用方形轨道/浮雕滑块呈现主题材质。PNG导出使用真正DialogPrimary绿色主动作材质。footer左侧状态占弹性空间，右侧层名/表面/模型尺寸均为相邻Auto列、统一列距且垂直居中。

滚轮围绕指针缩放：平面/UV保留指针对应纹理坐标，3D保留指针射线在相机目标平面的交点；按钮缩放仍以视口中心为锚点。3D的可见集合同时用于GPU绘制和CPU拾取，不能显示隐藏部位或向隐藏部位绘画。

已接快捷键：Ctrl+N新建、Ctrl+O打开、Ctrl+Shift+I导入、Ctrl+Shift+E导出、Ctrl+Z撤销、Ctrl+Y/Ctrl+Shift+Z重做、Ctrl+S提交待保存草稿；B/E/G/I分别为画笔/橡皮/填充/取色，M镜像，1/2切3D/平面，[ / ]调整笔宽。作用域随皮肤窗口释放，文本输入、IME、菜单和弹窗优先，不在背后触发单字母编辑。图层F2及Alt+上下保留，原生列表另支持Ctrl+上下排序。未接选区/剪贴板的快捷键不宣称已可用。

## 工具悬停与缩放

画笔保留普通指针，不接管系统形状。橡皮、填充、取色使用40 DIP画布的高对比实心轮廓，按窗口DPI生成并缓存；删除与工具分离的十字。热点分别是橡皮接触角、油漆滴落点、滴管尖端，工具主体向右上展开，作用端必须真实落在目标格上，不能用角落热点加偏移图标冒充。仅绘图输入区接管指针；工具按钮、UV浮层、文件选择器和菜单/对话框保留各自指针，窗口失活或视口释放时撤回覆盖。填充悬停使用当前活动绘图层的真实连通范围，淡色覆盖并描边，预览与点击共用填充参数和算法；不创建临时历史。取色仅描出实际采样的单格，不使用笔宽或镜像足迹，透明外层穿透沿用实际取色拾取结果。

投影轮廓按输出物理像素计算平滑coverage，保留纹理point采样。软件渲染继续有界场景预算，仅轮廓投影区域在resolve后补做输出分辨率绘制；不把全画面模糊当抗锯齿。footer增加主题化原生Slider与百分比，控制当前主视口缩放并同步按钮/滚轮/重置；3D、平面各保留自己的值，独立UV缩放不改主footer。背景底层不可擦除提示使用本地化资源，保留底层最终不透明约束。

3D旋转中心由当前可见部位重新计算：单部位使用该模型实际基础长方体中点；多部位对各中点取等权几何中心，不因部位体积或纹理分辨率改变权重。Classic/Slim复用实际模型几何，空集合使用稳定默认中心。切换部位或模型时清除旧目标平移，保留观察角度与缩放；缩放偏移保存在相机局部空间并随角度变换，使旋转仍围绕所选部位中心。GPU相机、CPU拾取及指针缩放使用同一相机快照。

128×128 工程的“导出 PNG”使用现有 accent SplitButton：主操作导出原始128尺寸，溢出菜单仅提供“导出为 64×64”；64工程保留单按钮。缩小先合成可见图层，再按像素中心最近邻采样，保留透明度与硬边；仅输出PNG副本，不改变工程、图层或撤销历史，Ctrl+Shift+E仍导出原尺寸。
