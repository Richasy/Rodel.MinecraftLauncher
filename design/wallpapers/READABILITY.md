# 壁纸局部可读性设计

内置 Light/Dark 各六张继续按已搭配的主题分组；跨明暗适配主要服务用户自行导入的图片。HTML导入保留浏览器本地；原生副本保留应用LocalState，不上传。

## 参考依据

只读核对 Rodel.Player 提交 `26c9ddfcc27e35c2c607208b4f38954fd7cd5c3c`：

- `src/Apps/RodelPlayer.Sprout/Home/Views/HomeCardView.cs`：`LightCoverTitleOutline` 为 ARGB(77,0,0,0)、宽 1.4 DIP；在分析认为需深色字时，给固定浅色标题补黑色描边；HC 走系统前景。
- `Home/Views/HomeProductCardControl.cs`、`Home/Images/HomeImageAnalysis.cs`：64×64 采样，后台分析，取消与 generation 校验后回 UI。
- `Home/Policies/HomeCardArtworkInkPolicy.cs`：横卡采样高度 50%～85%，竖卡 60%～90%，采用区域平均色。这个固定区域平均方法不直接适用于可缩放的启动器壁纸。

本稿借用柔和细描边的外观与后台分析/过期结果保护原则，不复制参考项目源码。CSS 与 Sprout 渲染器的线宽/抗锯齿不能当成逐像素等价。

## 局部文字判定

首页采用完整壁纸上的60deg斜向10 DIP模糊/调色降低阅读区纹理干扰，Light中右侧保留色彩，底部景物保留；参数见[设计规范](../DESIGN.md)。局部采样先近似合成实际场景再判断对比。非首页材质保留，内置图库按搭配主题分组。

逐个分析直接覆盖壁纸的标题、副文、版本字段、就绪信息和场景名称；有自身材质的按钮、面板不套壁纸描边。通过 DOM Range 获得字符的实际矩形，而非把整个 hero 连同空白求平均；按实际 cover 缩放、居中/顶对齐和当前窗口几何映射回图像。字符矩形仍包含字形内部空白，当前没有逐字形 alpha 掩模，不能宣称像素级字形检测。

采样采用 sRGB 线性化的相对亮度比：大字判定 3:1，其余 4.5:1。按字符投影大小使用 3～12 列、3～12 行的局部网格，总预算不超过 65,536 点（最多 16 个文字组、每组 256 字符）。不足点达到 12%，或相邻两个字符各有至少 40% 点不足时加描边；已启用时降到 5% 才撤回，减少临界闪烁。局部坏块不会被整图平均色掩盖。

描边以参考的 30.2% 透明度为起点；固定 30% 在 Light 深色文字叠到极暗自定义图片上仍不清楚，因此仅对不足区域按亮度比选择 45% / 60% / 72% 的补偿档。标题 1.4 CSS px，副文 0.85 CSS px，保留原文字填色、细轮廓及轻微软边。描边黑白方向按文字亮度决定。采样阈值是触发依据，不等于抗锯齿后的每个文字像素已经满足无障碍对比度认证；细纹理、极端图片仍须目视核验。

## 性能边界

- Worker 持有像素，解码、缩样、读回和对比计算全部在后台。最长边最多 768 像素；LRU 至多两张，每张另缓存模糊结果，原生还复用一个模糊工作数组，均受768样本上限约束。原始浏览器解码的临时内存不包含在这个数字中，超大导入图片的解码峰值尚未专门验证。
- 主线程仅在布局/文字/主题/图片改变时读取文字矩形和发起任务，几何签名相同则跳过分析。不存在逐帧循环、轮询或 resize 时反复读原图。
- 最快每 120 ms 一次，单个在途任务，只保留最新待处理布局；连续 resize 合并，结束后补最后一次。revision 防止旧结果回写；HC、非首页和隐藏标签不继续分析，HC 清除效果并关闭图库。
- 本地性能计数只放在 DOM 的 `data-contrast-metrics`，不添加产品开关或用户可见技术面板。验证脚本/报告仅留忽略目录。

## 原生实现与验证边界

原生使用Sprout文字描边、DWrite实际字符矩形及后台WIC有界缩放解码。WallpaperScene负责GPU绘制，WallpaperScenePolicy/Contrast/Readability负责后台分析；两图LRU、120ms合并、单任务及generation保护。CPU三次box模糊近似GPU GaussianBlur，不宣称逐像素等价。计时、计数和诊断访问器只在验证构建存在。

实际16次resize、静置及缓存验证和最终109项场景断言通过。系统文件选择器GUI边界、连续滚动帧时间及超大图解码峰值尚未完整验证。完整背景参考Rodel.Player提交 `f2a73c39bcce8d0a89e7e19abd0c9a742a36c78f` 的HomeHeroView、MediaDetailBackdropControl及ImmersiveCoverBlurPolicy，不复刻其底部消失效果或复制源码。
