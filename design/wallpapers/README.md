# 内置壁纸图库

当前内置 **Light/Dark 各12张，共24张**：每个主题含6张自然群系风景和6张玩家玩法壁纸。原生设置页与HTML原型使用相同的稳定ID；已保存的选择、导入图片与默认浅色神殿/深色河谷继续保留。

## 玩家主题

| 玩法 | Light | Dark |
| --- | --- | --- |
| 生电 | 世吞开机 | 夜班刷铁 |
| 跑酷 | 再远一格（晴空遗迹） | 别停下（月光脆冰） |
| 种田 | 丰收时刻 | 午夜访客 |
| 竞技 | 窄桥攻防 | 读懂下一招 |
| 机械工业 | 航空学：首次升空 | 机械动力：夜班开工 |
| 多人冒险 | 共同发现 | 我来照路 |

玩家是这些图片的主体，场景表现各玩法的行为与故事。同一玩法的Light/Dark采用不同情境，而非同图调色。认可当前版本并授权加入正式资源和设置列表；机械工业使用头身比修正版，竞技Light使用握剑修正版。

## 自然群系

- Light：沙漠神殿、樱花草甸、斑驳秋林、雪峰冰湖、热带海湾、赤岩高原。
- Dark：河谷、熔火峡谷、幽光洞庭、红树夜泊、诡异幽谷、末地浮岛。

## 资源与运行边界

- 运行资源自包含于[App背景目录](../../src/Rodel.MinecraftLauncher.App/Assets/Backgrounds)。`WallpaperStore.BuiltIns`提供本地化列表，MSBuild通配项将JPG复制到构建与发布输出；运行不引用design目录。发布背景保留1536×1024，以JPEG质量92、4:4:4色度采样编码，不改变稳定ID、裁切或用户导入图片。
- [catalog.json](catalog.json)记录当前24张的稳定ID、主题、资源路径、大小与SHA256；[HTML图库数据](../wallpapers-data.js)用于设计原型。新玩家图片由原型直接引用仓库内的App JPG资源，不另维护副本；自然群系的设计源图保持独立。
- 自然群系的12个已有稳定ID对应游戏内的六面全景。玩家壁纸没有六面资源，传给游戏的槽值为`minecraft`，保留原版全景；不把平面壁纸当全景，也不传本地图片路径。
- 原生图库按实际数量换行，12张内置图及尾部可选自定义图均可滚动到达；不再固定绘制7个格子。标题保持三语Resources，自动化ID不随语言变化。
- 缩略图和首页采用cover裁切；末地保留顶对齐，其他图居中。完整人物可见性、UI遮挡与文字对比需要按实际窗口观察，图片本身不烘焙遮罩。显示端规则见[可读性设计](READABILITY.md)。
- 图像是艺术表现，不作为跳跃距离、刷铁或模组机械可直接按图搭建/运行的证明；脆冰采用26.4快照新方块的叙事特征。

高对比度模式继续禁用壁纸。导入保持浏览器本地或App自己的可写存储；不上传用户图片。
