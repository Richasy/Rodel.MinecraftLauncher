# 服务器客户端入口

服务器与本地实例一起管理，“游戏”首页提供进入服务器的入口。HTML 入口为 [首页服务器](index.html?page=home&target=server&theme=light) 与 [实例 / 服务器](index.html?page=instances&view=servers&theme=light)。两处已接原生，共用连接链路；HTML 本身不作业务证据。

## 游戏首页：选中即可连接

右侧“我的游戏”面板共用“本地实例 / 服务器”Segmented，各自保留选择和滚动位置。选择服务器后，左侧主区显示真实名称、原始地址、客户端及启动身份/运行配置；明确首选或唯一关联时，大按钮直接连接，不先进入管理页，也不重复弹确认。缺少明确客户端或已有选择失效时，才从首页打开既有连接 Dialog；本地实例始终保留普通启动路径。

应用记住上次首页类型和服务器 ID，不改写本地实例选择；删除已选服务器后不自动改选其他收藏。首次默认选择同样保存，避免重启后悄悄换目标。从实例管理明确启动本地游戏（包括新建后启动）会回到本地首页；普通返回首页仍恢复上次类型。状态查询与可选摘要不作一键连接门槛。

卡片显示服务器实际SLP favicon；缺省用共用服务器线条图标，不从地址猜Logo或另找第三方图源。右上角8 DIP圆点表示绿/在线、灰/未知或查询中、警告色/查询失败；RTL仍在卡片物理右上角。提示包含完整状态、玩家/版本/延迟、上次查询时间及可选图标错误，卡片HelpText提供同一说明，不给圆点增加独立焦点。查询失败不等于确定离线，更不等于禁止连接。

首页与管理页共用按地址缓存的状态和图标；可见服务器页面约30秒刷新，最多4个并发查询，离开相关页面取消过期批次。查询失败保留本次运行最后有效图标，成功但服务器未提供图标则回退通用图标；不将内存缓存描述成跨重启持久化。

准备、取消、失败与重试留在原主启动区，使用同一 Jobs/Sessions 观察；只能取消本进程拥有、且确为当前实例/地址的任务。后台准备、切页及换目标不停止游戏。成功退出的历史会话不把下次开屏显示成失败重试；账户与地址在排队前冻结，运行中切身份不改写已启动游戏。

主操作行保留连接、设置；错误卡片存在时使用卡片内的展开按钮，只有没有可展开错误卡时才追加中性“查看错误信息”图标兜底，不能同时出现两个入口。实际服务器评审选择服务器收藏及已关联客户端，不以本地副本列表代替服务器；关联客户端仍保留普通本地启动路径。

错误面只显示实例及游戏/加载器原文，不显示“如何恢复”“技术依据”或匹配生成的原因解释，也不按分类跳转修复。原文卡沿用共用几何，用Critical图标及错误底色表示日志声明的错误。完整记录位于页头，底部仅半列关闭；只读查看不修改配置。会话历史/游戏进程原文不能猜测归属服务器，必要时隐藏地址并说明进程上下文。评审保持同一失败记录，不切换到另一个资料根制造“未读取到”的混淆。

## 实例页：管理和维护

- 主导航统一“实例”，页内“本地实例 / 服务器”使用同一 Segmented，保留各自选择与滚动位置，页头操作随当前分段变化。这是客户端收藏，不是服务器进程管理。服务器列表按名称/地址、SLP 状态、客户端实例、操作排列；小窗将状态与实例移到名称下方，保留连接及更多入口。
- 页头提供直接连接与添加收藏；每行只保留连接和省略号。编辑、关联实例、移除收藏放在菜单；移除图标为 Critical，确认只删除收藏，不删除实例或游戏数据。
- 一个收藏可关联多个既有实例，也可指定首选。无关联仍可选任意已有实例；多个关联且没有首选时不猜选。关联只保存选择，不安装、升级或校验服主内容清单。
- 连接是独立任务 Dialog：游戏地址、客户端实例、本次身份及可选“记为首选”。身份沿用实例实际配置或显式选择已有账户，不改变全局身份；不放账户管理按钮，账户管理从主界面头像进入。不附加游戏准备/运行/退出/取消的状态正文，忙态使用进度，实际错误沿用原文入口。
- 服务器更多菜单提供管理客户端、添加已有客户端、编辑和移除。管理客户端是归属明确的独立上下文：只列所属客户端，复用新建/二项导入菜单和全部实例维护业务；所属客户端默认“连接”，普通启动与转回本地放更多。普通本地列表和首页本地列表不列专用客户端；一次普通关联不意味着转移归属。移除服务器不删除客户端，而是转回本地。此项覆盖早期仅共用本地关联列表的设计。
- SLP 失败与启动准备失败分开；前者不禁用连接。准备可取消，失败/取消保留选择以便重试。任务和会话留在 Core，关闭页面不停止已经运行的游戏；无可靠游戏证据不显示“已入服”。
- 名称/地址组使用与首页相同的真实服务器图标及通用回退；状态沿用共用查询，不因切换到管理页重造另一套网络请求。
- 地址和技术版本保留 LTR 阅读顺序，界面布局可 RTL 镜像。Dialog 内容自然测高，超预算只滚正文；底部双等分列，单关闭按钮仍占尾端半列。

HTML 只用虚构内存数据，不查询服务器、不安装包、不授权或启动游戏。模拟准备结果的按钮明确标记为非产品评审工具。HTML 不代表三语原生、Windows 系统高对比或真实入服通过。

服务器表单不填写内容分发 URL；现有实例来源归其整合包元数据。归档准备、补件和更新复用Core整合包服务；不从普通 IP 猜模组，不要求分发站点或 Rodel UI。
