# 账户菜单 HTML 设计

原生微软登录默认使用Windows WAM，首次登录、重新登录和缺少待完成缓存的重试直接请求当前启动器窗口所属的系统账户选择器；正式构建向Core注入公开OAuth应用ID，不要求玩家配置，显式／环境覆盖仍优先，源码不记录实际值，包不携带Client Secret。已知WAM运行组件初始化失败时才提供“使用浏览器登录”替代按钮，其他失败保留重试与现有账户。HTML默认模拟系统授权等待，不访问Windows账户，也不代替真实认证验收。

头像修订：[头像交互原型](account-avatars/index.html)与[流程规格](account-avatars/DESIGN.md)。快速菜单改为左侧方形缩略头像、尾部类型徽标及悬停说明；本地账号默认史蒂夫，可选28个预制头像或裁切自定义图片，微软与外置账户使用在线皮肤头像且不提供本地修改。已有“需要重新登录”状态的副文字采用12 DIP Critical色。

：有远程皮肤地址的在线头像在首次打开、账户切换和皮肤更新时使用原尺寸方形shimmer，不先显示默认史蒂夫或上一账户的头像；加载完成后原位替换。旧请求在切换时取消，迟到结果不得覆盖当前头像。远程失败结束shimmer并回退默认头像，缺少皮肤地址及离线本地头像直接显示；侧栏、账户列表和快捷菜单共用此行为，不增加常驻说明或改变命中区。

## 外置账户增量

外置账户设计见[完整交互与来源](EXTERNAL-ACCOUNTS.md)及[预览](index.html?accounts=1&external=1&theme=light)。微软、外置与本地为三个账户分组，LittleSkin与其他Yggdrasil服务属于同一外置账户类型。

LittleSkin设备授权可用时使用设备码，打开网页在左、取消在右且等宽并排；设备流应用未开通时直接转邮箱/角色名和密码表单，预置服务地址且不展示地址字段。表单及错误页标题左侧均可返回来源选择。其他服务同页填写认证地址和账号密码，一次登录自动读取服务信息，失败保留输入供修正。HTTP按用户填写的协议处理，无特别提示。错误详情由提示条标题尾部的信息图标打开Flyout，可选取及复制原文，外部点击/Esc只收起Flyout。HTML表单仅接受评审用虚构输入，不发送或保存；全部身份/皮肤为模拟数据。新增模块为external-accounts.js/css，沿用本页共用容器、主题和组件，底部下拉框选中即预览完整虚构状态。

## 间距与条目边界

账户表单保留独立字段标题，同时为可编辑输入提供placeholder：离线玩家名、其他认证服务地址/账号、LittleSkin邮箱或角色名及密码。认证地址“可粘贴网站或 Yggdrasil API 地址。”改为框内placeholder，不在框下重复说明；placeholder不是预填值，获得焦点仍可见，输入后隐藏，清空后恢复。只读的授权码/错误原文及系统微软授权页不作为App新增输入字段。

正文四边16 DIP，账户条目四边12 DIP并按内容自然测高；末项不画分割线，单项列表没有分割线。禁止用首末项不同padding或固定行高制造上下空白。

等待行的加载环、两行状态文字和右侧取消整体垂直居中。错误提示条内距12 DIP，图标到文字组12 DIP、标题到正文4 DIP、提示条到后续组件16 DIP；不为错误详情入口预留正文空行。并排操作统一主操作在左、取消在右，DOM与键盘次序一致。

## 预览与基本流程

从仓库根目录启动本地静态服务，打开 [账户管理](index.html?accounts=1&theme=light)；[头像菜单](index.html?accounts=1&panel=closed&theme=light)保留首页上下文。账户逻辑由 accounts.js 承接，视觉由 accounts.css 复用既有主题、方角微立体按钮与短投影。

1. 点击左上头像，菜单列出当前身份和其他账户。选择立即切换后续启动的身份，不改变运行中的游戏；管理和添加为独立入口。
2. 账户管理显示当前身份、账户类型和状态。行内只保留使用/当前tag与省略号溢出按钮；微软验证会话/重新登录、移除收进溢出菜单。菜单项统一有线条图标，移除使用Critical色；当前使用是平面tag，不伪装成操作按钮。头像菜单底部管理账户与添加账户同样带图标。
3. 添加账户展开可light-dismiss的界面中央类型Popup，选择微软或离线；无关闭按钮；点击外部或Esc关闭并回到主界面头像。账户管理与添加类型Popup互斥，打开另一个前先关闭当前Popup，保留已添加账户和当前身份。离线填写名称，检查空值与已有同名身份，添加并使用；本原型不额外限定历史名称字符集。名称变更影响本地玩家身份，首版不提供静默重命名。
4. 选择微软账户立即请求Windows安全登录窗口，不再展示说明和“继续登录”的中间页；重新登录与换账户同样直接请求。HTML不仿制系统密码表单，直接进入授权等待，通过明确标记的“设计评审 · 非产品界面”工具返回成功、网络失败、系统组件不可用、无游戏权限或取消。Alt+1至Alt+5提供同序快捷键。取消回到管理列表；浏览器替代入口只在系统组件不可用时出现。
5. 首个成功登记的账户自动选中，后续新增微软/外置账户不切换现有身份；离线“添加并使用”仍是显式选择。重复登录复用演示账号，验证已有账户只更新其状态。取消不创建身份，已取消视图不接受迟到模拟结果。
6. 移除先确认本地影响；移除当前身份后清空选择。移除最后一项显示空态，保留添加入口；不自动补一个 Steve，不删除游戏或 Windows 账户。

首次尝试启动游戏时若没有所选身份：没有任何账户则直接打开离线玩家名表单，不能用隐藏的Player占位名开始任务；已有账户则先选择实际账户。填写并使用后继续这一次启动，取消则不创建启动任务。全局设置不再提供第二个默认离线玩家名，名称由真实账户维护；实例明确保存的离线身份和Core/CLI手工playerName配置仍按现有契约保留。

示例 Steve、RodelExplorer、CloudBuilder 为虚构数据，仅存浏览器内存。刷新恢复；无 LocalStorage、IndexedDB、OAuth 调用、Client ID 或凭据。头像是现有原型示意图，不冒充真实账户皮肤。

## 容器与状态

| 区域 | 行为 |
| --- | --- |
| 头像菜单 | 就近展开、边界避让、内部列表滚动；外部点击/Esc关闭；方向键、Home/End、Enter/Space；关闭恢复头像焦点 |
| 账户管理 | 居中light-dismiss Popup，宽度最多440 DIP；标题及绿色立体添加按钮固定，仅正文滚动，无右上关闭或底部关闭栏 |
| 添加/离线/微软/移除 | 类型选择同样light-dismiss且无关闭按钮，保留微软/离线/外置选择卡及Microsoft Logo；普通表单保留必要返回／提交，进行中的授权、验证及移除拒绝外部关闭，显式取消语义保留 |
| 等待 | 不定状态，独立取消与授权状态同行，进行中不显示顶部关闭/返回，也不设置底部取消栏；初始焦点落在取消，Esc同样取消并回管理。系统授权后仍需检查 Xbox 与 Minecraft 权限，不能伪造完成百分比 |
| 登录失败 | 网络失败可重试；系统组件不可用可改浏览器；无权限可换账户；既有身份保持 |
| 空列表/长列表 | 关闭管理后顶部工具可载入场景；长名真实截断才提供全文 tip；长列表只滚正文 |
| 评审工具 | 原型顶部场景、底部模拟说明；模态内独立虚线区仅为评审返回和主题切换，不进入产品UI |

账户同类流程的单个底部提交/继续按钮共用通栏布局，紧接正文、没有独立分割线；不再使用单按钮靠右的操作栏。关闭与取消各有独立职责，不将进行中的取消复用为标题栏关闭。

微软授权取消后先重新读取账户与当前选择，再返回管理列表；未完成首次读取或读取失败不能展示为空账户。切换“使用”时保留同一面板、列表与高度，只原位更新当前身份及禁用状态，不为短暂的本地写入增加会引起居中跳动的进度行。

主题跟随共用 Light/Dark/HC；模拟HC不等于Windows系统HC实测。正文按 leading 对齐、说明使用 Muted、图标使用连续线条；无真实皮肤时原生应使用明确回退，不以名字首字母冒充皮肤。HTML中文演示不冒充三语与RTL原生验收。

## 社区参考与取舍

- [HMCL 账户说明](https://docs.hmcl.net/faq.html)明确左上账户入口与微软/离线选择。这里保留两条清楚可达的路径。
- [Prism 账户页源码](https://github.com/PrismLauncher/PrismLauncher/blob/60bcc2694d7433e2d2a657fbf62b0d022f9116e0/launcher/ui/pages/global/AccountListPage.ui)确认添加微软/离线、刷新、默认选择与移除操作。本设计采用基本职责，不复刻其设置页布局、皮肤管理、排序或其他产品的离线准入规则；未运行Prism。
- [Microsoft WAM 文档](https://learn.microsoft.com/en-us/entra/identity-platform/scenario-desktop-acquire-token-wam)支持broker与父窗口要求；原型只预留流程，实际个人账号/Xbox授权、NativeAOT和MSIX仍待实机。

后续原生使用Core同源能力与Resources本地化，UIA稳定ID及pattern核验；HTML通过不等于凭据保护、真实认证或入服通过。

账户管理、登录、离线表单、移除确认和类型选择统一最大440 DIP，客户区四周保留至少24 DIP。标题控件垂直居中，正文与状态共用24 DIP内距；登录状态先说明后操作，操作自然宽度并排靠末端，不铺满面板。未配置微软登录时不显示无效的重试/浏览器入口。类型选择在Sprout使用非模态light-dismiss Flyout（框架禁止模态与light-dismiss同时启用），仍通过账户功能协调保持各Popup互斥。
用户随后明确：未配置微软登录等阻断性配置错误使用独立警告Dialog，不作为登录Popup内的普通状态展示。关闭当前账户Popup后显示警告图标、原因和确认按钮；确认回到账户管理，不叠加登录面板、不提供无效重试。这是此前账户Popup规则的明确例外。
账户行“当前使用”仅表示选中的启动身份；纯平tag采用自然高度与8×4 DIP内距，名称列、tag、使用和更多操作均在行内垂直居中，不随账户行拉伸。
最新实审修订：账户Popup统一440 DIP；Header采用紧凑工具栏，标题16 DIP、操作/关闭28 DIP、水平16及垂直12 DIP内距、8 DIP间距；正文起点与标题组共用16 DIP内距。账户名13 DIP、类型11 DIP，离线不重复显示状态，当前使用tag自然高度居中。NativeAOT UIA实测Header约54 DIP（含容器边界），添加按钮28 DIP，已目视复核。

调整：本阶段点击微软账户及重新登录直接走默认浏览器授权，WAM暂停前台接入，不再先尝试系统broker。成功回账户列表供显式选择；取消保留旧账户和选择；失败重试优先复用已授权的加密缓存，凭据失效明确提示重新登录，网络/超时不误报为文件权限问题或用户取消。

当前修订：微软账户固定在本地账户之前，两组交界画线、末项无线。微软头像读取官方Minecraft皮肤头部及帽子层；HTML虚构账户不发真实皮肤请求。验证成功回列表并静默更新状态，不再显示会话已更新提示。文字按钮自然测高，不设置固定高度裁切文字。

账户两行修订：名称与可用状态两行显示，删除单独的类型文字行；类型改为尾部Microsoft四色Logo/电脑图标，提供本地化提示与无障碍名称。列表外层不重复加padding，条目四边统一16 DIP，头像28 DIP按两行内容居中；首项到页头分割线只保留一层16 DIP内距，末项不画线。文字按钮继续自然测高。

尾部次序补充：账户类型Logo/电脑图标放在省略号左侧，省略号保持最右侧操作。头像快速切换菜单仅显示玩家名，账户类型由尾部图标表达，继续保留微软/本地分组。

快速切换选中态修订：左侧始终为账户缩略头像，尾部保留Microsoft四色Logo或电脑图标；类型不因选中而变为勾号；当前身份用持续下凹底色表示，保留名称/类型文字与原生菜单导航、UIA选择语义。移除账户的垃圾桶图标使用主题Critical色，标签保留正文色。

最新菜单修订：容器继续为MenuFlyout，选中下凹与悬停行均使用直角。可见用户名后不再追加账户类型文字，左侧缩略头像、尾部Logo/电脑图标表达类型，无障碍名称仍包含类型。

快速菜单固定360 DIP并在窄窗夹取，左侧头像、尾部类型标与Critical小字延续原型；本地头像编辑用可见铅笔入口与管理头像角标。28张预制及自定义裁切由App实际接线，微软仅用官方皮肤图片。

头像菜单在头像右侧展开并顶部对齐，菜单宽度与HTML统一为360 DIP；边缘避让沿用原生Popup定位。预制头像/图标与自定义图片通过共享segmented控件切换，使用启动器统一的轨道与选中材质，不以两个独立按钮拼装。
